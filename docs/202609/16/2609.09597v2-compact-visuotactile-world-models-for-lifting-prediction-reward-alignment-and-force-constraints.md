## 摘要
准确的触觉预测未必能改善受力约束的控制。我们研究了一个具有 652,157 个参数的、以动作为条件的视触觉世界模型，并结合了匹配的行为克隆、想象中策略学习、独立反应式隐式 Q 学习以及模型辅助的力反馈。一个固定协议在 120 个全新的 MuJoCo 环境中执行了 34 个策略，这些环境涵盖几何和物理参数偏移；此外还在 12 个额外的 ID 环境上独立重放了 324 个动作分支。视触觉动力学将力作用效应 MAE 从持续性预测的 0.413 N 降低到 0.338 N。模型辅助反馈将 ID 力预算成功率从 73.3% 提高到 93.3%，配对差异为 +20.0 [+6.7,+33.4] 个百分点（95% CI），且该差异出现在脚本化下放过程中。其合并差异为 +3.9 [-4.5,+11.7] 个百分点。想象式 RL 实现了 11.9% 的合并联合成功率，而反应式 IQL 为 25.0%。一项实证触觉残差压力测试增加了 330 次执行。该证据涉及在共同接近阶段之后的刚性盒举升，不包含物理机器人迁移或闭环安全保证。

## Abstract
Accurate tactile forecasts need not improve force-constrained control. We study a 652,157-parameter action-conditioned visuotactile world model with matched behavior cloning, policy learning in imagination, independent reactive implicit Q-learning, and model-assisted force feedback. A fixed protocol executes 34 policies on 120 fresh MuJoCo environments spanning geometry and physical-parameter shifts, plus 324 independently replayed action branches on 12 additional ID environments. Visuotactile dynamics reduce force action-effect MAE from 0.413 N for persistence to 0.338 N. Model-assisted feedback raises ID force-budgeted success from 73.3% to 93.3%, with paired difference +20.0 [+6.7,+33.4] percentage points (95% CI), with the difference occurring during scripted lowering. Its pooled difference is +3.9 [-4.5,+11.7] points. Imagined RL achieves 11.9% pooled joint success versus 25.0% for reactive IQL. An empirical tactile-residual stress test adds 330 executions. The evidence concerns rigid-box lifting after a common approach, without physical-robot transfer or a closed-loop safety guarantee.

## 1. 核心问题与整体含义

- **研究动机**：视觉擅长描述物体几何与运动，触觉提供局部接触信息，二者结合理论上可指导力预算约束下的举升操作。然而作者指出，**良好的预测指标可能具有误导性**：接触力变化缓慢可能使"持续性预测"（persistence）表现良好；微小动作效应可能被状态估计偏差掩盖；策略可能完成举升却超出力限制。
- **核心问题**：视触觉控制流水线中，**哪些环节真正产生了可测量的决策价值**？具体分解为四个子问题：
  - 固定任务奖励时，加入触觉是否有帮助？
  - 在学习模型中优化策略，是否优于其精确的行为克隆初始化？
  - 基于模型的候选选择对共享力反馈控制器是否有增量价值，还是测量力守卫才是改善来源？
  - 力约束下的策略优化（想象式 RL）能否真正解决约束控制问题？
- **整体含义**：这是一项**实证诊断性研究**，而非新的模态融合架构或安全定理。作者强调预测精度与决策质量在基于模型的 RL 中是概念上不同的两件事，并用受控实验揭示二者的脱节。

## 2. 方法论

### 2.1 紧凑视触觉世界模型

- **规模**：652,157 个参数，从随机权重开始训练，不使用任何预训练视觉/触觉权重。
- **编码结构**：
  - 视觉卷积编码器 → 256 维特征
  - 触觉 MLP → 64 维特征
  - 本体感知 MLP → 32 维特征
  - 融合为 128 维 SimNorm 潜变量，由两层 384 单元隐藏层的转移 MLP 传播：$z_t = e_\theta(o_{t-2:t})$，$\hat{z}_{t+k+1} = d_\theta(\hat{z}_{t+k}, a_{t+k})$
- **预测头**：六个端点力分量、两个子步峰值法向力、相对物体高度、支撑、手指接触、原生奖励、辅助 16×16 RGB 目标。
- **训练目标**（式 4）：归一化 Huber 损失组合端点力、峰值力、高度、奖励，加二值支撑/接触损失、RGB 误差与潜变量一致性（到 stop-gradient EMA 编码器），各项权重为 $L_F + L_p + L_h + 0.25(L_S + L_C) + 0.5L_r + 0.5L_I + 20L_z$。
- **训练配置**：25 个 epoch，batch size 64，AdamW 学习率 $3\times10^{-4}$，权重衰减 $10^{-4}$，梯度裁剪 20，EMA 率 0.01，训练/验证窗口步幅 3/5。

### 2.2 预测式行为克隆与想象式策略改进

- **WM-BC**：33,282 参数、两层隐藏层的 actor，在冻结世界模型下拟合编码历史的动作。其精确权重用于初始化 WM-RL。
- **WM-RL**：在想象中优化五步回报，奖励函数（式 5）为高度对齐项 $\text{clip}(\hat{h}_k/0.10, 0, 1)$，减去超力惩罚 $\frac{1}{2}\sum_j \left(\frac{[\max(0,\hat{p}_{kj})-8]^+}{8}\right)^2$，再减去动作代价 $0.005u_k^2$。
- **关键约束**：想象更新期间**从不查询模拟器状态与奖励**；actor 最小化负折扣回报加两倍与冻结 BC 先验的均方偏差；折扣 0.95；每个 run 含 1,000 次 BC 更新与 1,500 次想象更新。

### 2.3 独立反应式 BC 与 IQL

- 反应式策略接收相同的观测历史与动作维度，但**训练全新编码器，不使用转移模型、潜变量 rollout 或预测奖励**。
- actor、双 Q 评论家、价值网络各使用独立编码器。BC 拟合高斯动作似然并部署有界均值；IQL 拟合期望值价值、TD 评论家与优势加权动作似然。
- 每模态每种子 2,000 次 BC 更新 + 10,000 次 IQL 更新，batch 256，Adam 学习率 $3\times10^{-4}$，expectile 0.7，逆温度 3，最大优势权重 100，折扣 0.95。
- 部署的 actor 有 184,692 参数；IQL 总可训练参数 785,751，另有 350,578 不可训练目标评论家参数。

### 2.4 分离模型选择与测量力保护

- **力反馈基线**：将夹爪速率替换为 $\text{clip}(0.12(5-F_n), -0.25, 0.35)$，保留脚本化垂直命令。
- **共享反应式基座**：使用上述夹爪反馈，并在 18 个抓取步后加入末端执行器相对 0.14 m 的垂直斜坡（50 步内增加），垂直增益 12，命令幅值上限 0.6；当任一测量手指法向力低于 0.25 N 时停止上升。
- **测量力守卫**：当任一当前法向力达到 7.25 N 时以 −0.25 速率打开并停止上升，但**无法追溯阻止子步峰值**，不是硬约束保证。
- **模型辅助选择器**：在局部垂直/夹爪偏移 $\{0, -0.06, 0.06\} \times \{0, -0.10, 0.10\}$ 中搜索，经裁剪后最多 9 个唯一动作，每个重复五步开环预测；使用式 6 的当前力偏移校正解码器偏差：$\hat{p}^{\text{anc}}_{kj} = [\hat{p}_{kj} + F_{n,tj} - \hat{F}_{n,tj}]^+$；在最大锚定五步峰值不超过 8 N 的候选中最大化 $\text{clip}(\hat{h}_5/0.10, 0, 1) - 0.02 p^{\text{anc}}/8 - 0.002\|a-a^{\text{base}}\|^2$；若无可行候选则使用基座。该偏移**不是保形校准**。
- **四种消融**：独立保留/移除选择器与守卫。

## 3. 实验设计

### 3.1 环境与任务

- 在 MuJoCo 中扩展 robosuite Panda Lift；每 episode 150 个动作（20 Hz），每个动作经 25 个 0.002 s 物理子步积分。
- 观测：三个 64×64 外部 RGB 帧、三个六维触觉读数、三个九维本体感知读数（末端执行器位姿与手指位置）。这些是**刚体模拟器接触力信号，不是渲染的光学触觉图像**。
- 每个控制器在动作 0–43 接受相同的特权脚本化接近；策略在动作 44–134 仅控制垂直位移与夹爪速率（水平与旋转增量恒为零）；动作 135–149 执行公共脚本化下放。
- **严格举升**定义：相对复位高度达到 0.10 m，且在下降前连续十个观测满足（首末样本间隔 0.45 s，其间不连续检查高度）。
- **主结局**（式 1）：$J_i = \mathbb{1}\{L_i\}\mathbb{1}\{\max_{t,j} p_{itj} \le 8\text{ N}\}$，力最大值覆盖完整 episode（含接近与下放）。

### 3.2 几何与数据分布

- **训练几何**（3 个）：近立方体、矮胖盒、高盒；**留出几何**（2 个）：宽盒、窄高盒。仅测试盒类内部的纵横比与尺寸泛化。
- **ID 物理参数**：质量 {0.06, 0.12, 0.25} kg，摩擦 {0.60, 0.75, 0.90}；**物理 OOD**：质量 {0.30, 0.40, 0.50} kg，摩擦 {0.30, 0.40, 0.50}；执行器上限在所有域均为 {6, 12, 20} N。
- **静态抗滑筛查**（式 2）：$\frac{2\mu\min(8,c)}{mg} \ge 1.5$，加保守孔径检查，不能保证动态可行性。
- **数据采集**：240 个训练、48 个验证、48 个校准 episode，跨三种几何均衡，50:50 混合脚本与 5 N 力反馈。归一化仅用训练 episode；所有训练方法使用相同采集数据，种子 0/1/2，无在线再训练。

### 3.3 Benchmark 与对比方法

- **评测域**：ID、几何 OOD、物理 OOD、组合 OOD，各 30 个新环境；另有 12 个不相交环境用于分支诊断。
- **对比方法**（共 34 个策略配置）：
  - 世界模型类：WM-BC V/VT、WM-RL V/VT（V 为纯视觉，VT 为视触觉）
  - 反应式类：BC V/VT、IQL V/VT
  - 控制器类：Script、FFB（力反馈）、Model+guard、Model、Reactive+guard、Reactive
- **评测指标**：联合力预算成功率 J / 严格举升 L / 力违规 V，三者分别报告，所有失败接近保留在分母中。
