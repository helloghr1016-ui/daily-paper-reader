## 摘要
视觉-语言-动作（VLA）策略通常在每个策略推理步骤都运行具有数十亿参数的视觉-语言模型（VLM）主干，这会带来延迟和能耗开销。我们重新审视一种用于多任务操作的解耦替代方案：将视觉和语言编码器分离，其表示用于条件化一个紧凑的动作头。我们进行了一项标准化比较，在固定演示数据、训练步数预算、任务、评估协议和测量平台的情况下，改变视觉编码器、语言编码器和动作头，并与七个 VLA 基线进行对比。由此得到的解耦具身模型（DEM）结合了微调的 DINOv3 视觉编码器、冻结的 NeoBERT 语言编码器，以及一个 MeanFlow 动作头，后者在一次前向传播中生成动作块。在 18 个 RoboCasa 任务上，使用留出的指令复述和随机化场景进行评估时，DEM 达到 55.6% 的平均成功率，而 GR00T N1.7 为 56.9%，π_{0.5} 为 54.6%；在三个真实机器人任务上，DEM 达到 66.0%，而 GR00T N1.7 为 68.0%。在同一工作站上，DEM 每次策略前向传播需要 6.1 ms，最大吞吐量为每秒 162.7 次策略调用，每次调用估计消耗 2.07 J 的 GPU 能量，相比这些 VLM 主干策略，吞吐量高 8 到 17 倍，能耗低 6 到 15 倍。在这一训练任务范围内，DEM 位于观测到的成功率—延迟—能耗前沿上，并为语言条件机器人技能提供了一个强大且高效的基线。

## Abstract
Vision-Language-Action (VLA) policies commonly run Vision-Language Model (VLM) backbones with billions of parameters at every policy inference, which costs latency and energy. We revisit a decoupled alternative for multi-task manipulation: separate vision and language encoders whose representations condition a compact action head. We run a standardized comparison that varies the vision encoder, the language encoder, and the action head while holding the demonstrations, the training-step budget, the tasks, the evaluation protocol, and the measurement platform fixed, against seven VLA baselines. The resulting Decoupled Embodiment Model (DEM) combines a fine-tuned DINOv3 vision encoder, a frozen NeoBERT language encoder, and a MeanFlow head that generates an action chunk in one forward pass. On 18 RoboCasa tasks evaluated with held-out instruction paraphrases and randomized scenes, DEM reaches 55.6\% mean success against 56.9\% for GR00T N1.7 and 54.6\% for $π_{0.5}$, and on three real-robot tasks it reaches 66.0\% against 68.0\% for GR00T N1.7. On the same workstation, DEM needs 6.1\,ms per policy forward pass, a maximum throughput of 162.7 policy calls per second, and draws an estimated 2.07\,J of GPU energy per call, eight to seventeen times the throughput and six to fifteen times less energy than these VLM-backbone policies. Within this trained-task regime, DEM sits on the observed success--latency--energy frontier and provides a strong, efficient baseline for language-conditioned robot skills.

# 论文总结：Decoupling Vision, Language, and Action for Efficient Multi-Task Robot Policies（DEM）

## 1. 核心问题与研究动机

- **背景**：当前主流 Vision-Language-Action（VLA）策略普遍把动作模块挂在一个数十亿参数的 VLM 主干上（OpenVLA、π 系列、GR00T 等），每次策略推理都要完整跑一遍 VLM，导致高延迟与高能耗。例如 π0.5 单次推理约需 100 ms。
- **痛点定位**：动作分块（action chunking）与异步执行只是"容忍"慢推理，并不缩短"感知→动作"的计算本身。底层操作任务要求 25–50 Hz 的响应频率且在能耗约束下运行，因此推理成本直接制约可部署性。
- **核心质疑**：在这种策略中，VLM 的主要作用只是提供图像与指令的**表征**，以条件化动作预测；而"生成语言"是 decoder-only VLM 的构造目标，并非该任务所需。
- **研究问题（刻意限定范围）**：当策略只需执行一组**固定的、已训练过的**语言条件操作技能时，用现代独立编码器替换联合融合的 VLM 主干，能保留多少成功率、节省多少推理成本？
- **整体含义**：作者重新审视早期解耦式通用策略（RT-1、Octo）的设计，指出其当年的瓶颈（编码器能力不足）已因 DINOv3、NeoBERT 等新一代独立编码器而改变，因而值得做一次标准化的实证检验。

## 2. 方法论

### 2.1 核心思想
- **DEM（Decoupled Embodiment Model）不跨模态共享主干**：视觉编码器、语言编码器、动作头是三个独立网络，其输出仅在动作头内部的**跨注意力**处汇合。
- 模块选择：DINOv3 ConvNeXt-B（视觉）+ NeoBERT（语言）+ MeanFlow（动作头），均由受控消融实验确定。

### 2.2 视觉通路
- 每帧图像经 DINOv3 ConvNeXt-B，取 **stage-3 特征图**：256 像素输入下为 16×16 网格、512 维特征，展平为每相机 256 个 token。
- 场景相机 + 腕部相机 ⇒ 每控制步 N_v = 512 个视觉 token。
- 编码器从公开 DINOv3 检查点初始化并**与动作头联合微调**（消融显示微调收益极大）。

### 2.3 语言通路
- 指令经 NeoBERT（加载时 222M 参数，encoder-only），填充/截断至 N_l = 32 token，保留最后一层**全部 token 的隐状态 + attention mask**，而非池化句向量。
- **语言编码器保持冻结**（微调未带来可分辨的成功率变化）。
- 关键设计优势：语言 token 的计算不依赖图像，因此**指令不变时可复用缓存**；指令变化时才重新编码。相比之下，联合融合的 VLM 中语言与图像 token 每步一起过共享主干，无法这样复用。

### 2.4 动作头：MeanFlow 单步生成
- 目标：一次前向生成动作块 a ∈ R^{H×A}。
- 标准 flow matching 学习插值路径 z_t = (1−t)a + tϵ 的瞬时速度 v，需要多步积分；**MeanFlow 改为学习区间 [r, t] 上的平均速度**：
  - u(z_t, r, t) = 1/(t−r) ∫_r^t v(z_τ, τ)dτ
  - 位移恒等式：z_r = z_t − (t−r)·u(z_t, r, t)
  - 对 t 求导得 MeanFlow 恒等式：u = v − (t−r)·(d/dt)u，网络 u_θ 被训练去满足它；沿插值路径 v = ϵ − a 有闭式解，全导数 (d/dt)u_θ 只需一次 Jacobian-vector product。
- 训练损失：L = E[ w·‖u_θ(z_t, r, t | C) − sg(v − (t−r)·(d/dt)u_θ)‖² ]，其中 sg 为停止梯度，w = (‖·‖² + c)^{−p} 为自适应权重（c = 10⁻³, p = 0.5），(r, t) 从 logit-normal 采样、以 **0.5 概率取 r = t**（MeanFlow 默认为 0.75），此时损失退化为标准 flow matching 以稳定训练。
- **推理仅一次前向**：â = ϵ − u_θ(ϵ, 0, 1 | C)。

### 2.5 模块组装（融合方式）
- 视觉 token V、语言 token L（带 mask m）、本体状态 q 各自线性投影到动作头宽度 d 并加**模态嵌入**，拼接为上下文 C ∈ R^{(N_v+N_l+1)×d}，本配置共 **545 个上下文 token**。
- 噪声动作块作为 H 个动作 token 输入：h⁽⁰⁾ = z_t W_a + P（可学习位置嵌入）；时间区间 (r, t) 通过时间嵌入 c 注入。
- 每个 DiT 风格块：先做动作 token 自注意力 + FFN，均由 c 经 **AdaLN** 调制；再以动作 token 为 query、上下文 C 为 key/value 做跨注意力：h^{(i+1)} = h̃ + g_i ⊙ CrossAttn(LN(h̃), C, m)，其中 g_i 为**零初始化**的逐通道门控，使每块初始为无条件去噪器，再学习读取场景与指令的程度。
- 配置：d = 768、D = 8 个块，动作头 **107M 参数**。
- 由于只有动作头消费 C，替换任一编码器只需改 W_v 或 W_l，所有消融变体可插入同一动作头。
