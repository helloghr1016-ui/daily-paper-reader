## Abstract 

Robots should adapt to unfamiliar environments and ac-quire new skills through interaction, then execute those skills efficiently with practice. Vision-language-action poli-cies provide efficient control, but often need additional hu-man demonstrations to handle unfamiliar settings; reason-ing agents can discover solutions using broad prior knowl-edge and robot-control APIs, but repeated deliberation and repair are costly. Inspired by human learning through reasoning and practice, we propose RoboEvo 2, a frame-work for recursive harness–policy co-evolution . In Policy-to-Harness (P2H) evolution, policy failures guide a cod-ing agent to search complementary Code, Code+ICL, and Code+Policy routes, consolidating verified solutions into reusable skills, routing strategies, and experience mem-ory. In Harness-to-Policy (H2P) evolution, verified tra-jectories provide supervised training, while Counterfactual Preference Distillation (CPD) teaches the policy to favor successful corrections over failures from the same starting state. The improved policy provides stronger motor skills for subsequent search, while its remaining failures redirect harness evolution, closing the reciprocal loop. Through recursive co-evolution without additional human demon-strations, RoboEvo 2 improves standalone success from 11.0% to 84.1% and hybrid success from 30.4% to 90.5% on LIBERO-PRO, with similar gains and reduced agen-tic costs on RoboTwin C2R. ## 1. Introduction 

Robots should adapt rapidly to unfamiliar environments, acquire new skills through interaction, and execute those skills efficiently with practice. Human learning moti-vates this progression from deliberate problem solving to fluent execution, while retaining the flexibility to tackle new situations. Current robot systems offer complemen-tary strengths toward this goal. Vision-language-action models (VLAs) [2, 3, 15, 45] and world action models (WAMs) [11, 13, 41] enable efficient visuomotor control, but remain vulnerable to task and scene shifts [30, 46]. Adapting them through imitation learning often requires collecting many additional human demonstrations, making continual skill acquisition costly. Foundation-model agents can draw on broad prior knowledge, reason about unfamil-iar situations, and invoke robot-control APIs to discover and refine solutions [10, 21, 43, 44]. However, repeated reason-ing, tool use, and repair introduce latency and API costs that limit reliance on agentic execution for routine behavior. Realizing this progression requires a reciprocal learn-ing loop between an agent’s harness —its executable skills, memory, and orchestration—and its low-level pol-icy. Harness-centered recursive self-improvement methods refine programs and accumulate experience through feed-back [9, 20, 32, 35], but keeping the motor policy fixed does not transfer newly acquired skills into the learned con-troller. Policy-centered methods use foundation models to guide autonomous data collection and improve learned con-trollers [12, 23, 47], but do not jointly adapt the harness to the controller’s changing abilities. Co-evolution must there-fore connect learning efficient policy behaviors from har-ness discoveries with adapting the harness to the improving policy . This reciprocity is essential because policy improve-ment changes both the motor skills available to the agent and the failures that still require exploration and repair. We introduce RoboEvo 2, a framework for recursive 

harness–policy co-evolution that uses current-policy fail-ures to drive both updates (Fig. 1). In Policy-to-Harness (P2H) evolution, a coding agent diagnoses failures, dis-covers verified corrections, and consolidates them into reusable skills, routing strategies, and persistent memory. In Harness-to-Policy (H2P) evolution, successful trajecto-ries and matched failure–correction pairs teach the policy to reproduce effective corrections and disfavor failed alterna-tives. The updated policy then supplies stronger motor skills for subsequent agentic search, while its remaining failures redirect harness refinement. Concurrent studies also investi-gate harness–policy coupling [4, 7, 34, 36]. RoboEvo 2 con-nects failure-guided, multi-route solution discovery with explicit learning from matched failures and corrections, progressively reducing repeated agentic intervention as ac-quired skills are internalized into the policy. 

First, to discover complementary capabilities, we de-velop a failure-conditioned, multi-route P2H repair engine. 

For each policy failure, it searches three solution routes in parallel: Code refines control programs, Code+ICL in-corporates demonstration guidance, and Code+Policy com-poses programs with learned motor skills. Execution feed-back drives iterative repair, and the successful candidate with the lowest normalized motion jerk is selected under matched conditions. This design combines complementary control capabilities to generate verified, smooth corrections targeted at current policy weaknesses. 

Second, to internalize corrective capabilities, we intro-duce Counterfactual Preference Distillation (CPD). CPD pairs failed and corrected continuations from the same start-ing state and optimizes a margin between their action-prediction losses relative to a frozen reference policy. Asymmetric proximity penalties discourage degradation of corrective behaviors and excessive suppression of failed al-ternatives. Combined with supervised learning on verified trajectories, CPD teaches both which corrections to repro-duce and which failed alternatives to disfavor. Failure-aware sampling and continual-learning regularization sup-port targeted acquisition and capability retention. 

Third, to sustain iterative capability reuse, we develop a harness update mechanism coupled with policy reuse across rounds. Compatible repairs update executable skills and routing logic, while persistent memory retains failure con-texts, attempted solutions, and validated guidance. The up-dated policy then drives subsequent rollouts and participates in Code+Policy search, changing both the failures requir-ing exploration and the motor primitives available for re-pair. This closes the reciprocal loop: accumulated harness knowledge supports correction discovery, while internal-ized policy capabilities directly support subsequent search. Experiments demonstrate recursive adaptation to dis-tribution shifts without additional human demonstrations. Across eight rounds on LIBERO-PRO [46] and five rounds on RoboTwin C2R [5], standalone success improves from 11.0% to 84.1% and 46.0% to 77.5%, respectively, with hybrid success reaching 90.5% and 87.4% alongside re-duced agentic API expenditure. On RoboTwin C2R, our method with 7.5K trajectories matches conventional train-ing with 27.5K trajectories. Ablations validate recipro-cal co-evolution, complementary solution routes in P2H, and counterfactual preference distillation in H2P. We fur-ther demonstrate autonomous task acquisition on Mol-moSpaces [16] and cross-embodiment harness transfer. On the Unitree G1-D, a simulation-evolved harness en-ables the collection of 120 demonstrations, yielding 85.0% 2standalone success compared with 80.0% using 200 hu-man demonstrations, while fixed-harness hybrid execution reaches 95.0%. 

## 2. Related Work 

Continual Robot Learning. A continually learning pol-icy must retain earlier skills and obtain supervision for new ones. For retention, EWC regularizes weights [17], ER re-plays data [29], and PackNet isolates parameters [27]. In manipulation, LOTUS builds skill libraries [33] and TAIL uses task-specific adapters [25]. On pretrained VLAs, expe-rience replay mitigates forgetting [24, 48]; PHASER refines it by prioritizing phases most at risk of forgetting [6], while CRL-VLA limits advantage magnitudes on prior tasks dur-ing continual RL [42]. For new supervision, HG-DAgger and RECAP draw on human interventions during policy rollouts [1, 14], APO and FlowPRO turn such interven-tions into preference signals [38, 39], and SOAR uses au-tonomous VLM-guided practice [47]. RoboEvo 2 learns from verified harness repairs of policy failures rather than operator corrections, and employs failure-aware task sam-pling to retain skills and improve low-success tasks. 

Agentic Self-Improvement. Agentic systems such as Code as Policies [21], Harness VLA [44], RATs [43], and AS-PIRE [26] solve tasks through programs, skills, and mem-ory without model fine-tuning. Among recursive self-improvement (RSI) frameworks, Zetta, EmbodiedEvo, Em-bodiedRSI, and RPG evolve only the harness [9, 20, 32, 35], whereas ENPIRE and EmbodiRSI focus on policy improve-ment [18, 40]. Co-Harness and Self-HPO alternate harness and model updates for LLM agents [7, 37]. AdaRSI [34] refines its harness and fine-tunes only sub-steps that still fail when retried from saved states. However, these meth-ods train the policy only to imitate successful executions. In contrast, RoboEvo 2 also learns from failures: it pairs a failed continuation with a verified repair from the same state and trains the policy to prefer the repair. Repairs are sought in parallel along code-only, demonstration-guided, and policy-calling routes. 

## 3. RoboEvo 2

3.1. Overview of Recursive Co-Evolution 

RoboEvo 2 is a policy-driven framework for recursive harness–policy co-evolution. The current policy exposes capability gaps through execution failures, the harness dis-covers effective solutions, and the policy subsequently internalizes these corrections. As illustrated in Fig. 2, RoboEvo 2 jointly evolves an agentic harness Hr =(Lr , M r , ρ r ) and a neural policy πθr at evolution round r.The harness consists of an executable skill library Lr ,persistent experience memory Mr , and a routing mecha-nism ρr for skill invocation and code–policy coordination. We initialize H0 with robot APIs and parameterized code-based skills from CaP-X [10] and RATs [43]. The initial policy πθ0 is obtained by fine-tuning a pretrained VLA or WAM on robot demonstrations D0.Each evolution round r consists of four stages: 

(1) Policy Rollouts. The current policy πθr serves as the primary executor, generating task rollouts Tr . Task-level verification partitions them into successful trajectories Sr

and failed trajectories Fr . The failures identify where addi-tional capabilities are needed. 

(2) Policy-to-Harness Evolution (P2H). For each failed rollout, a VLM-based coding agent (GPT-6 Astra) di-agnoses the failure and searches for solutions through three complementary routes: Code, Code+ICL, and Code+Policy. Verified solutions are selected based on exe-cution quality, and compatible improvements are integrated across failures into a candidate harness eHr+1 . Execution and repair experiences are retained for subsequent reuse (Sec. 3.2). 

(3) Harness-to-Policy Evolution (H2P). Successful policy rollouts and harness-generated corrections are accumulated as training data. Matched successful and failed executions further provide counterfactual supervision. Task-balanced, failure-aware sampling and policy optimization produce an updated candidate policy πeθr+1 (Sec. 3.3). 

(4) Evaluation and Selection. We evaluate two execution modes: standalone , where the policy executes tasks inde-pendently, and hybrid , where the harness coordinates policy execution with reusable code skills. Candidate and previ-ous versions are compared on matched development tasks, initial states, and execution budgets. Updates are retained when they improve the corresponding success rates; oth-erwise, previous versions are preserved. The selected pair 

(Hr+1 , π θr+1 ) enters the next round. Further details are provided in Appendix D. By repeatedly discovering and internalizing missing ca-pabilities, RoboEvo 2 forms a recursive improvement loop driven by the evolving policy’s remaining failures.

Rather than relying on the coding agent to solve tasks independently from scratch, P2H targets failed policy executions and converts successful corrections into reusable harness capabilities. Given Fr , it first searches for solutions to individual failures and then consolidates the verified results across tasks. 

Failure-Guided Solution Search and Selection. For each failed rollout f ∈ F r , a VLM-based coding agent diag-noses the failure using policy observations, action history, and task outcomes. 3.4. Standalone and Hybrid Execution Modes 

RoboEvo 2 supports two complementary execution modes that balance policy autonomy and agentic assistance: • Standalone Execution: The co-evolved policy executes tasks directly without coding-agent intervention, enabling efficient neural inference while leveraging capabilities ac-quired from agentic corrections. • Hybrid Execution: An embodied agent coordinates the co-evolved policy with reusable code skills, support-ing explicit task decomposition, skill composition, and feedback-driven recovery [44]. Through recursive co-evolution, policy failures drive the discovery of new executable capabilities, while agentic cor-rections are progressively internalized into the policy. As the policy improves, its evolving capability gaps guide sub-sequent harness evolution, forming a self-reinforcing cycle of discovery and learning. This process aims to amortize costly agentic reasoning into efficient policy execution, pro-gressively reducing reliance on agentic assistance while re-taining the harness for unresolved challenges. 

## 4. Experiments 

We evaluate RoboEvo 2 on LIBERO-PRO [46] and RoboTwin C2R [5] for multi-round co-evolution and gen-eralization to unseen perturbations, with ablations exam-ining reciprocal evolution, P2H solution routes, and CPD. 5MolmoSpaces [16] evaluates autonomous capability acqui-sition, while cross-embodiment and Unitree G1-D experi-ments demonstrate harness reusability, sim-to-real transfer, and real-world policy learning. 

4.1. Generalization and Multi-Round Evolution 

We evaluate RoboEvo 2 on two benchmarks under distribu-tion shifts. LIBERO-PRO [46] transfers policies trained on original LIBERO demonstrations to task and position per-turbations, while RoboTwin C2R [5] adapts policies trained on 2,500 clean demonstrations to randomized scenes across 50 bimanual tasks. On both benchmarks, evolution runs on seeds held out from the initial training data without ad-ditional human annotation, and generalization is evaluated on separate unseen seeds (800 LIBERO-PRO and 5,000 RoboTwin C2R episodes; Appendix D). 

Multi-Round Adaptation and Data Efficiency. Figure 3 demonstrates progressive improvements in standalone and hybrid execution. On LIBERO-PRO, eight rounds improve standalone success from 11.0% to 84.1% and hybrid suc-cess from 30.4% to 90.5%, while API expenditure de-creases from $430.63 to $98.92. On RoboTwin C2R, five rounds increase standalone success from 46.0% to 77.5% and hybrid success from 48.8% to 87.4%, with API ex-penditure decreasing from $719.05 to $323.84. These re-sults demonstrate sustained capability improvement along-side decreasing agentic costs, highlighting the benefits of recursive harness–policy co-evolution. Beyond execution efficiency, RoboEvo 2 acquires train-ing experience without additional human demonstrations. As shown in Tab. 1, starting from 2,500 clean demon-strations, our framework autonomously collects 5,000 ver-ified trajectories and achieves 77.5% standalone success on RoboTwin C2R. With the same 7.5K trajectories, clean+random training reaches only 67.2%, and it needs 27.5K to reach 76.8%. RoboEvo 2 thus matches it with only 27.3% of the training data, suggesting that failure-driven experience provides effective supervision.

Harness Transfer and Autonomous Data Collection. Using its frozen Code route, the transferred harness collects 10 veri-fied demonstrations per task. We first fine-tune π0.5 on these trajectories and execute the resulting policy on the physi-cal robot. When execution fails, an operator approximately restores the robot and scene to the pre-failure state, with-out teleoperating the corrective actions. The agent then ex-plores Code, Code+ICL, and Code+Policy routes, selecting verified corrections with the lowest normalized motion jerk. ## 5. Conclusion 

We presented RoboEvo 2, a framework for failure-driven re-cursive harness–policy co-evolution. Through complemen-tary solution discovery (P2H) and counterfactual capability internalization (H2P), verified agentic corrections become reusable harness skills and learned policy behaviors. Across rounds, the improved policy provides stronger motor prim-itives and redirects subsequent harness exploration, closing the reciprocal learning loop. Experiments demonstrate pro-gressive improvements in standalone and hybrid execution with reduced agentic costs, alongside data-efficient adapta-tion, autonomous task acquisition, cross-embodiment reuse, and real-world policy learning. A.1. Agent, Skill Library, Memory, and Routing 

Coding agent. The agent is GPT-6 Astra (gpt-6-astra ), run with reasoning effort xhigh ;it is used both for coding and for demonstration video analysis. Each coding call receives the task instruction, recorded camera frames, the localized failure, retrieved memory entries, and the editable skill programs, and returns a program revision; the prompts are given in Appendix E. After each round we save the accepted code, memory, policy checkpoint, and data manifest. 

Skill library. The skill library Lr holds only executable code, separate from memory Mr and routing ρr . It is or-ganized as a two-level skill tree. At the bottom are atomic skills : observing, gripper commands, relative motions, mo-tions to a target anchored at an image pixel, and policy calls, which only Code+Policy may use. Above them are compos-ite skills , each composed from atomic skills and parameter-ized by its arguments, such as grasping, placing, transfer-ring, pulling, and stroking along a surface. A program calls skills by name with arguments. Extending Lr adds a new entry, and refining a skill writes a new revision of its entry while earlier revisions are kept. Figure 6 shows how general skills are specialized and how memory grows on LIBERO-PRO. 

Memory. Memory Mr has two parts. General memory holds lessons that apply across tasks, grouped by skill cat-egory (perception, grasping, placing, contact, policy, and motion and planning). Experiences are learned from indi-vidual tasks: each entry states when it applies, the action to take, and the skills it uses, and is retrieved by matching the task instruction. An experience that holds across tasks is promoted to general memory (Fig. 6). 

Routing. Routing ρr is a set of rules in the agent’s in-structions rather than a separate model. In hybrid execution, code staging precedes each policy call, and after the call the agent re-observes before choosing the next step. Updat-ing ρr edits these rules. ## E. Agent Prompts 

The agent uses two prompts: the execution prompt writes and revises programs from the current views, and the evolu-tion prompt modifies the harness itself (skills, memory, and routing rules) from recorded failures.

## H. Limitations 

RoboEvo 2 composes and revises skills on top of a fixed set of atomic skills and perception tools, which do not yet cover capabilities such as force-controlled contact or in-hand re-grasping. Future work can enlarge this initial library with such primitives, which the agent can then compose and re-vise like the existing ones. A task-level success check se-lects the executions that train the policy; the VLM check that repaired skills already use could replace it, at the cost of extra model calls. 19
