## 摘要
可负担性引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（例如固定接触点），在机器人操作任务中展现了令人印象深刻的表现。然而，常用的静态可负担性在精度关键任务或目标位置扰动下可能变得不一致，导致接触后轨迹漂移。为解决这一问题，我们提出AffordTrajDP，一种动态框架，通过以物体为中心的时序传播构建可负担性轨迹，以引导渐进式操作过程。具体而言，给定RGB-D观测，我们的核心见解是：检索到的锚定可负担性（捕捉末端执行器与目标物体之间期望接触点）可以通过可负担性传播，利用物体的SE(3)位姿作为自然的传播媒介，向前传播以产生可负担性轨迹，从而在整个执行过程中提供时序一致、状态感知的引导。AffordTrajDP在ManiSkill3上实现了70.0%的平均成功率，比强基线高出最多17.8%。在Galaxea A1和UR7e机械臂上的真实世界实验，涵盖StackCube、PickCup、AdapterInsertion、Ring-on-Peg、Put-in-Bowl和USB Insertion，进一步验证了在物体放置变化和外观变化下的鲁棒性，并在Galaxea A1上评估了可见与未见物体实例，消融实验确认了每个提出组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

## 1. 核心问题与整体含义

- **研究动机**：现有的可负担性（affordance）引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（如固定接触点）来提升机器人的操作表现，但这些约束通常是**静态的**。
- **核心问题**：静态可负担性在**精度关键任务**（如插入、对接）或**物体位置扰动**下会与物体实际状态逐渐失配，导致接触后轨迹漂移和操作失败。
- **整体含义**：论文提出，成功操作需要同时保留两种信息——**在哪里接触（where to contact）** 与**接触后如何随时间演化（how the contact evolves）**。现有方法要么只提供语义接触点，要么只提供物体位姿轨迹，均不完整。
- **解决方案**：提出 **AffordTrajDP**，通过以物体为中心的时序传播，将锚定接触点沿预测的 SE(3) 位姿轨迹传播，生成动态的可负担性轨迹，为策略提供状态一致、时间一致的引导。

## 2. 方法论

### 2.1 核心思想

- 以检索到的**锚点可负担性**（目标表面上期望的接触点）为起点。
- 利用物体自身的 **SE(3) 位姿变化**作为自然传播媒介，将接触点向前传播，得到未来一段时间的接触点序列（即可负担性轨迹）。
- 该轨迹作为条件信号输入扩散策略，使策略在接触后仍能跟踪物体运动，避免漂移。

### 2.2 关键技术细节

- **锚点可负担性生成**：
  - 使用 GroundedSAM 分割目标物体区域，用 CLIP 提取外观特征。
  - 在物体记忆库中按任务标签和余弦相似度检索最相似的源实例。
  - 通过源/目标之间的密集视觉对应，将源接触点转移到目标物体上，得到目标接触点 c_tgt（3D 坐标）。

- **未来位姿预测**：
  - 用 FoundationPose 从演示中提取物体 6D 位姿轨迹，以目标物体坐标系为参考（消除绝对场景布局差异）。
  - 训练一个扩散模型（DDIM 确定性采样）预测未来 H 步的 SE(3) 位姿轨迹，条件为当前位姿历史。
  - 位姿以平移+四元数表示，扩散去噪后对四元数重新归一化。

- **可负担性传播**：
  - 将锚点接触点通过预测位姿进行刚性变换：`p_{t+k} = T_{t+k} * c_tgt`，得到动态可负担性轨迹 `τ = [p_t, ..., p_{t+H}]`。
  - 该轨迹与静态接触点一起构成策略的条件。

- **动作生成**：
  - 静态接触点由 MLP 编码，动态轨迹由 Transformer（含 [CLS] token）编码。
  - 行动策略采用 DDIM 扩散模型，从噪声中迭代去噪生成动作序列，并采用滑动窗口（预测 16 步，执行 8 步）的闭环控制。
