## 摘要
键-键槽装配任务具有严格的几何约束，并且在不确定环境中对抓取位姿偏差高度敏感。这项工作提出了一种用于带键轴孔装配的基于力的偏移估计方法，并将其嵌入感知-验证-插入流程中。残余失准直接根据腕部力/力矩测量值，使用局部 KNN-高斯过程混合回归器进行估计。该框架区分两种接触状态，即硬碰撞和引导倒角插入，并将推理路由到各自的专用模型。状态分类通过接触窗口持续时间阈值实现。KNN 结合利用抓取后单目视觉验证结果的确定性搜索，有助于提高回归器模型的精度。该方法在基于关键点检测的抓取放置应用中，实现了倒角轴插入中的精确径向偏移估计。使用协作机械臂集成力/力矩传感器进行的实验表明，应用该流程后，插入成功率从 67% 提高到 87%。

## Abstract
Key-keyway assembly tasks impose strict geometric constraints and are highly sensitive to grasp pose deviations in uncertain environments. This work presents a force-based offset estimation method for keyed peg-in-hole assembly, embedded within a perception-validation-insertion pipeline. Residual misalignment is estimated directly from wrist force/torque measurements using a local KNN-Gaussian Process hybrid regressor. The framework distinguishes between two contact regimes, hard collision and guided chamfer insertion, and routes inference to a dedicated model for each. Regime classification is achieved via a contact-window duration threshold. KNN combined with a deterministic search using the results of a post-grasp monocular visual validation contributes to an increased accuracy of the regressor model. This approach achieves accurate radial offset estimation in chamfered peg insertion, during a keypoint detection-based pick and place application. Experiments using the integrated force/torque sensor of a collaborative robot arm showed an increase in insertion success rate from 67% to 87% after the pipeline was applied.

## 2. 方法论

### 2.1 核心思想

- 构建三阶段流水线：
  1. **预抓取位姿估计**：YOLOv8 关键点检测 + 碰撞感知抓取规划。
  2. **抓取后平面位姿验证**：基于 IBVS 的 SE(2) 平面调节，得到度量校正量。
  3. **基于 F/T 的轨迹校正**：用局部 KNN–GP 回归从腕部力/力矩特征估计残余平面偏移，并重参数化插入轨迹。
- 将接触状态分为两类并分别建模：
  - **引导插入（guided insertion）**：偏移小于倒角径向捕获范围，倒角持续接触，产生持续力签名。
  - **硬碰撞（hard collision）**：偏移超过倒角径向长度，圆盘撞击轴边缘，机器人因力限停止，产生短时瞬态接触。
- 状态分类依据**接触窗口持续时间阈值**：硬碰撞接触数据行 <100，完整引导插入 ≥100 行；同时结合力阈值 \(F_{th}=30\text{ N}\) 路由。

### 2.2 关键技术细节

- **预抓取位姿估计**：
  - 自定义 YOLOv8 姿态模型预测边界框与 2D 关键点 \(k_1\)–\(k_4\)，其中三个结构参考点、一个键槽特征点。
  - 孔中心 \(c_h\) 为结构关键点均值；抓取方向 \(l_{grasp}\) 为质心到键槽关键点的向量。
  - 检查夹爪对偶轴与邻近边界框是否碰撞，若碰撞则迭代旋转 \(\Delta\theta\) 直到可行，得到 \(T_{pre-grasp}\)。

- **抓取后平面位姿验证（IBVS）**：
  - 不重新估计完整 SE(3) 位姿，而是做任务约束的 SE(2) 平面调节。
  - 机械臂移动到外部标定相机上方预设路点，相机光轴与 TCP 对齐。
  - 收敛条件：\(|\Delta u| \le 4\) 像素，\(|\Delta v| \le 4\) 像素，\(|\Delta\gamma| \le 0.5^\circ\)。
  - 定义 \(T_0\) 为 IBVS 起始 TCP 位姿，\(T_f\) 为收敛位姿，则验证后的平面校正为：
    \[
    T_{post-grasp}=T_0^{-1}T_f
    \]
  - 由于该变换来自编码器测量的位移，具有度量意义，利用现代机械臂的亚毫米重复精度。

- **接触力特征表示**：
  - 对每个 F/T 通道 \(c\)，在接触窗口 \(N_{contact}\) 内提取 5 个统计量：均值、RMS、最大值、最小值、标准差。
  - **引导插入**：使用全部 6 个通道，形成 30 维特征 \(f_{ins}\)。
  - **硬碰撞**：仅使用 \(\tau_x,\tau_y\)，形成 10 维特征 \(f_{col}\)。
  - **角偏移**：使用 \(f_{col}\)；当 \(\varphi_{off}\) 接近临界角 \(\varphi_{crit}\) 后，键–键槽碰撞不再产生显著力签名，需重新执行抓取后视觉验证。
  - 力/力矩通道直接编码接触力臂信息；引导插入中倒角持续施加径向腕力，可用于验证插入成功与偏移充分性。

- **局部 KNN–GP 混合回归**：
  - GP 建模非线性映射：
    \[
    \Delta r = g(f) + \epsilon,\quad g(f)\sim GP(\mu(f),k(f,f'))
    \]
  - 核函数采用带自动相关确定（ARD）的平方指数核。
  - 全局 GP 在稀疏区域存在平滑偏差，因此对每个查询 \(f^*\)，在归一化力空间中检索 \(k=30\) 个最近邻，仅在该子集上拟合局部 GP，分别对 \(\Delta r\) 的平面分量进行推断。
  - 邻居检索仅基于力特征空间；IBVS 得到的偏移估计 \(T_{post-grasp}=p_{xy}\) 作为 GP 的信息先验/均值先验，模型预测相对于该估计的残差校正。
  - 预测在 \(k\in\{10,15,30\}\) 下保持稳定，说明力–偏移映射具有局部平滑性。

- **轨迹重参数化**：
  - 最终预测偏移 \(\hat{\Delta r}\) 作为补充平移校正：
    \[
    T_{pred} = (T_{shaft}T_{post-grasp})
    \begin{bmatrix}
    I_{3\times3} & \hat{\Delta r}\\
    0 & 1
    \end{bmatrix}
    \]
  - 在接触时刻、轴位姿 \(T_{shaft}\) 处实现确定性轨迹重参数化。
  - 当预测校正超过倒角捕获阈值 \(|e_{pred}|>d_{chamfer}\) 时，系统回退到最近邻偏移与均值先验，保证稳定校正。

- **算法流程（Algorithm 1）**：
  1. 移动到预插入位姿 \(T_{shaft}\)。
  2. 开始采集 F/T 数据。
  3. 沿 TCP z 轴执行名义插入，监测滚动特征窗口。
  4. 若 \(F_z>F_{th}\) 检测到接触，停止运动，提取 \(N_{contact}\)。
  5. 计算 \(T_{pred}\)，沿插入轴回退，更新插入轨迹 \(p'(s)=p+T_{pred}+sz\)。
  6. 沿重参数化轨迹继续插入，直到成功或达到最大重试次数。
