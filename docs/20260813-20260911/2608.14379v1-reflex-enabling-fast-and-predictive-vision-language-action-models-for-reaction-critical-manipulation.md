## 摘要
视觉-语言-动作（VLA）模型最近在机器人操作中取得了令人鼓舞的性能。然而，现有基准主要评估静态操作任务上的泛化能力，而在很大程度上忽视了动态交互场景。为弥补这一不足，我们提出了 ReflexBench，一个用于反应关键型操作的基准。ReflexBench 包含六个动态任务，并引入了一个评估框架，将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于 ReflexBench，我们提出了 ReflexVLA，一种高效的 VLA 模型，专为反应关键型操作设计，无需大规模机器人数据预训练。ReflexVLA 通过在视觉骨干网络中进行潜在未来预测和多帧时序融合来增强时序推理能力，同时通过批量视觉编码和 CUDA Graph 重放来降低部署延迟。实验表明，ReflexVLA 持续提升了动态操作性能，同时在标准静态操作基准上保持了具有竞争力的精度，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 2. 论文提出的方法论

### 2.1 ReflexBench：反应关键型操作基准

- 包含 **6 个动态操作任务**：
  - 传送带抓取与放置（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚球拦截（Rolling Ball Interception）
  - 抛球入筐（Ball Throwing）
  - 旋转销插入（Rotating Peg Insertion）
- 评估框架特点：
  - **解耦模拟器步进与机器人控制**，使环境动态独立于策略计算演进。
  - 支持**同步推理**（阻塞直到推理完成）和**异步推理**（推理与执行重叠）。
  - 支持**可配置推理延迟**，并可通过现实世界推理延迟和实时因子（RTF）换算为仿真延迟。
  - 数据收集采用规划流水线：将任务分解为子阶段、对动态物体进行未来轨迹预测，必要时使用任务特定强化学习策略生成演示。

### 2.2 ReflexVLA 模型

ReflexVLA 基于紧凑的 VLA 架构（如 VLA-Adapter）构建，包含三个核心设计：

#### （1）潜在未来预测（Latent Future Prediction）

- 不直接预测未来图像，而是在**冻结的 DINOv3 视觉编码器**的语义潜在空间中预测未来观测。
- 对每个训练样本，提供未来观测序列 \( \{o_{t+i}\}_{i=1}^H \)，用冻结 DINOv3 编码得到 \( y_{t+i} \in \mathbb{R}^{1024} \)。
- 在输入序列中附加 \( H \) 个可学习的 future tokens，预测输出 \( \hat y_{t+i} = f_{\text{pred}}(h^{\text{future}}_i) \)。
- 使用**掩码余弦相似度损失**训练：
  \[
  \mathcal{L}_{\text{future}} = \frac{\sum_{i=1}^{H} m_i [1 - \cos(\hat y_{t+i}, y_{t+i})]}{\sum_{i=1}^{H} m_i}
  \]
- 联合优化动作损失：
  \[
  \mathcal{L} = \mathcal{L}_{\text{act}} + \lambda_{\text{future}} \mathcal{L}_{\text{future}}
  \]
- 预测水平 \( H \) 与动作块大小一致，使未来预测与动作生成的时序结构对齐。

#### （2）多帧时序融合（Multi-Frame Temporal Fusion）

- 在视觉骨干网络内部对多个历史帧进行时序融合，只将当前帧的融合表示送入语言模型，避免语言模型侧视觉 token 数量增加。
- 对每个视角和每个 patch 位置，将 \( T \) 帧中间层特征形成时序轨迹，经 LayerNorm、降维、加入时序位置嵌入，然后做**因果时序注意力**。
- 融合后的增量特征加到当前帧的最终视觉特征上，得到当前帧的时序增强表示。
- 使用中间层特征而非最终层特征，保留更丰富的运动线索。

#### （3）推理延迟优化（Inference Latency Optimization）

- **批量视觉编码**：将所有视角和所有历史帧图像合并为一次视觉编码前向，减少框架开销，提高 GPU 利用率。
- **CUDA Graph 重放**：捕获完整推理计算图（视觉编码、时序融合、多模态投影、语言模型推理、动作预测），在部署时直接重放，消除重复的 kernel 调度和运行时开销。
- 这些优化不改变模型架构或训练目标，仅降低部署延迟。

## 3. 实验设计

### 数据集与场景

- **ReflexBench**：6 个动态操作任务，每个任务 200 个演示 episode，所有 VLA 策略在相同数据集上训练为单一策略。
- **LIBERO**：标准静态操作基准，用于评估静态任务上的泛化能力。
- **真实世界实验**：在 AgileX Piper 机械臂上，选择 3 个动态操作任务：传送带抓取与放置、按按钮、接球。

- 轻量级模型：VLA-Adapter（1B，作为 ReflexVLA 的骨干基线）、SmolVLA（0.5B）

- 大规模 VLA 模型：OpenVLA-OFT（7B）、π0.5（4B）

- 所有策略使用异步推理、动作块大小 8、动作执行水平 2。
- 在单张 NVIDIA RTX 5880 Ada GPU 上评估。
- 每个任务 150 个评估 episode，取 3 个随机种子的均值和标准差。

## 6. 论文的主要结论与发现

- **异步推理 + 大动作块 + 短动作执行水平**在 30 Hz 推理频率下通常取得最佳性能（Q1）。
- ReflexVLA 在 ReflexBench 上取得 **50.4% 平均成功率**，超过所有对比基线，且仅使用 1B 参数；相比其骨干 VLA-Adapter（30.3%）提升显著；性能接近 4B 的 PUMA。
- ReflexVLA 在 LIBERO 静态基准上取得 **97.2% 平均准确率**，与最佳 VLA 相当，表明动态增强设计没有损害静态任务泛化。
- 消融实验表明：
  - 使用**冻结 DINOv3 目标**的未来预测显著优于可训练目标（62.8% vs 4.9%）。
  - **中间层时序融合**优于最终层融合（71.7% vs 68.2% 等）。
  - 增加延迟优化后，成功率提升至 73.8%，同时推理延迟从 125.1 ms 降至 65.0 ms。
- 真实世界实验中，ReflexVLA 在三个动态任务上优于 SmolVLA，并在参数远小于 PUMA 的情况下取得相当或更好的性能。

## 7. 优点

- **问题定位清晰**：明确指出动态操作中“预测能力”和“推理延迟”往往被割裂研究，提出统一框架。
