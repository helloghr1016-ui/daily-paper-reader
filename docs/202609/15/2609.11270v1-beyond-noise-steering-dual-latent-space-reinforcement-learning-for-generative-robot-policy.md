## 摘要
预训练的生成式机器人策略能够从演示中学习具有表现力的动作先验。然而，现有强化学习方法仅引导噪声空间，而未能调节生成过程中的中间动作表示，导致性能下降和效率低下。为解决这一局限，我们提出了一种新颖的双潜在空间强化学习（DLSRL）框架，该框架通过冻结生成器内部的表示级控制来补充初始噪声引导。具体而言，我们的 actor 网络预测两个不同的潜在变量：一个用于引导行为生成的初始噪声潜在变量，以及一个用于中间特征调制的动作表示潜在变量。此外，该表示潜在变量被映射为适配器特征，并通过残差连接巧妙地注入到中间动作 token 的隐藏状态中。我们的双重控制设计能够在不更新基础策略的情况下直接调整动作表示。在多种生成式策略架构和机器人操作任务上的实验表明，DLSRL 有效加速了在线机器人策略自适应，并取得了具有竞争力的性能。我们的代码可在 https://github.com/xianchaoxiu/DLSRL 获取。

## Abstract
Pretrained generative robot policies learn expressive action priors from demonstrations. However, existing reinforcement learning methods only steer the noisy space but fail to modulate intermediate action representations during the generation process, resulting in performance degradation and inefficiency. To address this limitation, we propose a novel Dual-Latent Space Reinforcement Learning (DLSRL) framework, which complements initial-noise steering with representation-level control inside the frozen generator. Specifically, our actor network predicts two distinct latent variables: an initial-noise latent variable that steers behavior generation, and an action-representation latent variable for intermediate feature modulation. Moreover, this representation latent variable is mapped to adapter features and ingeniously injected into the hidden states of intermediate action tokens via residual connections. Our dual-control design enables direct adjustment of action representations without updating the base policy. Experiments across generative policy architectures and robotic manipulation tasks show that DLSRL effectively accelerates online robot policy adaptation and achieves competitive performance. Our code is available at \href{https://github.com/xianchaoxiu/DLSRL}{https://github.com/xianchaoxiu/DLSRL}.

## 2. 方法论

### 2.1 核心思想

- 将传统噪声空间 RL 的 actor 扩展为**双潜在 actor**，同时输出：
  - 初始噪声潜变量 \(z_t\)：控制生成起点，影响整体行为模式。
  - 动作表征潜变量 \(u_t\)：用于中间特征调制，提供表示级控制。
- 基座生成策略 \(G_\phi\) 全程冻结，仅训练轻量外部控制模块。

### 2.2 关键技术细节

- **双潜在 actor**：\((z_t, u_t) \sim \pi_\theta(\cdot \mid o_t)\)，其中 \(o_t = (I_t, q_t, \ell)\) 为视觉、本体状态与语言指令构成的观测。
- **适配器特征映射**：\(f_t = A_\omega(u_t)\)，将 \(u_t\) 映射为与动作 token 隐状态同形状的适配器特征 \(f_t \in \mathbb{R}^{N_a \times d_h}\)。
- **残差注入**：在选定的冻结 Transformer 块输出处，将适配器特征按注入强度 \(\lambda_{\text{inj}}\) 缩放后残差加入动作 token 隐状态：
  - \(\tilde{H}^{(l)}_{t,k} = H^{(l)}_{t,k} + \delta_t\)，其中 \(\delta_t = \lambda_{\text{inj}} f_t\)
  - 仅作用于动作 token 位置，不修改视觉、语言、本体等上下文 token。
  - 同一 \(f_t\) 在选定的多个 Transformer 块和生成更新步间共享。
- **动作生成**：\(a_t = G_\phi(o_t, z_t, f_t)\)，同时适用于扩散策略（\(k\) 索引反向去噪步）与流匹配策略（\(k\) 索引离散积分步）。

### 2.3 双潜在策略优化（算法流程）

- 维护两个仅训练时使用的 critic：
  - **动作空间 critic** \(Q^{\text{act}}_\psi(o_t, a_t)\)：用标准 off-policy TD 学习，估计动作块期望回报。
  - **潜在空间 critic** \(Q^{\text{lat}}_\nu(o_t, z_t, f_t)\)：通过值蒸馏目标学习：
    - \(\mathcal{L}_{\text{distill}} = \mathbb{E}\left[\left(Q^{\text{lat}}_\nu(o_t, \hat{z}_t, \hat{f}_t) - \text{sg}[Q^{\text{act}}_\psi(o_t, \hat{a}_t)]\right)^2\right]\)
    - 蒸馏时梯度仅回传至 \(\nu\)，不穿透冻结生成过程。
- **Actor 更新**：熵正则化目标，熵正则仅施加于初始噪声分支：
  - \(\mathcal{L}_{\text{actor}} = \mathbb{E}\left[\alpha \log \pi^z_\theta(z_t \mid o_t) - Q^{\text{lat}}_\nu(o_t, z_t, f_t)\right]\)
  - 潜在空间价值对 \(z_t\) 和 \(f_t\) 的梯度会同时传播至两个 actor 分支与适配器映射器。
- **交替更新**：动作空间 critic、潜在空间 critic、双潜在 actor 与适配器映射器交替优化，基座参数 \(\phi\) 冻结。
- **部署**：仅保留双潜在 actor 与适配器特征映射器，丢弃两个 critic。

- **加速在线适应**：DLSRL 在 RoboMimic 的 Lift、Can、Square 以及 LIBERO 六个任务上均表现出更快的早期与中期性能提升，通常以更少的环境交互达到饱和性能。
