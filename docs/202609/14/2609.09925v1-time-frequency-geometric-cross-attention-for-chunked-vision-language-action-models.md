## 摘要
现代视觉-语言-动作（VLA）策略会预测一整块动作：在一次前向传播中输出一到两秒的协调运动。然而，一个动作块本质上是一段短时多元轨迹，但在这些模型内部，它却是由线性解码头解码的、通用的逐时间步隐藏 token 序列。这导致两类运动结构未被充分建模。第一，频率：一个动作块叠加了平滑的全局趋势与跨时间尺度的精细修正运动，而单个 token 会将二者纠缠在一起。第二，跨相位几何：不同相位（接近、接触、抓取调整、稳定）的运动在表示空间中沿非常不同、近乎正交的方向展开，但它们在任务上紧密相关，并沿时间轴出现。点积注意力通过内积来度量对齐程度，因此偏好对齐的 token，而在接近正交时最不敏感，使得这类关系只能让网络通过间接路径恢复。我们提出时频几何交叉注意力（TFGCA），这是一个即插即用模块，可修复上述两个盲点。TFGCA 使用逐维可学习的平稳小波变换，将动作块分解为时频 token，每个时间 token 通过一种交叉注意力从中检索信息；该交叉注意力通过可学习权重融合点积（相似度）与楔积幅值（对近正交敏感）。一个零初始化的残差在初始化时复现基座行为，因此可以将其即插到预训练的 VLA 上并进行联合微调。相对于同源基座，TFGCA 在分布内 LIBERO 上平均提升 +1.5，在 OOD LIBERO-Plus 上提升 +6.3，在 RoboTwin 域随机化下的随机平均提升 +28.5，并在三个真实机器人 AgiBot A2 任务上的总体成功率提升 +11.67 个百分点，且在分布外获得更大增益。

## Abstract
Modern vision-language-action (VLA) policies predict a whole chunk of actions: one to two seconds of coordinated motion emitted in a single forward pass. Yet an action chunk is essentially a short multivariate trajectory, but inside these models it is a sequence of generic per-timestep hidden tokens decoded by a linear head. This under-serves two motion structures. First, frequency: a chunk superimposes a smooth global trend and fine corrective motion across time scales, and a single token entangles them. Second, cross-phase geometry: motions of different phases (reach, contact, grasp adjustment, settling) unfold along very different, near-orthogonal directions in representation space, yet are tightly related for the task and arise across the time axis. Dot-product attention scores alignment by an inner product, so it favors aligned tokens and is least sensitive near orthogonality, leaving such relationships for the network to recover through a detour.   We introduce Time-Frequency Geometric Cross-Attention (TFGCA), a drop-in module repairing both blind spots. TFGCA uses a per-dimension learnable stationary wavelet transform to decompose the action chunk into time-frequency tokens, and each time token retrieves information from them via a cross-attention that fuses the dot product (similarity) with the wedge-product magnitude (sensitive to near-orthogonality) through a learnable weight. A zero-initialized residual reproduces the base behavior at initialization, so it can be dropped onto a pretrained VLA and fine-tuned jointly. Relative to the same-source base, TFGCA improves in-distribution LIBERO by +1.5 on average, the OOD LIBERO-Plus by +6.3, the randomized average under RoboTwin domain randomization by +28.5, and the overall success rate on three real-robot AgiBot A2 tasks by +11.67 points, with larger gains out of distribution.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：现代视觉-语言-动作（VLA）策略（如 π0、π0.5、RDT-1B、ACT）已收敛到"动作块预测"接口：一次前向传播输出 T×D 的未来动作轨迹（约 1–2 秒协调运动），执行其前缀后再重新规划。动作块本质上是一段**短时多元轨迹**，其价值在于各维度如何随时间协同运动。
- **问题**：现有 VLA 将动作块视为无结构的通用逐时间步隐藏 token 序列，由线性头解码，导致两类运动结构被隐式忽略：
  - **频率结构**：一个块叠加了慢速全局趋势（搬运）与快速精细修正（接触修正、抓取调整、稳定），单一 token 将多时间尺度纠缠在一起，模型无法显式区分"趋势"与"修正"。
  - **跨相位几何关系**：熟练操作沿时间轴展开为接近、接触、抓取调整、稳定等相位，各相位在表示空间中沿**近乎正交**的方向展开（作者将其命名为 TO-DoL，即"时序正交分工"），但它们在任务上紧密相关，且这种关系**沿时间轴跨相位出现，而非同一时刻**。
- **关键矛盾**：点积注意力以相似度打分，在**接近正交时最不敏感**，因此这类跨相位关系只能由网络"绕路"重新编码为相似性，耗费表示容量。
- **整体含义**：论文提出 **TFGCA（Time–Frequency Geometric Cross-Attention）**，一个即插即用模块，同时修复"频率"与"跨相位几何"两个盲点，且能在预训练 VLA 上安全接入并联合微调。

## 2. 方法论

### 2.1 核心思想
- 将动作块投影到**动作空间**，用**逐维可学习平稳小波变换（SWT）**分解为多分辨率时频 token；
- 每个时间 token 通过**交叉注意力**从全部时频 token 中检索信息，打分融合**点积（相似度）**与**楔积幅值（对近正交敏感）**，权重可学习；
- 输出经**零初始化残差**写回，保证初始化时严格复现基座行为。

### 2.2 三阶段流程（H ∈ R^{T×d} → H̃ ∈ R^{T×d}）

- **阶段一：动作空间投影**
  - Z_act = ActionProj(H) ∈ R^{T×D}，D 为控制维度（LIBERO 为 7 维笛卡尔末端增量+夹爪；RoboTwin/AgiBot 为关节空间）。
  - 辅助对齐损失：L_align = ‖Z_act − sg(a)‖²，sg 为 stop-gradient（只更新投影，不回传目标）；总损失 L = L_FM + λ·L_align，λ 取 0.01（LIBERO/Plus）或 0.1（RoboTwin）。

- **阶段二：逐维可学习 SWT 分词**
  - SWT **不降采样**，各频带长度保持 T，与原始时间步对齐，可直接作为注意力 key。
  - 一层分解：近似分支 a^{(j+1)}_t = Σ h_k a^{(j)}_{t+2^j k}，细节分支 d^{(j+1)}_t = Σ g_k a^{(j)}_{t+2^j k}，对近似分支递归。
  - J 层输出 {d^{(1)},…,d^{(J)}, a^{(J)}}，按高频到低频排序。
  - 三个 VLA 专用设计：
    - **逐维可学习滤波器**，初始化为 Daubechies-2（db2，两个消失矩，使细节系数对局部线性运动不响应、只响应曲率）；
    - **逐维去 DC**（减均值），但**不除标准差**，以保留高运动时刻与静止段的幅度对比信号；
    - **可选差分预处理**：LIBERO 直接送入（order 0），RoboTwin 关节 qpos 低频漂移强，先做二阶差分（order 2）。
  - 每个 (时间, 频带) 位置用逐带线性映射把 D 维动作向量嵌入到模型宽度 d，加频带类型嵌入与时间位置嵌入，展平后得到 F ∈ R^{T(J+1)×d}（多维度结构作为 token 内容承载，而非逐维配对）。

- **阶段三：点积 + 楔积交叉注意力**
  - 查询为时间 token H，键/值为时频 token F：Q = W_Q H，K = W_K F，V = W_V F。
  - 两个打分矩阵（缩放 s = 1/√d_h）：
    - S_dot,ij = s·(q_iᵀk_j)
    - S_wed,ij = s·√(‖q_i‖²‖k_j‖² − (q_iᵀk_j)²)（由 Cauchy–Schwarz 恒等式闭式给出，无需构造反对称张量）
  - **双 softmax 后混合**（而非先求和再 softmax，保证两通道各为合法分布）：A = (1−β)·softmax(S_dot) + β·softmax(S_wed)，β = σ(ℓ) 为全局可学习标量（初始化为 0.5）。
  - 输出：H̃ = H + W_O(A V)，**仅 W_O 零初始化**，值路径与动作空间投影保持非零，保证初始梯度 ∇_{W_O}L = δ(AV)ᵀ 一般非零、模块可逃离恒等映射。

### 2.3 理论性质（Proposition 1）
- **对齐–正交分解**：归一化后 ŝ² + ŵ² = 1，ŝ = cos θ、ŵ = |sin θ|；点积与楔积是单位圆上两个正交坐标，点积只读 ŝ、对 ŵ 轴盲。
- **顺序分离**：固定 q，取等模长键 k_a、k_b 且 qᵀk_a > qᵀk_b ≥ 0，则点积通道必给 k_a 更大权重，而楔积通道给 k_b 更大权重；当 β 超过阈值 β⋆ = Δ_dot/(Δ_dot+Δ_wed) ∈ (0,1) 时，混合打分可使**近正交键排序反超**——这是纯点积无法实现的排序。
- **表示复杂度视角**：楔积幅值在 (q,k) 上是二次型，点积需二次特征提升 φ(x)=vec(xxᵀ)（维度 O(d_h²)）才能复现，而楔积经 Cauchy–Schwarz 以 O(d_h) 闭式计算。
- **范围声明**：该分离在固定表示下成立；由于 Q/K 来自可学习投影，深层网络理论上仍可把正交关系重编码为对齐，故 Proposition 1 不是"点积模型的不可行性定理"，而是"低成本归纳偏置"，其实际收益由实验回答。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark
- **LIBERO**（4 个套件：Spatial、Object、Goal、Long/L10）：分布内、近饱和（基座平均约 97%）；单臂、末端增量控制，chunk=10。
- **LIBERO-Plus**：在 LIBERO 上施加 7 类 OOD 扰动（Camera、Robot、Language、Light、Background、Noise、Layout），仅用干净 LIBERO 训练后零样本测试；chunk=10，**复用 LIBERO 训练模型不再单独训练**。
- **RoboTwin 2.0**：6 个双臂任务（open_microwave、stamp_seal、handover_block、turn_switch、stack_bowls_three、click_bell），仅在 clean 演示上训练 30k 步，分别在 clean 与 randomized 环境测试；chunk=50，二阶差分，2 层 SWT。
- **AgiBot A2 真机**：3 个任务（肥皂入盒、毛绒玩具入篮、从盒中抽纸巾），每任务 20 次、共 60 次试验。

### 3.2 对比方法
- **主对比**：同源复现的 π0.5 基座（`lerobot/pi05_base`），共享数据、训练预算与评估协议，仅 TFGCA 特有配置不同。
- **消融**：w/o SWT（去掉频率分支）、w/o geometry（去掉楔积通道，退化为纯点积）、w/o alignment（禁用对齐损失）。
- **附录外部方法**（仅供参考、协议可能不同）：LIBERO 对比 DP、OpenVLA、SpatialVLA、CoT-VLA、π0/π0-FAST、GR00T-N1/N1.6、OpenVLA-OFT、Fast-WAM、X-VLA 等 11 种；RoboTwin 对比官方排行榜的 DP、ACT、DP3、RDT、π0。

### 3.3 主要结果
- **LIBERO**：相对复现基座（96.7）提升至 98.2（**+1.5**），Long 套件 94.6 → 97.0；消融均下降（w/o alignment 降幅最大至 97.1）。
- **LIBERO-Plus**：Total 66.7 → 73.0（**+6.3**），7 类扰动中 6 类提升，增益集中在基座最弱的 Noise、Robot、Camera；消融中 **w/o geometry 降幅最大（69.7）**，与分布内相反。
- **RoboTwin 2.0**：6 任务均值 clean 61.3 → 65.0（**+3.7**），randomized 14.2 → 42.7（**+28.5**）；randomized 均值比次优方法高约 24 点；click_bell（6%→86%）与 stack_bowls_three（6%→59%）增益最显著；handover_block 随机化 13→11（在 n=100 二项置信区间内，视为噪声）。
- **AgiBot A2**：总体 50.00% → 61.67%（**+11.67 个百分点**），三任务均提升，抽纸巾任务 +15 点。

  - LIBERO 基座已近饱和（~97%），分布内提升空间有限，难以充分体现方法上限；
  - 楔积通道的 β 阈值 β⋆ 仅为理论刻画，论文未系统报告学到的 β 值随时间/层/任务的演化，缺少对"模型是否真的用上了几何通道"的机制性证据；
  - 消融只做了"去掉整条分支"，未做**交叉消融**（如 w/o SWT 且 w/o geometry、单频带 vs 多频带、不同消失矩 db2/db4/正交 vs 双正交），频率与几何的交互效应未被拆解；
  - 未与其他注意力变体（如加性注意力、cosine 注意力、相对位置编码）作等价预算对照，无法排除"额外参数/额外 token 数量"本身的贡献；
  - 真机仅 3 任务 × 20 次，样本量偏小，且任务同质（均为拾取-放置类），泛化结论需谨慎。

## 6. 论文的主要贡献与创新点

1. **问题识别层面**：把 VLA 动作块从"无结构 token 序列"重新表述为**短时多元轨迹**，明确指出被忽视的两类结构——多时间尺度频率结构与跨相位近正交几何关系，并用 TO-DoL（时序正交分工）为其命名，给出了直观且可检验的假设。
2. **方法层面**：
   - 提出**逐维可学习 SWT** 分词器，无降采样、长度对齐、可作注意力 key，并用 db2 初始化 + 去 DC 不除标准差 + 可选差分三项设计贴合控制信号特性；
   - 提出**点积 + 楔积双通道交叉注意力**，用 Cauchy–Schwarz 恒等式以 O(d_h) 闭式计算对近正交敏感的楔积幅值，避免构造反对称张量；
   - 采用**双 softmax 后线性混合**与**仅输出投影零初始化**的工程细节，兼顾分布合法性与恒等初始化安全性。
3. **理论层面**：Proposition 1 给出对齐–正交分解（ŝ²+ŵ²=1）、点积/楔积通道的**排序分离**及 β⋆ 阈值，并指出楔积以 O(d_h) 复现了需 O(d_h²) 二次特征提升才能表达的量，为"低成本归纳偏置"提供了形式化依据。
4. **实证层面**：在 4 个设置上验证，**参数量仅增加 0.10%** 却带来分布外增益（LIBERO-Plus +6.3、RoboTwin randomized +28.5、真机 +11.67pt），其中零样本域随机化与真机结果最具说服力。

## 7. 论文的局限与未来工作方向（含审稿视角）

- **作者自述的边界**：Proposition 1 明确限定在固定表示下成立，深层网络仍可能把正交关系重编码为对齐，故该性质是归纳偏置而非不可行性定理；论文也声明未测量显存、吞吐、延迟等工程指标。
- **可推断的局限**：
  - 动作空间投影依赖**已知控制维度与动作语义**（笛卡尔增量 vs 关节空间），跨本体迁移时 ActionProj 与差分阶数（0/2）需人工选择，自动化程度不足；
  - SWT 层数 J、频带嵌入、差分阶数等超参在不同 benchmark 上取值不同（LIBERO order 0、RoboTwin order 2、2 层 SWT），**缺少统一的超参选择准则**；
  - 计算与显存开销虽参数少，但 F ∈ R^{T(J+1)×d} 使 key/value 序列长度变为原来的 (J+1) 倍，注意力复杂度随 J 线性增长，长 chunk（如 T=50）下开销不可忽略；
  - 楔积幅值在 ‖q‖ 或 ‖k‖ 接近 0 时数值不稳（恒等式差值可能因浮点误差为负），论文未详述数值稳定处理。
- **可拓展方向**：将楔积推广到多向量（如 Grassmann/外积的高阶形式）以捕捉多相位联合几何；把频率分支从逐维 SWT 扩展为跨维联合变换以捕捉维度间耦合；将 β 从全局标量改为逐头/逐层/逐时间步动态预测；在更长 chunk 与更高频控制（如 100Hz）上验证；与 diffusion/flow 去噪轨迹的时间结构做联合建模。

## 8. 对后续研究/实践的启发

- **表示接口的再设计**：VLA 的瓶颈可能不在于 backbone 规模，而在于**输出接口对动作结构的隐式假设**。把"动作块 = token 序列"改写为"动作块 = 时频轨迹"是一个低成本的切入角度。
- **"零初始化残差 + 双 softmax 混合"是通用安全插件范式**：仅零初始化输出投影、保留值路径梯度，既保证初始恒等又能逃离恒等，可作为任何预训练策略后插入模块的工程模板。
- **用闭式几何量替代高维特征提升**：当希望模型对某种几何关系（正交、角度、秩）敏感时，优先寻找 O(d) 闭式表达式而非 φ(x)=vec(xxᵀ) 之类的二次提升，是性价比很高的归纳偏置注入方式。
- **OOD 比分布内更能检验结构先验**：在近饱和 benchmark（LIBERO ~97%）上做分布内对比区分度低；把评测重心放到零样本域随机化与真机扰动上，更可能暴露方法的真实价值。
- **对评价规范的要求**：小增益（+1.5、+3.7）应配多种子方差与置信区间；消融应做交互消融与等预算对照；机制性证据（学到的 β、频带注意力分布可视化）应作为主张的补充支撑。
