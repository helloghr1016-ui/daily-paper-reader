## 摘要
当固定视角使任务相关信息被遮挡或未被观测到时，主动感知对于机器人操作至关重要。然而，使视觉-语言-动作（VLA）模型能够在变化视角下进行推理并主动获取有信息量的观测仍然具有挑战性。我们提出 ActiveScale，一个通过模型、数据和硬件协同设计推进主动感知的框架。我们的模型通过历史视频观测和显式相机位姿监督增强 VLA，利用逐帧位姿 token 和轻量级预测头来关联跨视角观测，并支持对场景的一致理解。为了从人类活动中自然存在的相机运动中学习，我们引入一种可扩展的人-机器人中期训练方案，使用 1000 小时的第一人称视角和机器人数据，使模型适应时序输入和位姿监督。我们进一步提出主动感知移动操作平台（Active-perception Mobile-manipulation Platform, AMP），这是一个通过单人遥操作支持主动感知和移动操作的机器人平台，能够可扩展地收集协调视角变化与操作的演示数据。实验表明，在主动感知任务上成功率有所提升，而消融研究验证了相机位姿感知建模和第一人称视角中期训练的贡献。这些组件共同为研究和开发机器人操作中的主动感知提供了集成基础。

## Abstract
Active perception is essential for robotic manipulation when fixed viewpoints leave task-relevant information occluded or unobserved. However, enabling vision-language-action (VLA) models to reason across changing viewpoints and actively acquire informative observations remains challenging. We present ActiveScale, a framework that advances active perception through coordinated model, data, and hardware designs. Our model augments a VLA with historical video observations and explicit camera-pose supervision, using per-frame pose tokens and a lightweight prediction head to associate observations across viewpoints and support a coherent understanding of the scene. To learn from the camera motion naturally present in human activity, we introduce a scalable human--robot mid-training recipe using 1000 hours of egocentric and robotic data, adapting the model to temporal inputs and pose supervision. We further introduce Active-perception Mobile-manipulation Platform (AMP), a robotic platform that supports active perception and mobile manipulation through single-operator teleoperation, enabling scalable collection of demonstrations that coordinate viewpoint changes and manipulation. Experiments demonstrate improved success rates on active-perception tasks, while ablation studies validate the contributions of camera-pose-aware modeling and egocentric mid-training. Together, these components provide an integrated foundation for studying and developing active perception in robotic manipulation.

- **研究背景**：机器人基础模型（尤其是视觉-语言-动作模型 VLA）已显著扩展了机器人在多环境中的任务能力，但固定视角下的观测往往只提供部分信息。
- **核心问题**：在杂乱环境中，机器人需要**主动获取任务相关信息**（例如调整第一人称视角去查看柜子里的碗、背包内的物品），以消除遮挡。静态感知因此日益不足，**主动感知**成为通用机器人智能体的关键能力。
- **已有工作的三类不足**：
  - 现有 VLA **缺乏推断自身相机位姿、并据此预测后续相机运动**的能力（后者依赖前者）。

  - 当前研究多集中在**静态环境**（如 SAPAVE、ActiveMimic），与真实世界的**移动操作**（机器人本体与观察视角都需适应动态杂乱环境）之间存在明显差距。
- **整体含义**：论文指出，目前缺乏一个**跨模型、数据、硬件系统化研究主动感知的统一基础设施**，因此提出 ActiveScale，从这三个维度协同推进，为机器人主动感知与移动操作提供集成基础。

## 2. 方法论：核心思想与关键技术细节

### 2.1 问题形式化

- 将主动感知操作建模为学习一个**语言条件策略** πθ，同时控制操作与视角运动。
- 时刻 t 给定观测 ot ∈ O 与语言指令 ℓ ∈ L，策略预测未来动作块：πθ(ot, ℓ) → a_{t:t+K−1}。
- 观测 ot 包含视觉观测与状态上下文 st（本体感知、运动学等非视觉信息）。
- 每个动作 aτ **联合指定左右操作末端执行器与主动相机的笛卡尔位姿，以及两个夹爪指令**，统一表达在共享的机器人中心坐标系 FU 中。

### 2.2 模型架构（核心思想：位姿锚定的时序 VLA）

- **基础骨干**：采用 π0.5（预训练 PaliGemma VLM + 轻量 Transformer 动作专家）。
  - VLM 编码多视角视觉、语言指令、token 化的本体状态作为上下文。
  - 动作专家基于流匹配（flow matching）预测连续动作块：给定干净动作 a、高斯噪声 ϵ ~ N(0, I)、流时间 τ ∈ [0,1]，构造 xτ = τϵ + (1−τ)a，目标速度 uτ = ϵ − a，损失为 Lflow = E[‖vθ(xτ, τ, c) − uτ‖²₂]，其中 c 为 VLM 上下文。
  - 保留 π0.5 的自回归 token 预测目标：高层 VLM 预测当前子任务（Lsubtask，交叉熵）；低层用 FAST 将未来连续动作轨迹转为离散动作 token 并自回归预测（LFAST，交叉熵）。

- **相机 token（关键技术细节）**：
  - 将输入从单帧扩展到**历史视频观测**：当前前视相机观测 + 3 帧过去观测（间隔 16 帧），即 Hft = (Ift−48, Ift−32, Ift−16, Ift)。
  - 每帧由共享视觉编码器编码，并在其视觉 token 后**追加一个可学习相机 token**；使用两个可学习嵌入 cfirst（最早有效帧）与 crest（后续帧）。
  - 前缀组织为 [V_{ft−48}, c1, …, V_{ft}, c4, V_lt, V_rt, E(ℓ, st)]。
  - 对前视相机历史采用**块因果注意力**：每个时序块只能关注自身及更早历史，相机 token 不能访问未来帧；手腕、语言、动作 token 可关注所有有效相机历史块。
  - 相机 token 隐状态经线性投影送入 **VGGT 风格的相机头**，预测 **9 维相机表示**：3D 平移 (x, y, z)、四元数朝向 (qx, qy, qz, qw)、垂直与水平视场角 (fovy, fovx)。
  - 相机损失：**Lcam = Ltrans + Lrot + λfov·Lfov**（λfov = 0.5），三项分别为平移、四元数朝向、视场角的分量式 ℓ1 损失。
  - 该辅助头在**动作推理阶段被移除**，仅用于几何锚定相机 token 表示；得到的 prefix 用于条件化原 π0.5 动作专家，联合生成操作与头部相机运动。

### 2.3 训练方案（两阶段）

- **第一阶段：人-机器人中期训练（Human–Robot Mid-Training）**
  - 从预训练 π0.5 检查点出发，联合训练人类与机器人演示，按 **1:1 平衡比例采样**。
  - 人类演示：头部相机位姿提供主动视角监督，手腕轨迹提供操作监督；参照 [6]，将人类相机与手腕轨迹**重表达为每个时序窗口最早有效观测的相机坐标系**；机器人轨迹保持固定机器人参考系。
  - 分别对每个数据源归一化状态与动作轨迹，并**掩码不可用的动作维度与相机位姿目标**。
  - 人类数据来自 EgoLive、EgoVerse；机器人数据来自 AgiBot World、RoboCOIN 及自建 AMP。
  - 混合批训练目标：
    **Lco = L^H_subtask + λH(L^H_FAST + L^H_flow) + L^R_FAST + L^R_flow + λC·Lcam**，其中 λH = λC = 0.2，各项仅在对应监督可用时计算。

- **第二阶段：遥操作数据后训练（Post-training）**
  - 在 AMP 遥操作演示上做任务特定后训练，保持模型架构与动作表示不变。
  - **Lpost = Lflow + λC·Lcam**（λC = 0.2）。
  - 与中期训练不同，**不使用自回归子任务或 FAST 目标**，因为后训练数据已直接提供目标本体上对齐的机器人动作与主动相机轨迹。

### 2.4 硬件平台 AMP

- 基于改进的 AgileX Cobot-Magic：差分驱动移动底座 + 两条 6-DoF Piper 臂（左右各配 Orbbec DaBai DC1 相机）。
- **新增第三条 6-DoF Piper 臂**搭载第三个 Orbbec DaBai DC1 相机，替代原固定前置相机，实现**独立驱动的第一人称主动视角**，同时保留双臂与移动底座。
- **单人遥操作**：Meta Quest 2 头显 + 两个手柄。头显控制主动相机所在中间臂，左右手柄控制对应操作臂；按下双手柄 grip 键注册参考位姿，运动以相对增量表达（Δp = p − p0，ΔR = R·R0^T），目标为 pA = pA0 + λΔp（λ = 1），经逆运动学跟踪；重新接入会重新锚定参考。手柄扳机控制夹爪，左控制器 X/Y 键旋转底座，右控制器 A/B 键前后驱动。
- **数据采集**：30 Hz 同步记录三路 RGB、相机内参、畸变参数、分辨率、三臂关节反馈与控制命令。
- **机器人中心坐标系 FU**：与中间臂基座坐标系同朝向，原点沿中间臂 z 轴下移 0.25 m，随机器人移动而非固定于世界坐标。
- 状态表示：23 维 st = [U ξLt, U ξRt, U ξCt, γLt, γRt]，其中 U ξXt = [U pXt, U qXt] ∈ R7（位置 + xyzw 单位四元数）；底座平面运动单独记录为 bt = (vt, ωt)。

## 3. 实验设计

### 3.1 场景与 Benchmark

- 在 **AMP 平台上进行真实世界评估**，聚焦于成功执行需要机器人**在操作过程中主动获取任务相关视觉信息**的任务。
- **五个真实世界任务族**，覆盖两类互补的视角需求：
  - **遮挡驱动操作（Occlusion-Driven Manipulation）**：
    - **Bag**：从背包内取出瓶子放到桌上（需在打开背包时查看内部）。
    - **Drawer**：打开上/中层抽屉，取出指定物体放到盘子上并关抽屉（目标物打开后才可见）。
    - **Table**：取出桌子下方的指定物体放入指定标签箱（目标初始在正面视野之外，需下移视角）。
  - **主动搜索与定位（Active Search and Localization）**：
    - **Pot**：从货架上取指定蔬菜放入锅中并盖上锅盖（需在货架、锅、锅盖之间切换视角）。
    - **Box**：从货架取指定物体，按语言指令放入左或右目标箱（不同货架高度需垂直视角搜索）。

### 3.2 评估协议

- 每个任务族使用 **150 条演示**做后训练。
- 每种方法在**匹配条件下进行 20 次真实世界 rollout**。
- 仅当所有必要阶段及任务特定最终状态判据均满足时才算成功。
- 指标：**严格任务成功率（SR）** 与 **任务进度（TP）**（TP 累加各阶段完成得分，见表 I 的阶段学分，如 Bag：抓背包 0.3 / 抓瓶 0.3 / 放瓶上桌 0.4）。

### 3.3 对比方法

- 主要对比 **π0.5**（当前最先进真实世界操作 VLA）。作者说明：近期主动感知 VLA **未公开检查点与完整训练配方**，无法直接评估。
- 消融对比：
  - **ActiveScale（w/o Mid-training）** vs 完整 ActiveScale（验证中期训练）。
  - **π0.5 原始** vs **仅加历史** vs **历史 + 相机 token**（验证时序历史与位姿锚定相机 token 的贡献）。
- 效率对比指标采用 OpenVLA-OFT 的动作生成吞吐量度量，并启用 RTC。

## 5. 实验数量与充分性

### 实验规模概览

- **1 组主实验**：ActiveScale vs π0.5，覆盖 5 个任务族，每任务 20 次 rollout（共 5×2×20 = 200 次真实 rollout）。
- **2 组消融实验**：
  - 中期训练消融（2 个变体 × 5 任务）。
  - 历史与相机 token 消融（3 个变体 × 5 任务）。
- **1 组效率实验**（RTX 4090 吞吐量）。
- **1 个 AMP 单人移动操作演示**（多阶段：查看抽屉取蔬菜 → 重定向相机定位烹饪区 → 导航 → 放蔬菜入锅并盖盖）。
- 另有定性分析（如 Pot 任务中中期训练策略锅盖放置更对齐）。

### 充分性与公平性评估

- **优点**：
  - 五个任务覆盖多种视角挑战（容器与铰接遮挡、桌下感知、多阶段视角切换、大范围垂直工作空间），任务设计具有代表性。
  - 消融实验针对性强，分别隔离了中期训练与模型设计两个变量，且明确说明“除特别说明外，所有变体使用相同的任务特定后训练数据与真实世界评估协议”，**控制变量较为严格**。
  - 采用严格成功率 + 任务进度双指标，TP 能反映二值成功之外的中间执行质量。
- **不足**：
  - 每任务仅 20 次 rollout，**样本量偏小**，统计显著性未做检验，结果波动风险较高。
  - **仅与 π0.5 单一基线比较**，缺少与其他主动感知方法（如 SAPAVE、ActiveMimic、EgoMI）的对比，作者以“未公开检查点”为理由，但这削弱了横向可比性。
  - 消融中的“仅历史”变体在 Bag 任务上表现反而低于单帧基线，说明结果存在任务依赖性，论文对此仅作定性解释。
  - 未报告多次运行/随机种子，也**缺少仿真或标准化 benchmark 上的可复现实验**。
