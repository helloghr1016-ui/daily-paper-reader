## 摘要
力感知的视觉-语言-动作（VLA）策略可提升富接触操作性能，但通常将任务级运动与依赖接触的调整结合在单一动作预测中。演示数据未提供显式标签来将该预测分解为可复用的参考动作和校正项。我们提出 ForceDelta-VLA，一种校正蒸馏框架，利用冻结教师模型在力条件模式与习得的无力感知模式下的成对预测，构建显式的力校正目标。另一个独立的延迟校正目标用于解释参考动作不匹配以及参考状态的变化。训练采用异步调度回放，并利用执行期间可用的缓存任务上下文。所得轻量策略利用近期力历史和机器人状态调整参考动作，在参考动作更新之间对接触变化做出响应，而无需重新生成完整动作块。在九项单臂和双臂富接触任务中，ForceDelta-VLA 达到 82.2% 的平均成功率，而原始 ForceVLA 基线为 54.4%。直接执行我们第一阶段时序教师模型（Stage-1 Temporal Teacher）达到 70.6%。相对于 ForceVLA，完整系统在两个平台上均将成功试验中的平均峰值接触力降低约 26%。

## Abstract
Force-aware Vision-Language-Action (VLA) policies improve contact-rich manipulation, but typically combine task-level motion and contact-dependent adjustment in a single action prediction. Demonstrations provide no explicit labels for decomposing that prediction into a reusable reference action and a correction. We present ForceDelta-VLA, a correction-distillation framework that constructs an explicit force-correction target using paired predictions from a frozen teacher's force-conditioned and learned force-agnostic modes. A separate delay-correction target accounts for reference-action mismatch and the change in reference state. Training uses asynchronous schedule replay with the cached task context available during execution. The resulting lightweight policy adjusts the reference actions using recent force history and robot state, responding to contact changes between reference-action updates without regenerating complete action chunks. Across nine single-arm and bimanual contact-rich tasks, ForceDelta-VLA achieves an 82.2% mean success rate, compared with 54.4% for the original ForceVLA baseline. Direct execution of our Stage-1 Temporal Teacher achieves 70.6%. Relative to ForceVLA, the complete system reduces mean peak contact force over successful trials by approximately 26% on both platforms.

# ForceDelta-VLA 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：富接触操作（如 USB 插接、按钮按压、插头插入、抽屉拉开）要求动作随接触状态的演化而实时调整。力感知的视觉-语言-动作（VLA）策略通过引入交互反馈提升了这类任务的表现。
- **核心痛点**：现有力感知 VLA 通常把**任务级运动**与**依赖接触的局部调整**混在**同一次动作预测**中输出。这种耦合带来两个问题：
  - 参考运动本可跨多个控制周期复用，但每次接触反馈都需要等待一次完整的生成式推理（延迟高、算力浪费）；
  - 演示数据只记录最终动作，**没有显式标签**说明哪部分属于"可复用的参考动作"、哪部分属于"接触相关修正"。不同的参考动作与修正组合可以相加得到同一个演示动作，因此修正通路缺乏明确的监督目标。
- **已有方案的不足**：异步策略（FAVLA、DAM-VLA 等）只分离了计算或传感的更新频率；残差强化学习与纠正式模仿学习则依赖奖励信号或额外的在线交互（人类纠正、on-policy 数据），成本高。
- **整体含义**：本文提出 ForceDelta-VLA，**仅使用原始演示数据**构造显式的力修正与延迟修正监督目标，并把"慢速生成参考动作"与"快速预测修正"解耦，使轻量策略能在两次参考动作更新之间响应接触变化，而无需重新生成完整动作块。

## 2. 方法论

### 2.1 核心思想
将指令姿态分解为三部分（式 1）：
`P(A_cmd) = P(A_ref) + ΔÂ_force + ΔÂ_delay`
- `A_ref`：由慢速生成通路（无力输入）预测的可复用参考动作块；
- `ΔÂ_force`：由力历史驱动的力修正；
- `ΔÂ_delay`：补偿"较早生成的参考动作"与"当前预测"之间的差异，以及参考状态的变化。
只有姿态被修正，夹爪指令直接取自参考动作；修正加在归一化姿态坐标（平移 + 连续 6D 旋转）上，再用 Gram–Schmidt 投影回合法旋转。双臂任务拼接两臂输入联合预测。

### 2.2 三阶段训练

**Stage 1：时序力条件教师（Temporal Force-Conditioned Teacher）**
- 以 ForceVLA 为骨干，把其瞬时力嵌入替换为 FAVLA 风格的**因果时间卷积网络（TCN）**来编码扳量历史：`z_F^t = E_FT(F_t)`，历史长度 100 ms。
- 在数据集 D 上以流匹配目标训练，输入 `(V_t, L, S_t, z_F^t; ϵ)`，输出 H=50 步动作块；训练后**冻结参数 θ**。

**Stage 2：无力感知参考动作模式**
- 关键设计是**区分"力不可用"与"物理上测得的零力"**：用力历史输入替换为可学习 token `z∅F`，并引入秩为 ρ 的适配器 `(W_in, W_out)` 修改动作专家的姿态通道输出：`v_p ← v_p + W_out σ(W_in h)`；适配器仅在无力模式下激活。
- 冻结 θ，仅训练 `ϕ = {z∅F, W_in, W_out}`，得到参考策略 `A_ref = T_ref(V_t, L, S_t, z∅F; ϵ)`。

**Stage 3：成对修正目标与轻量修正策略**
- **目标构造复用缓存前缀**：设修正时刻为 t，最近一次可用的参考查询为 k。复用该查询的视觉-语言前缀 `E_k` 与流噪声 `ϵ_k`，只把机器人状态与力历史更新到 t，得到同一上下文/状态/噪声下的两个成对预测：
  - 力条件预测 `A_cond_{T,t|k}` 与无力预测 `A_ref_{T,t|k}`；
  - **力修正目标**：`ΔA_force = P(A_cond_{T,t|k,j}) − P(A_ref_{T,t|k,j})`（式 8）。
- **延迟修正目标**：`ΔA_delay = P(A_ref_{T,t|k,j}) − P(A_ref_k(t_j)) + Γ(S_t, S_k)`（式 9），即"当前无力预测 − 存储参考在时刻 t_j 的插值 + 参考状态对齐项 Γ"。
- **修正策略网络**：条件集合 `C_t` 包含任务上下文 token、因果力编码 `u_F^t`、当前本体状态、插值后的参考动作片段、时序特征（缓存年龄与插值相位），各输入经投影到统一宽度并加类型嵌入。共享注意力模块 Φ 配一个可学习 query `q_corr`，**同一套权重前向两次**：一次用全部条件预测力修正，一次**掩蔽力 token**预测延迟修正；两个独立输出头分别输出 K=5 步修正。掩蔽保证延迟输出不直接依赖力 token。
- **异步调度回放（Asynchronous Schedule Replay）**：先采样查询周期与推理延迟，按该固定调度提取目标与构造学生输入（选择最近已完成的参考查询及其缓存上下文、插值参考、时序特征），使训练分布与部署时的延迟状态一致。
- **蒸馏损失**：对 K 步修正使用归一化坐标 MSE，时间权重 `w_j ∝ β^{j-1}`，力项与延迟项以 `λ_delay` 加权求和。

### 2.3 异步部署
- 教师周期性刷新缓存参考（约 5 Hz，单次前向 189.7 ms），学生独立高频运行（单次前向 2.43 ms）。
- 每个学生查询读取最新已完成的参考更新，并在执行期间与该参考保持配对；执行器选择最近启动且有效完成的学生查询结果，按其时间戳 j 插值参考、**分别裁剪两项修正**，按式 (1) 组合，再用所选参考的查询状态 S_k 转成绝对指令；过期步被跳过，有效修正步保持到下一时间戳或更新的有效结果出现。

## 6. 主要结论与发现

- **性能**：ForceDelta-VLA 平均成功率 **82.2%**，显著优于 ForceVLA（54.4%）、TA-VLA（57.2%）、π0.5（47.2%）、ImplicitRDP（45.0%）与 Stage-1 时序教师直接执行（70.6%）；9 个任务上全部优于 ForceVLA，提升最大的为 USB Insertion（40%→80%）、Button Pressing（50%→85%）、Plug Insertion（35%→70%）。
- **接触力与效率**：相对 ForceVLA，成功试验的平均峰值接触力在单臂/双臂分别下降 4.2 N / 4.3 N（约 **26%**），完成时间分别缩短 5.2 s / 5.9 s；相对时序教师也分别下降 3.3 N / 2.2 N。
- **实时性**：修正通路前向仅 2.43 ms，低于 100 Hz 指令传输间隔；参考动作与教师前向均超过该间隔，说明"复用参考 + 快速修正"的必要性。
- **延迟敏感性**：额外注入 200 ms 参考延迟时，ForceDelta-VLA 成功率下降 15 个百分点、峰值力上升 3.7 N，而时序教师分别下降 25 个百分点、上升 9.6 N，支持"在参考更新之间更新修正"的价值。
- **消融结论**：显式的教师成对目标优于演示派生目标（差 12.5/17.5 个百分点）；力分支与延迟分支分别贡献成功率与降力效果；单头合并修正、快速全动作蒸馏、去掉调度回放均明显变差；力输入置零比直接禁用输出更差，说明该分支确实依赖真实力反馈。
- **泛化**：未见物体上成功率 66.7%（教师 40.0%，ImplicitRDP 16.7%），峰值力降低 8.2 N。
- **失败模式**：插入类任务常在边缘接触或小角度误差下卡死，参考动作仍继续前进而修正不足以回退重试；柜门/抽屉拉开存在接触未稳定即拉动；擦除与翻转任务出现非预期侧接触。作者指出未来需要能"回退、重建接触、改变接近方向"的参考更新。

## 7. 优点

- **监督信号构造巧妙**：用冻结教师的"力条件 / 力无关"成对预测（共享上下文前缀、状态、采样噪声）定义力修正目标，把原本缺失的分解标签问题转化为可离线构造的差分监督，无需额外奖励或在线交互。
- **区分"力缺失"与"零力"**：用可学习空 token + 秩受限适配器实现力无关模式，比直接置零更合理，消融也验证了这一点。
- **双修正解耦 + 掩蔽机制**：力修正与延迟修正共享注意力权重但经两次前向、两个头输出，延迟头掩蔽力 token，保证两项修正语义清晰、可分别监督；延迟目标显式包含参考状态对齐项 Γ，建模了"旧参考、新状态"的错配。
- **训练-部署一致性**：异步调度回放先采样查询周期与推理延迟再构造目标，使学生训练分布贴近真实部署。
- **轻量高效**：修正策略仅 2.43 ms 前向，可在参考动作更新之间以远高于生成频率的速率响应接触变化。
- **实验扎实**：真实单臂 + 双臂共 9 个任务、每任务 200 条演示、10 个消融变体、延迟敏感性曲线与未见物体泛化，并同时报告成功率、峰值接触力与完成时间三类指标。

## 8. 不足与局限

- **力感知精度受限**：两平台均使用机器人关节力矩估计的扳量，**未使用专用腕部力/力矩传感器**，作者也把"引入高精度力/力矩传感器"列为未来工作，因此对精细力控任务的适用性存疑。
- **缺乏恢复行为**：失败分析表明系统不具备"回退—重新对准—再次插入"的恢复能力，一旦卡死或接触几何错误，修正项无法改变接近方向。
- **参考更新延迟仍是瓶颈**：约 5 Hz 的参考刷新与 189.7 ms 的单次前向在延迟注入下明显退化（200 ms 时降 15 个百分点），说明慢通路的实时性仍是系统上限。
