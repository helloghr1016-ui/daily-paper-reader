## 摘要
我们研究具有线性函数逼近的联邦在线强化学习。虽然近年来的多智能体强化学习算法实现了很强的遗憾保证，但它们通常需要共享原始轨迹。这种依赖导致的通信成本随回合数线性增长，并违反联邦设置的隐私约束。为解决这些限制，我们提出 Fed-LSVI，这是第一个在情景马尔可夫决策过程中具有线性函数逼近的可证明高效联邦在线强化学习算法。通过将基于行列式的事件触发同步与逐步反向更新机制相结合，Fed-LSVI 使多个智能体能够仅通过交换压缩的充分统计量来协作学习最优策略。我们证明 Fed-LSVI 达到 $\widetilde{\mathcal O}(\sqrt{Md^3H^4T})$ 的遗憾界，其中 $d$ 是特征维度，$H$ 是视界长度，$M$ 是智能体数量，$T$ 是每个智能体的回合数，与具有线性函数逼近的多智能体在线强化学习的最佳已知遗憾相匹配。此外，通过遵循联邦设置的严格通信与隐私约束，Fed-LSVI 将通信成本降低到仅对 $T$ 呈对数依赖，相较于先前方法有显著改进。

## Abstract
We study federated online reinforcement learning with linear function approximation. While recent multi-agent reinforcement learning algorithms achieve strong regret guarantees, they typically require sharing raw trajectories. This reliance incurs a communication cost that scales linearly with the number of episodes and violates the privacy constraints of federated settings. To address these limitations, we propose Fed-LSVI, the first provably efficient federated algorithm for online reinforcement learning with linear function approximation in episodic Markov decision processes. By integrating a determinant-based event-triggered synchronization with a stepwise backward update mechanism, Fed-LSVI enables agents to collaboratively learn an optimal policy by exchanging only compressed sufficient statistics. We prove that Fed-LSVI achieves a regret bound of $\widetilde{\mathcal O}(\sqrt{Md^3H^4T})$, where $d$ is the feature dimension, $H$ is the horizon length, $M$ is the number of agents, and $T$ is the number of episodes per agent, matching the best-known regret for multi-agent online reinforcement learning with linear function approximation. Moreover, by following the stringent communication and privacy constraints of the federated setting, Fed-LSVI reduces the communication cost to only logarithmic dependence on $T$, representing a significant improvement over prior methods.

## 2. 论文提出的方法论

- **系统模型**：
  - \(M\) 个智能体与一个中心服务器，每个智能体在自己的本地 MDP 上执行 \(T\) 个回合；
  - 中心服务器只接收统计量，不接收原始轨迹；
  - 学习过程分为若干通信轮 \(k=1,\dots,K\)，同一轮内所有智能体执行相同策略。

- **两个关键设计**：
  1. **基于行列式的事件触发同步**：
     - 每个智能体在本轮本地累积协方差矩阵 \(\Lambda_{m,h}^{\text{loc}}\)；
     - 若存在某个步 \(h\) 满足触发条件
       \[
       \frac{\det(\Lambda_h^{\text{ser}} + \Lambda_{m,h}^{\text{loc}})}{\det(\Lambda_h^{\text{ser}})} \ge \gamma^{\Delta t}
       \]
       或达到总回合预算 \(t=T\)，则触发一次全局同步；
     - 该机制避免冗余通信，使通信轮数对数增长。
  2. **逐步反向同步协议**：
     - 经典 LSVI 使用后向更新：第 \(h\) 步回归目标依赖第 \(h+1\) 步最新值函数；
     - 联邦设置下，若一次性上传所有统计量，第 \(h\) 步会使用过时的 \(V_{h+1}\)，产生严重偏差；
     - Fed-LSVI 从 \(h=H\) 到 \(h=1\) **逐层同步**：每层智能体用刚广播的最新全局 \(V_{h+1}\) 构造局部响应
       \[
       b_{m,h} = \sum_{(x,a,r,x')\in D_{m,h}} \phi(x,a)\bigl(r + V_{h+1}(x')\bigr),
       \]
       并上传 \(( \Lambda_{m,h}^{\text{loc}}, b_{m,h})\)；服务器聚合后解岭回归
       \[
       w_h = (\Lambda_h^{\text{ser}})^{-1} b_h,
       \]
       再广播 \((w_h,\Lambda_h^{\text{ser}})\)，保证第 \(h\) 步模型与最新全局值函数一致。
- **探索策略**：
  - 利用乐观 Q 值：
    \[
    Q_h(x,a) = \Pi_{[0,H]}\left(\phi(x,a)^\top w_h + \beta \|\phi(x,a)\|_{(\Lambda_h^{\text{ser}})^{-1}}\right),
    \quad V_h(x) = \max_{a} Q_h(x,a)
    \]
  - 执行贪婪策略 \( \pi_h(x) = \arg\max_a Q_h(x,a)\)。

## 6. 论文的主要结论与发现

- **同质设置**：当所有智能体共享相同 MDP 时，
  \[
  \operatorname{Regret}(T) \le \widetilde{\mathcal O}\bigl(\sqrt{M d^3 H^4 T} + M H^2 d^2 \sqrt{\gamma}\bigr).
  \]
  当 \(T \ge M d\) 且 \(\gamma = T/(Md)\) 时，主项为 \(\widetilde{\mathcal O}(\sqrt{M d^3 H^4 T})\)，体现 \(\sqrt{M}\) 多智能体加速。
- **误指定/异构设置**：当每个智能体的 MDP 与公共参考线性 MDP 偏差水平为 \(\xi\) 时，
  \[
  \operatorname{Regret}(T) \le \widetilde{\mathcal O}\bigl(\sqrt{M d^3 H^4 T} + M d^2 H^2 \sqrt{\gamma} + \xi M d H^2 T + \xi \sqrt{M^3 d^3 H^4 \gamma T}\bigr).
  \]
  若 \(\xi = \widetilde{\mathcal O}(\sqrt{d/(MT)})\)，则恢复同质设置的 regret bound。
- **通信成本**：
  - 通信轮数
    \[
    K \le 1 + \frac{2T}{\gamma} + \frac{dH}{\log 2} \log\left(1 + \frac{MT}{d}\right).
    \]
  - 取 \(\gamma = \max\{T/(Md),1\}\) 时，\(K = \widetilde{\mathcal O}(M d + dH \log(MT/d))\)；
  - 每轮只传输 \(O(M H d^2)\) 个标量，总通信成本
    \[
    O\left(M^2 d^3 H + M d^3 H^2 \log\left(1 + \frac{MT}{d}\right)\right),
    \]
    对 \(T\) 对数依赖，而先前方法需 \(O(MHT)\) 线性通信。
- **单智能体特例**：当 \(M=1\) 时，Fed-LSVI 退化为低切换成本 LSVI-UCB，仍保持 \(\widetilde{\mathcal O}(\sqrt{d^3 H^4 T})\) 遗憾，切换成本对数。

## 7. 优点
