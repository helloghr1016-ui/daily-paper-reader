## 摘要
四足机器人运动策略通常通过强化学习训练，而强化学习又高度依赖手工设计的奖励函数。设计奖励函数需要大量人工工程，且通常不清楚哪些局部奖励会诱导期望的全局行为。基于信号时序逻辑（STL）等形式语言中形式化规范所塑造的奖励可使奖励更具可解释性，但编写STL规范本身仍需要领域专业知识。我们研究大语言模型（LLM）是否可以通过生成参数化信号时序逻辑（PSTL）规范来填补这一空白，并将其用于后续策略学习。给定自然语言运动目标和受限的规范语法，GPT-5.5和Qwen 3.6分别提出用于指令跟踪、安全性和步态结构的STL模板。我们利用专家轨迹实例化所生成PSTL模板的参数，并仅保留与所示专家行为一致的规范。随后将所得规范转换为平滑的有限历史奖励函数，并在MuJoCo XLA（MJX）中使用近端策略优化（PPO）训练四足运动策略。我们评估了“步态感知”和“步态无关”两种设置。前者指定行走小跑（walking-trot）、小跑（trot）和跳跃（bound）步态模式，后者允许接触模式从任务目标中涌现。我们与手工设计奖励、Text2Reward风格的LLM生成奖励代码以及专家切换预言机进行了比较。步态感知的Qwen 3.6规范在所有测试速度（0.3--2.1 m/s）下实现了100%的存活率和指令成功率，并在高速时匹配目标步态，而Text2Reward在≥1.9 m/s时两项指标均为0%。视频：https://stl-locomotion.github.io/

## Abstract
Quadruped robot locomotion policies are often trained using reinforcement learning, which in turn relies heavily on hand-crafted reward functions. Designing reward functions requires substantial manual engineering, and it is often unclear which local rewards will induce the desired global behavior. Shaped rewards from formal specifications in languages like Signal Temporal Logic (STL) can make rewards more interpretable, but writing STL specifications itself still requires domain expertise. We study whether large language models (LLMs) can fill this gap by generating Parametric Signal Temporal Logic (PSTL) specifications that are subsequently used for policy learning. Given a natural language locomotion objective and a constrained specification grammar, GPT-5.5 and Qwen 3.6 independently propose STL templates for command tracking, safety, and gait structure. We instantiate the parameters of the generated PSTL templates using expert trajectories and retain only specifications that are consistent with demonstrated expert behavior. The resulting specifications are then transformed into smooth, finite-history reward functions and used to train a quadruped locomotion policy with Proximal Policy Optimization (PPO) in MuJoCo XLA (MJX). We evaluate both \emph{gait-aware} and \emph{gait-agnostic} settings. The former specifies walking-trot, trot, and bound regimes, while the latter allows contact patterns to emerge from the task objective. We compare against hand-engineered rewards, Text2Reward-style LLM-generated reward code, and an expert-switching oracle. Gait-aware Qwen 3.6 specifications achieved 100\% survival and command success across all tested speeds (0.3--2.1 m/s) and matched the target gait at high speeds, whereas Text2Reward achieved 0\% for both metrics at $\geq 1.9$ m/s. ## 2. 论文提出的方法论

### 2.1 总体流水线

- LLM（GPT-5.5 和 Qwen 3.6）接收：
  1. 自然语言描述的 Barkour 四足运动目标；
  2. 一个受约束的 STL 语法。
- 要求 LLM **只生成符号化的 STL 模板结构**，不生成具体数值阈值或时间常数；这些参数留待从专家数据中估计。
- 对生成的 PSTL 模板，使用专家轨迹进行参数实例化；
- 利用**专家一致性过滤**剔除与专家行为系统性冲突的规范；
- 将保留的规范通过 STL 定量鲁棒性转化为密集奖励；
- 用 PPO 在 MuJoCo XLA（MJX）中训练策略。

### 2.2 STL 与 PSTL

- 谓词形式：\(f(x(t)) \ge 0\)。
- 时序算子：\(G_{[a,b]}\)（区间内全局成立）、\(F_{[a,b]}\)（区间内某时成立）。
- 定量语义：鲁棒性 \(\rho_\varphi(x,t)\in\mathbb{R}\)，正值表示满足，负值表示违反。
- PSTL 将数值常量或时间区间替换为可拟合参数。

### 2.3 关键模板示例

论文给出了若干典型模板族：

- **力矩限制**：\(\varphi_\tau = G_W\left(\bigwedge_{j=1}^{12} |\tau_j| \le \tau_{\max}\right)\)
- **躯干姿态**：\(\varphi_\phi = G_W(|\phi| \le \phi_{\max}), \quad \varphi_\theta = G_W(|\theta| \le \theta_{\max})\)
- **质心高度**：\(\varphi_z = G_W(z_{\text{com}} \ge z_{\min})\)
- **支撑接触**：\(\varphi_c = G_W(n_c \ge n_{\min})\)
- **线速度跟踪**：\(\varphi_{v_i} = G_W(|v_i - v_i^{\text{cmd}}| \le \epsilon_{v,i})\)

数值参数 \(\phi_{\max},\theta_{\max},z_{\min},n_{\min},\epsilon_{v,i}\) 等不由 LLM 生成，而是从专家轨迹中估计。

### 2.4 鲁棒性计算与奖励聚合

- 评估窗口：\(W_t = \{t-H,\dots,t\}\)，\(H\) 为鲁棒性时域。
- 对 \(G_W \mu\) 形式：\(\rho_{G_W \mu}(t) = \min_{k\in W_t} \rho_\mu(k)\)，即窗口内最差谓词裕度。
- 多组鲁棒性通过**软最小聚合**：

\[
\text{smin}_\beta(z_1,\dots,z_K) = \sum_{k=1}^K \pi_k z_k, \quad \pi_k = \frac{e^{-\beta z_k}}{\sum_{j=1}^K e^{-\beta z_j}}
\]

- 最终奖励：

\[
r_t = w_{\text{safe}}\tanh(\mu_{\text{sa}}) + w_{\text{track}}\tanh(\mu_{\text{tr}}) + w_{\text{pattern}}\tanh(\mu_{\text{pa}})
\]

- 分解为安全、跟踪、步态模式三组，各组鲁棒性经 \(\tanh\) 归一化到 \([-1,1]\)，提高可解释性。

### 2.5 数据接地与专家一致性过滤

- 每个速度模式收集 50 条专家轨迹，每条 500 步。
- 对每个模板，按谓词方向选择合适分位数估计参数：误差上限用上分位数，安全下限用下分位数。
- 专家一致性过滤：对规范 \(\varphi\)，计算其在所有专家轨迹上的鲁棒性集合 \(R_\varphi\)，保留当且仅当

\[
Q_{0.50}(R_\varphi) \ge 0
\]

即若中位鲁棒性为负（在超过一半专家评估点被违反），则丢弃该规范。

### 2.6 多步态 vs 步态无关设置

- 使用 Froude 数 \(Fr = v^2/(gh)\) 确定步态切换阈值，基于 Barkour 腿长 0.41 m 和参考 Froude 数 0.15、0.74，得到 0.7 m/s 和 1.7 m/s 两个阈值。
- **步态感知（multi-gait）**：行走小跑（0–0.7 m/s）、小跑（0.7–1.7 m/s）、跳跃（>1.7 m/s），训练单一策略在不同速度段切换步态。
- **步态无关（gait-agnostic）**：不指定步态，让接触模式从任务目标中自然涌现。

## 6. 论文的主要结论与发现

- **步态无关设置**：GPT-GA 和 Text2Reward-GA 在全部速度范围实现 100% 跟踪成功率和生存率，且 CoT 最低；但视觉检查发现它们在低速时仍采用 bound 式高频步态，产生显著身体振荡，说明**仅靠速度跟踪成功并不能保证运动质量**。
- **步态感知设置**：Qwen-MG 在 0.3–2.1 m/s 全范围实现 100% 生存率和指令成功率，并在高速段匹配目标 bound 步态；Text2Reward-MG 在 ≥1.9 m/s 时两项指标均为 0%，全面失败。
- **GPT-5.5 vs Qwen 3.6**：LLM 生成规范的质量**高度依赖控制设置**。步态无关时 GPT 更强，步态感知时 Qwen 更强。
- **STL 中间表示的价值**：相比 Text2Reward 直接生成奖励代码，STL 规范更适合编码高速时序约束，能够在高速下保持稳定；但这不保证所有预期步态结构都能恢复。
- **鲁棒性窗口 \(H\)**：较短窗口（\(H=1,5\)）通常更稳定、更高效；过长窗口（\(H=20,30\)）会保留历史违反信息，导致信用分配困难，性能下降。

## 7. 优点

- **新颖的奖励设计范式**：让 LLM 生成符号化 PSTL 结构而非数值奖励代码，将“结构设计”与“参数拟合”分离，兼顾 LLM 的语义理解与专家数据的可靠性。
- **专家一致性过滤**：用专家轨迹中位鲁棒性作为筛选标准，能自动剔除 LLM 提出的系统性过严/不合理规范，提高生成规范质量。
- **可解释性强**：奖励由安全、跟踪、步态模式三部分构成，每部分对应明确的 STL 规范，训练中可分别监控鲁棒性，便于调试和审计。
- **实验对比全面**：包含手工奖励、人工 STL、两种 LLM、Text2Reward、专家 oracle，并覆盖步态感知/无关两个维度，结论信息量大。
- **发现重要负面结果**：指出“高跟踪成功率”并不等于“高质量运动”，强调多步态显式规范的价值。
- **平滑鲁棒性聚合**：使用软最小和 \(\tanh\) 归一化，避免个别鲁棒性量级主导奖励。
