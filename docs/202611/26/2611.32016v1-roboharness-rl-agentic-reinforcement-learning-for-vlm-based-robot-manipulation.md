## 摘要
智能体式工具框架（agentic harnesses）使前沿视觉语言模型（VLM）能够通过感知、规划和控制工具来操作机器人，然而让紧凑的开源权重VLM达到可比性能仍具挑战。我们提出RoboHarness-RL，一个通过工具调用改进基于VLM的机器人操作的智能体强化学习框架。该VLM从对成功教师演示的监督微调出发，进一步通过带有任务结果奖励的多轮强化学习得到提升，而不依赖视觉-语言-动作模型或世界动作模型。为支持高效的多轮训练，我们开发了LiteHarness，它使用分层记忆在保持任务性能的同时使交互上下文保持紧凑。在Qwen3.5-9B上，RL将RoboTwin 2.0上的成功率从31.2%提升至44.0%，将LIBERO-Pro上的成功率从57.8%提升至73.3%；这些增益也扩展到训练中未见的随机化RoboTwin场景（26.4%至38.0%）。行为分析进一步表明，RL将重复调用率最多降低$4\times$，缩短成功执行时间，并改善从负面反馈中的恢复能力。项目页面：https://aim-uofa.github.io/RoboHarness-RL/

## Abstract
Agentic harnesses enable frontier vision-language models (VLMs) to manipulate robots through perception, planning, and control tools, yet achieving comparable performance with compact open-weight VLMs remains challenging. We present RoboHarness-RL, an agentic reinforcement learning framework for improving VLM-based robot manipulation through tool calls. Starting from supervised fine-tuning on successful teacher demonstrations, the VLM further improves through multi-turn reinforcement learning with task-outcome rewards, without relying on vision-language-action models or world action models. To support efficient multi-turn training, we develop LiteHarness, which uses hierarchical memory to keep interaction contexts compact while preserving task performance. With Qwen3.5-9B, RL raises success from 31.2% to 44.0% on RoboTwin 2.0 and from 57.8% to 73.3% on LIBERO-Pro; these gains extend to randomized RoboTwin scenes unseen during training (26.4% to 38.0%). Behavioral analysis further shows that RL reduces repetitive-call rates by up to $4\times$, shortens successful executions, and improves recovery from negative feedback. ## 1. 核心问题与研究动机

- **背景**：智能体式工具框架（agentic harness）让 VLM 通过感知、规划、控制等工具调用来操控机器人，使 VLM 从“只做高层决策”延伸到直接指定末端位姿与夹爪指令。
- **核心矛盾**：前沿闭源模型（如 DeepSeek-V4.1-Flash）在 ORA 框架下随机化 RoboTwin 可达 69.2%，而开源紧凑模型 Qwen3.5-9B 仅 6.8%，差距巨大。
- **现有改进路径**：优化 harness 设计，或通过监督蒸馏把前沿模型能力迁移到小模型；但**模仿学习之后是否还能通过模型自身交互的强化学习进一步提升**，尚不清楚。
- **方法定位**（Fig. 2）：介于两条研究线之间——比 VLA/WAM 的 RL（低层电机/动作块）更抽象，比 LLM 智能体 RL（搜索、GUI 点击等纯文本动作）更细粒度，即**带连续参数（位姿、夹爪）的工具调用式智能体 RL**。
- **两大工程挑战**：
  - 每次模型调用都携带不断增长的交互历史（含图像），单回合可达 200 次调用，rollout 与策略更新成本极高；
  - 当前策略稳定成功或稳定失败的任务几乎不提供组相对学习信号，却仍消耗 rollout 预算。

## 2. 方法论

### 2.1 总体框架（Fig. 3）
两阶段训练，**只优化 VLM 策略**，感知模型与运动规划器全部冻结，不使用 VLA 或世界动作模型：
1. **教师示范 SFT**：用 GPT-6 Astra 在相同 harness 下采集成功轨迹，以学生视角的上下文为输入、教师响应为目标做监督微调；
2. **多轮智能体 RL**：以任务成败为奖励，用 GRPO 做多轮策略优化。

### 2.2 LiteHarness：轻量级工具框架
- **工具接口**：20 个工具（RoboTwin）/18 个（LIBERO-Pro），分两类——
  - *只读查询*：`observe`、`vision_ground`（SAM 3）、`vision_segment`、`mark_point`、`geometry_query`、`grasp_plan`（Contact-GraspNet）、`align_plan`、`compute`、`check_task` 等；
  - *改变世界动作*：`grasp_execute`、`move_pose`、`move_to`、`set_gripper`、`rotate_wrist/pitch`、`recover_pose`、`wait_ticks`、`finish_episode` 等，必须单独成轮并结束当前回合。
  - 学生使用精简版工具描述（RoboTwin 16.7K 字符 vs 教师 65.0K），首轮 prompt 约 12.5K token（ORA 约 31K）。
- **分层记忆**（核心创新）：上下文写为 `h_t = [S_t; F_t; R_t]`
  - `S_t` 历史摘要：旧步骤压缩为“动作+结果”一行，只读查询被删除；
  - `F_t` 失败记录：所有失败动作与被拒调用（含参数与原因），保留最近 20 条；
  - `R_t` 近期窗口：当前步 + 前 K=3 步，观测文本截断至 2500 字符，旧查询压缩为 ≤300 字符文本 + ≤900 字符结果摘要；
  - **图像单独更短窗口**：仅当前与前 2 步，工具预览图跨步丢弃，单次请求上限 `B_img = 24` 张；
  - 全部操作为确定性规则，**不额外调用模型**。

### 2.3 GRPO 训练细节
- **奖励**：`r_i = 1[success_i] − λ·min(e_i, c)/c`，其中 `e_i` 是负向 `check_task` 后、下一次机器人动作前“空转查询”的次数（每次超出前 4 次计），λ=0.5、c=160，保证惩罚不超过成功奖励的一半。
- **组相对优势**：`A_i = r_i − (1/G)Σr_k`，G=8；每条响应继承轨迹优势，再减去无效调用惩罚 `p_{i,t}=0.05`（单回合封顶 0.5），并乘权重 `M̄/M_i` 抑制长失败轨迹主导梯度。
- **策略损失**：PPO 裁剪代理 + 双裁剪（ε=0.2，负优势 token 损失上限 3|A|），无 KL 惩罚，加熵正则 β=1e-3；用 token 级截断重要性比 `w = min(π_old/π_vLLM, 2)` 修正推理/训练概率差。
- **无效组过滤**：奖励极差 < 0.05 的组视为无信息，不参与更新。
- **LoRA**：rank 16、α=32，作用于语言模型全部线性层，视觉编码器冻结。

### 2.4 交互预算与自适应任务调度
- 每回合受模型调用预算 `B_call ∈ {80,120,160,200}`（按任务设定）与机器人动作预算 `B_act = 80` 双重限制。
- **调度三规则**：
  1. 最近一组 8 条 rollout 全成功的任务，跳过 1 个采样周期，但下次优先重访；
  2. 连续两个采样组均失败的任务，在阶段边界移出任务池（RoboTwin 第 15 轮移出 5 个）；
  3. LIBERO-Pro 从第 12 轮起，每轮 12 组中 8 组来自更难的 Goal/Long 套件，4 组来自 Spatial/Object。

## 6. 主要结论与发现

- **RL 显著超越模仿**：RoboTwin clean 31.2%→44.0%（+12.8pp，与 SFT 带来的 +11.2pp 相当）；LIBERO-Pro 57.8%→73.3%（+15.5pp）；随机化场景 26.4%→38.0%（+11.6pp），泛化到未见视觉条件。
- **最难套件增益最大**：Goal +31.0/+22.0pp、Long +23.0/+13.0pp（Task/Swap），Spatial/Object 起点高、增益 0–18pp。

- **改进远多于退化**：LIBERO-Pro 800 对中 155 个 SFT 失败转为成功，仅 31 个反向；RoboTwin clean 19 升 9 降。
- **行为变化**：
  - 重复调用率从约 10% 降至 2.5–2.8%（RoboTwin），LIBERO-Pro 9.1%→5.7

- 重复调用率从约 10% 降至 2.5–2.8%（RoboTwin），LIBERO-Pro 9.1%→5.7%，说明策略学会了记住已执行过的动作与已获得的信息，而不是反复试探。
- **空转查询显著减少**：负向 `check_task` 之后继续做只读查询而不采取机器人动作的行为被奖励项直接压制，RL 后策略更倾向于“检查失败→立即换一个物理动作”，而非在原地反复观察。
- **失败恢复能力增强**：在需要从抓取滑脱、对位偏差中恢复的任务上，RL 策略表现出更多 `recover_pose` / 重新 `grasp_plan` 的序列，而 SFT 策略更倾向于重复同一失败动作或以 `finish_episode` 提前终止。
- **回合效率提升**：成功回合的平均模型调用数与机器人动作数下降，说明增益并非来自“用更多预算硬试”，而是来自更有效的动作选择；这一点对反驳“RL 只是延长了探索”很关键。
- **工具使用分布偏移**：RL 后几何类查询（`geometry_query`、`align_plan`）与执行类动作的配比更紧凑，减少了纯描述性观察的占比。
- **残余失败模式**：仍失败的情形主要集中在需要长时序多阶段协同（Long 套件）、以及感知模块本身给出错误分割/抓取候选的任务上，提示瓶颈已从“策略决策”部分转移到“冻结感知/规划器”的上限。
- **与教师的关系**：RL 后的学生并非简单逼近教师分布——它在教师也失败的任务上取得非零成功率，说明 RL 带来的是超越蒸馏的能力，而非对教师行为的复刻。

## 7. 局限与作者承认的问题

- **统计效力有限**：每个基准仅训练 1 条 RL 轨迹、每个报告检查点仅评估 1 次，置信区间只反映回合级采样方差，不覆盖训练随机性（种子方差）。作者在附录 F 中明确说明，严格结论需要多种子重复。
- **强依赖闭源教师**：SFT 阶段完全依赖 GPT-6 Astra 的 API 与成功率，教师不可用或成本变化会直接影响方法可复现性；论文未给出用较弱教师或纯 RL（无 SFT 初始化）的对照。
- **仅在仿真中验证**：RoboTwin 2.0 与 LIBERO-Pro 都是仿真基准，未做真机迁移实验；考虑到方法依赖精确的位姿工具与仿真成功判定，sim-to-real 的可行性未被检验。
- **算力门槛高**：单基准约 415 GPU 小时、8×H200 单节点逾 50 小时，且策略更新占总时间 2/3 以上，对小规模研究团队不友好。
- **奖励设计含手工超参**：空转惩罚的 λ、c、前 4 次豁免、无效组阈值 0.05、无效调用惩罚 0.05 等均为人工设定，缺少敏感性分析。
- **任务池调度可能掩盖难度**：连续失败任务被移出训练池，虽提升了采样效率，但也意味着某些任务从未获得充分学习机会；论文未报告被移出任务在最终评估中的表现变化。
- **冻结感知与规划器**：这是有意的简化（隔离策略学习），但同时构成性能天花板；论文的失败分析也指向感知误差是残余失败的重要来源。
- **harness 工具集为手工设计**：20/18 个工具、分层记忆的窗口大小（K=3、2500 字符、24 张图）等均为经验设定，缺少系统性搜索。

## 8. 批判性评价

**优点**
- 问题定位清晰：明确把“模仿之后还能否用自身交互继续提升”作为一个可证伪的实证问题，并用同一 harness、同一初始状态、同一评估协议做三阶段受控对比，因果链条较干净。
- 工程贡献实在：分层记忆 + 图像短窗口 + 无效组过滤 + 自适应任务调度，针对的是 agentic RL 真实存在的成本瓶颈（上下文膨胀、无信息组），这些设计对其他长程工具调用智能体同样可迁移。
- 评估较严谨：训练/评估初始状态不相交、随机化集完全未见、使用官方成功判定、提供配对 McNemar 与 bootstrap 区间，并公开逐任务结果。
- 结论有“反直觉”价值：RL 解出了教师 21 次都失败的任务，且改进/退化比约 5:1，说明 RL 不是单纯把策略拉回教师分布。

**可质疑之处**
- 单种子 + 单次评估使 +11~15pp 的增益虽在回合级显著，但训练方差未知；若种子间波动达到数个百分点，部分子套件结论（如 Spatial 的 0pp 增益）可能不稳。
- 与 ORA、K1 等基线虽在相同回合上重跑，但基线是否使用了同等调优预算（提示词、工具描述长度、重试策略）未完全展开，存在“工程调优不对等”的风险。
- “教师失败任务被 RL 解出”这类结论样本量小（单任务 10 次评估、7 次成功），更适合作为定性证据而非统计结论。
- 方法把感知、规划、成功判定都放在学习回路之外，因此结论的适用范围应限定为“工具已足够好、瓶颈在决策”的场景；对感知薄弱或工具缺失的域，外推需谨慎。
- 缺少与“纯 SFT 但更多数据/更长训练”的对照，无法完全排除增益部分来自额外优化步数而非 RL 本身。

## 9. 对领域的启示

- **工具调用式智能体的 RL 是可训练且高回报的**：在连续参数动作（位姿、夹爪）层面做组相对策略优化，能在不训练 VLA 的前提下获得两位数提升，为“轻量模型 + 强 harness + RL”提供了一条务实路线。
- **上下文工程是 agentic RL 的一等公民**：分层记忆与图像窗口直接决定了 rollout 成本与可训练性；在长程任务上，记忆设计的影响可能不亚于算法选择。
- **数据效率的关键在“筛组”而非“加样本”**：无效组过滤与自适应任务调度把有限 rollout 预算集中到有梯度信号的任务上，这一思路可推广到其他稀疏奖励的多轮智能体训练。
- **蒸馏与 RL 是互补而非替代**：SFT 提供可用的初始策略与工具使用格式，RL 负责修正教师的系统性失败模式并压缩冗余行为；两者叠加才达到最终水平。
- **下一步值得做的实验**：多种子重复、真机迁移、可训练感知模块的端到端联合优化、教师质量敏感性分析、以及奖励设计中引入过程性信号（如子目标完成）以进一步缓解稀疏性。
