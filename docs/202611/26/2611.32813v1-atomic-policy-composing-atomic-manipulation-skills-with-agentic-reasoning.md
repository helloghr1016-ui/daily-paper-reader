## 摘要
长时程操作要求机器人在场景变化时将任务意图转化为物理交互。视觉语言模型（VLM）提供语义与空间推理，而视觉运动策略提供精细控制。然而，模糊的目标以及动作之间的依赖关系使其集成颇具挑战。我们提出 Atomic Policy，一个通过基于场景的引导和执行反馈来组合已学习操作技能的框架。VLM 估计符号状态与目标，PDDL 求解器构建技能计划。一个智能体式执行框架通过语言、视觉指向或二者兼用来引导每项技能，并验证其结果以指导阶段转换和重新规划。一个通用的阶段级接口支持专用策略和通用动作模型。仿真和真实机器人实验表明，Atomic Policy 如何改善任务遵循，并支持复杂长时程操作中的恢复。项目页面：https://aaronzkd.github.io/atomic-policy/

## Abstract
Long-horizon manipulation requires robots to translate task intent into physical interactions as the scene changes. Vision-language models (VLMs) offer semantic and spatial reasoning, while visuomotor policies provide fine-grained control. Yet ambiguous goals and dependencies between actions make their integration challenging. We introduce Atomic Policy, a framework that composes learned manipulation skills through grounded steering and execution feedback. A VLM estimates the symbolic state and goal, and a PDDL solver constructs a skill plan. An agentic harness steers each skill through language, visual pointing, or both, and verifies its outcome to guide phase transitions and replanning. A common phase-level interface supports specialized policies and generalist action models. Experiments in simulation and on a real robot show how Atomic Policy improves task following and supports recovery in complex, long-horizon manipulation. ## 1. 核心问题与研究动机

- **背景**：长程操作（long-horizon manipulation）要求机器人在场景随每次交互变化的过程中，把任务意图转化为物理动作。语言指令往往不给出中间步骤，一次失败的动作又会改变后续可行性。
- **能力割裂**：VLM 擅长语义与空间推理，可解释指令、协调感知/规划/控制；视觉运动策略（模仿学习、VLA）擅长精细控制与语义泛化。但二者难以直接衔接。
- **已有方法的不足**：
  - 解析式基元难以应对复杂抓取、受限放置、铰接物体交互；
  - 端到端 VLA 在“把熟悉行为重定向到新目标”或“以新顺序组合技能”时可靠性不足；
  - 现有技能编排工作（代码化技能、策略编排、世界模型引导切换）较少同时解决“如何引导技能”与“如何根据执行结果调整”。
- **核心问题**：任务级推理如何引导局部运动行为，同时对其执行结果保持响应——即把“有依据的引导（grounded steering）”与“验证（verification）”纳入技能组合本身。
- **整体含义**：论文提出 **Atomic Policy**，将局部操作技能与任务级推理/组合解耦：原子技能是可复用、带相位级完成条件的行为单元，由 VLM+PDDL 负责编排，由语言/视觉指向负责引导，由 VLM checker 负责推进与重规划。

## 2. 方法论

### 2.1 核心思想
- 用**相位（phase）** 作为统一抽象：每个相位 `Pk = (sk, gk)`，`sk` 为原子技能，`gk` 为目标描述（可为空 ∅）。
- 一个相位可跨越多个控制步与多次策略查询，其完成由“相位级完成条件 + 视觉证据”判定。
- 同一接口同时支持**专用视觉运动策略**与**通用动作模型（VLA）**。

### 2.2 关键技术流程（闭环）
1. **状态与目标估计**：给定 PDDL 域 `D`、指令 `ℓ`、当前主相机图像，VLM 输出当前成立的地面谓词 `x̂t` 与目标谓词 `G`。
2. **符号规划**：PDDL 求解器（对地面状态做广度优先搜索，域内算子 ≤5 个）返回最短算子序列，并映射为相位序列 `Pt = Solve(D, x̂t, G)`；算子通过前置条件/效果保证依赖关系（如先 grasp 再 open、先 pick 再 place）。
3. **引导（steering）**：
   - **点引导**：对依赖目标的相位，将 `gk` 转为指代查询（如“Point to the blue cube”），MolmoPoint 返回归一化 2D 点 `pk ∈ [0,1]²`，执行中每 R 步刷新；
   - **语言引导**：用相位模板生成短指令 `ℓk`（如“grasp the blue cube and lift it”）；
   - 也可二者结合；无目标相位省略点输入。
4. **执行**：策略以动作块形式输出 `At ∼ π_sk(· | ot, uk)`，`uk` 为点、语言或二者。
5. **验证与重规划**：VLM checker 每 C 步结合主相机、腕部相机与夹爪开合度，按相位检查清单返回 `done`（推进）/`not_done`（继续）/`replan`（重规划）；相位超时 T 步也触发重规划。重规划从最新观测重新估计状态并求解，已满足的目标不再重复执行。
6. **算法流程（Algorithm 1）**：规划 → 循环{刷新点 → 执行动作块 → 检查 → done 则 k+1；replan 或超时则重新规划并 k←1}。

### 2.3 实现细节
- **专用技能库**：每个相位一个 Diffusion Policy（1D 卷积 U-Net 去噪器），条件输入为多视角历史帧经共享视觉编码器 φ 的特征、本体状态、以及点特征 `ψ(pk)`（三层 MLP 映射到 128 维）；默认编码器 CLIP ViT-B/32，以 1/10 学习率全量微调。
- **腕部相机指向**：不依赖图像跟踪（SAM 2 会漂移），而是维护基座系 3D 目标 `xk`，用 `wt = Π(E(qt)⁻¹ xk)`、`E(qt) = F(qt)Ecam` 投影到腕部图像，并附几何可见性标志 `νt`；标定由演示自动估计，重投影中位误差 8.0 像素。
- **训练增强**：腕部坐标加 σ=0.02 高斯噪声，以 0.15 概率掩码腕部点与可见性标志。
- **通用模型实例**：π0.5 仅用相位语言提示（其原生接口不支持点条件）；MolmoBot 接收相位提示 + 原生 `<points>` 标签点。
