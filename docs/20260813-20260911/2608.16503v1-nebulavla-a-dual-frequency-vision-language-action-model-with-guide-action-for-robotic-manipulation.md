## 摘要
视觉-语言-动作（VLA）模型的实际部署往往受限于效率与性能的权衡、跨具身泛化能力以及执行平滑性。我们提出 NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源与模块化。为弥合异构机器人之间的语义鸿沟，我们引入 GESTURE-7，一种统一的基于语言的动作表示。此外，我们的 Guide Action 算法通过基于掩码的平滑约束来保证运动学连续性。综合评估表明，NebulaVLA 显著优于同步基线，在 LIBERO-Plus 上达到 85.5% 的平均成功率，并将动作生成速度提升约 2.7 倍。这种异步设计为实际机器人提供了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 2. 方法论

### 2.1 核心思想：异步双频架构

NebulaVLA 基于“快—慢认知”范式，将系统解耦为两个频率不同的模块：

- **System 2（S2，约 10 Hz）**：高层语义规划，使用 Qwen3-VL 视觉语言主干处理自然语言指令和稀疏视觉输入，输出抽象动作引导。
- **System 1（S1，约 20 Hz）**：低层动作控制器，基于 DiT（Diffusion Transformer）扩散生成器，接收 S2 的引导、高频视觉输入和动作历史，生成具体执行动作。

该解耦设计支持分布式部署：S2 与 S1 可运行在不同计算设备上，减少交互延迟、提高硬件利用率。

### 2.2 统一动作表示：GESTURE-7

GESTURE-7 是一种 7 维连续末端执行器状态向量：

\[
s = [x, y, z, r, p, w, gesture]
\]

- \(x,y,z\)：笛卡尔位置（厘米，整数）。
- \(r,p,w\)：滚转、俯仰、偏航角（度，整数）。
- \(gesture\)：自然语言关键词（如 `grasp`、`push`、`rotate`、`release`），统一描述不同末端执行器的目标手部姿态。

这种表示使不同机器人执行同一动作时共享相同关键词，从而统一异构具身语义，并可与语言条件强化学习无缝结合。

### 2.3 三阶段训练流程

1. **Stage 1：System 2 监督微调（SFT）**
   - 初始化：Qwen3-VL 原始权重，不进行额外大规模预训练。
   - 任务类型：姿态回归、2D 关键点回归、2D 航点预测、3D 轨迹预测、链式思维（CoT）任务分解与未来 GESTURE-7 轨迹生成。

2. **Stage 2：System 2 强化学习（RL）**
   - 使用 GRPO 算法继续优化 S2 的轨迹规划能力。
   - 奖励函数包括：GESTURE-7 距离、关键点定位奖励、航点奖励（欧氏距离 + DTW）、轨迹奖励、格式奖励。

3. **Stage 3：System 1 监督微调**
   - 联合优化 S2 与 S1 权重，但冻结各自的视觉编码器。
   - 使用加权 flow-matching 损失，但损失只施加于 Guide Action 机制中掩码 \(M=0\) 的新生成区域（见式 3）。

### 2.4 Guide Action 机制

受图像外扩（Image Outpainting）启发，Guide Action 将上一动作分块中尚未执行的动作作为“锚点”，用于约束下一分块的生成：

- 已知动作区域设置二进制掩码 \(M\)，其中锚点区域 \(M=1\) 严格保留，新生成区域 \(M=0\) 由模型预测。
- 每一步去噪后，通过元素乘法将已知动作强制恢复：
  \[
  A^{t-1}_{full} = M \odot A^{(t-1)}_{prior} + (1-M) \odot A^{t-1}_{noisy}
  \]
- 引导动作点数量在训练中随机从 0 到 3 采样，以适应推理延迟。
- 该机制将平滑约束内化到扩散生成过程中，避免传统后处理平滑（如样条插值、RTC）的语义不一致问题。

## 6. 主要结论与发现

- **仿真性能**：NebulaVLA 在 LIBERO-Plus 上总体成功率达 **85.5%**，超过 InternVLA-M1（81.3%）、OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。
- **效率提升**：动作生成速度提升约 **2.7 倍**；真实机器人部署中平均推理延迟从 InternVLA-M1 的 81 ms 降至 **42 ms**，同频变体为 115 ms。
- **真实机器人成功率**：
  - Task 1：NebulaVLA-Heter **92.08%**，NebulaVLA-Homo 87.14%，InternVLA-M1 77.91%。
  - Task 2：NebulaVLA-Heter **92.5%**，NebulaVLA-Homo 90%，InternVLA-M1 72.5%。
- **平滑性**：Guide Action 使 7 个关节的平均 Jerk 降低约 **25.6%**，在关节 12 和 13 上分别减少 41.2% 和 45.1%。
- **三阶段训练有效性**：完整训练相比省略 SFT 或 RL 的变体分别提升 1.7% 和 2.5% 总体成功率；S2 RL 还在 Language 和 Layout 等语义耦合维度上有所增益。
- **Camera 扰动性能下降**：GESTURE-7 的训练假设建立了固定的视觉—空间映射，相机姿态扰动会破坏该对应关系，导致该维度性能略低于 InternVLA-M1。

## 7. 优点

- **架构创新**：异步双频设计清晰解耦高层推理与低层控制，兼顾语义泛化与实时响应。
- **跨具身统一表示**：GESTURE-7 用自然语言关键词统一多种末端执行器动作，具有良好的可扩展性和 RL 兼容性。
- **内在平滑约束**：Guide Action 将轨迹连续性直接集成到扩散去噪过程中，避免后处理平滑带来的语义不一致问题。
- **显著效率收益**：推理延迟降低约一半，同时成功率不降反升。
- **工程实用性**：S2 和 S1 可分离部署，适合边缘计算和分布式硬件场景。
- **训练流程完整**：三阶段训练结合 SFT、GRPO RL 和连续动作 SFT，逐步构建语义规划与动作执行能力。
