## 摘要
行人路径预测对于提升自动驾驶车辆和高级驾驶辅助系统的安全性至关重要。以往研究探索了行人路径预测的不同学习任务表述，并使用浅层神经网络比较了这些表述，但未将分析扩展到更复杂的深度学习模型。本文将时空图注意力网络（STGAT）适配到统一的行人路径预测框架中，并引入了针对STGAT的状态和动作定义。由此产生的表述支持确定性和随机策略、一次性及序列决策，以及包括REINFORCE和近端策略优化在内的强化学习算法。与标准监督学习表述相比，所提出的学习任务表述在选定的基准数据集上提高了预测性能。这些结果表明，重新表述决策过程和训练目标可以改进先进的行人轨迹预测架构，并可能为改进其他基于图的预测模型提供途径。

## Abstract
Pedestrian path prediction is crucial for enhancing the safety of autonomous vehicles and advanced driver-assistance systems. Previous studies explored different learning-task formulations for pedestrian path prediction and compared these formulations using shallow neural networks, but did not extend this analysis to more complex deep-learning models. This paper adapts the Spatial-Temporal Graph Attention Network (STGAT) to a unified pedestrian path prediction framework and introduces state and action definitions specific to STGAT. The resulting formulations support deterministic and stochastic policies, one-time and sequential decision-making, and reinforcement-learning algorithms including REINFORCE and proximal policy optimization. The proposed learning-task formulations improve prediction performance across the selected benchmark datasets compared with the standard supervised-learning formulation. These results demonstrate that reformulating the decision process and training objective can improve an advanced pedestrian trajectory prediction architecture and may provide a path toward improving other graph-based prediction models.

## 2. 方法论

### 核心思想
- 将行人路径预测形式化为**马尔可夫决策过程（MDP）**，使用**逆强化学习（IRL）**的思路，将真实轨迹视为专家演示，以预测轨迹与真实轨迹之间的欧氏距离作为奖励信号。
- 采用**统一的 PPP 框架**，将 STGAT 作为策略网络（policy），既可作为确定性策略，也可作为随机策略，分别对接不同的学习任务表述。
- 设计了两种决策过程：
  - **ODM（One-time Decision-making）**：一次性输出未来全部 12 步轨迹，单步 MDP（Tε=1）。
  - **SDM（Sequential Decision-making）**：逐时间步预测下一步位置，12 步 MDP（Tε=12），并引入折扣因子 λ 以调节对远期奖励的关注。

### 关键技术细节
- **模型架构**：STGAT 由 G-LSTM、M-LSTM 编码器和一个共享的 D-LSTM 解码器组成。GAT 用于建模行人间的时空交互。其原有学习方式为监督学习，本文将其策略化。
- **状态与动作定义**：
  - ODM 中，状态为整个场景所有行人的 8 个观测步位置；动作为一个行人未来 12 步的联合坐标向量。
  - SDM 中，状态为观测轨迹与累积预测步的拼接（维度逐步增加）；动作是当前预测时间步的二维坐标。状态转移函数为 \(s_{t+1} = s_t \oplus a_t\)。
- **奖励与回报**：奖励函数 \(r_t = \|(\hat{s}_t, \hat{a}_t) - (s^*_t, a^*_t)\|_2^2\)，即预测状态-动作与真实状态-动作的平方 L2 距离。折扣回报为 \(G_t = \sum_{l=t}^{T_\epsilon-1} \gamma^{l-t} r_l\)。
- **学习算法**：
  - 监督基线：SL-MSE（与 STGAT 原始训练等价）。
  - 随机策略梯度：SL-MSE-SPG（通过 REINFORCE 优化）。
  - 高级 RL：REINFORCE with baseline、PPO（带/不带价值基线）。
- **价值网络设计**：提出两种价值网络架构：
  - **全状态基线（Full State Baseline）**：使用与 STGAT 共享的编码器，只更新浅层全连接网络。
  - **简化基线（Simplified Baseline）**：仅使用单个行人的观测轨迹作为输入。
- **随机性处理**：STGAT 编码器输出中加入固定噪声，以保持多模态预测能力；策略输出按高斯分布采样，标准差固定为 0.05。

## 3. 实验设计

- **数据集**：ETH 数据集（ETH、Hotel 子集）和 UCY 数据集（Zara1、Zara2、Univ 子集），共 5 个标准子集，是 PPP 领域的通用基准。
- **Benchmark**：各子集按 leave-one-out 划分训练/验证/测试集；使用**平均位移误差（ADE）**和**最终位移误差（FDE）**作为主要评价指标，并额外报告多次采样下的最小值 minADE、minFDE。
- **对比方法**：
  - 标准监督学习：SL-MSE（等价于原始 STGAT 训练目标）。
  - ODM 随机策略：SL-MSE-SPG（REINFORCE）。
  - 高级 RL 变体：REINFORCE with baseline、PPO with baseline、PPO without baseline。
  - SDM 序列决策：SL-MSE-SDM，在多个折扣因子（λ=0.2/0.4/0.6/0.8）下评估。
  - 价值网络消融：全状态基线 vs. 简化基线，分别在 REINFORCE 和 PPO 下比较。
- **主要结果**：
  - PPO with full-state baseline 在多数子集上优于 SL-MSE，平均 ADE 从 0.5801 降至 0.5460（约 5.9%），平均 FDE 从 1.1824 降至 1.1335（约 4.1%）。
  - SL-MSE-SDM 在 λ=0.4 时平均 ADE 为 0.5439，优于 SL-MSE（0.5801），且优于部分 PPO 变体。
  - 简化基线在 PPO 下也能达到与全状态基线相当的性能；但 REINFORCE + 简化基线在部分数据集上明显退化（如 Univ 的 ADE 从 0.53 升至 0.73）。

## 6. 主要结论与发现

- 在统一 PPP 框架下，将 STGAT 适配为 RL 策略后，使用**基于基线的 PPO** 或**序列决策监督学习（SL-MSE-SDM，λ=0.4）**均能显著改善预测性能，且在所有基准子集上均优于原始标准监督学习。
- 随机策略本身（SL-MSE-SPG）因 REINFORCE 高方差问题并未带来整体提升，说明**算法选择比单纯引入随机性更关键**。
- 价值网络采用**全状态输入**比简化输入更能提升 REINFORCE 的性能，但对于 PPO 则两种价值网络性能相当。
- SDM 的累积式状态转移使优化更侧重于轨迹初始几步的学习，从而对整体轨迹（尤其是最终位置）有正向影响，印证了“初始决策对长轨迹预测至关重要”的直觉。
- 结论性观点：**重新设计决策过程和训练目标是一类有效的 PPP 性能提升手段**，有潜力迁移到其他基于图注意力架构的现代预测模型。
