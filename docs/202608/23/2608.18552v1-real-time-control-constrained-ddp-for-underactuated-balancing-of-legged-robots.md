## 摘要
本文提出了一种适用于欠驱动足式机器人的实时控制约束微分动态规划（DDP）框架。为解决经典DDP在处理控制约束方面的局限性，我们提出了一种基于加速投影梯度（APG）的控制约束DDP（ABC-DDP），该方法能够高效计算约束解并识别有效集，且无需重复进行Karush-Kuhn-Tucker（KKT）求逆。通过引入虚拟约束，将控制约束集成到可行性驱动的多重打靶框架中，即使从动态不可行初始状态出发也能实现稳定优化。所提方法支持在强欠驱动条件下进行短时域实时模型预测控制（MPC）。仿真结果展示了在统一MPC框架下的静态双腿站立（抗外部扰动）以及多种动态运动，包括慢速猫步、直立行走和高速奔跑。据我们所知，这是首次通过实时有限时域MPC实现四足机器人静态双腿站立的演示。

## Abstract
This paper presents a real-time control-constrained Differential Dynamic Programming (DDP) framework for underactuated legged robots. To address the limitation of classical DDP in handling control constraints, we propose an Accelerated Projected Gradient (APG)-based control-constrained DDP (ABC-DDP), which efficiently computes constrained solutions and identifies active sets without repeated Karush-Kuhn-Tucker (KKT) inversions. A virtual constraint is introduced to integrate control constraints within a feasibility-driven multiple-shooting framework, enabling stable optimization even from dynamically infeasible initializations. The proposed method supports real-time model predictive control (MPC) with short horizons under strong underactuation. Simulation results demonstrate static two-leg standing under external disturbances, along with diverse dynamic motions including slow catwalk, upright walking, and high-speed running within a unified MPC framework. To the best of our knowledge, this is the first demonstration of static two-leg standing of a quadruped robot achieved using real-time finite-horizon MPC.

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

- **整体框架**：将 MPC 问题建模为有限时域最优控制问题，使用单刚体动力学（SRBD）模型，控制量为各腿的地面反作用力（GRFs）。成本函数包含状态误差二次项、控制项和相邻控制变化项。
- **核心思想**：将约束 DDP 子问题中的受限极小化求解交给 APG 方法，利用其投影计算简单、无需海森逆的优点，自然识别活跃集；之后再利用活跃集构造 KKT 系统求解反馈增益，从而兼顾效率与精确性。
- **APG 方法**：
  - 采用非单调加速投影梯度法（Nonmonotone APG），结合 Barzilai–Borwein（BB）步长初始化、回溯线搜索和非单调接受准则，保证在病态或非凸场景下的收敛性。
  - 使用 Nesterov 动量以在局部凸区域获得 O(1/k²) 的收敛速率。
- **受限反向传播（Constrained Backward Pass）**：
  - 在每个时间步最小化二次近似 Q 函数，约束形式为线性不等式 \(A_k \delta u_k - b_k \le 0\)；
  - 对活跃约束构建 KKT 系统求解，得到控制律 \(\delta u_k^* = K_k \delta x_k + k_k\)；
  - 利用 APG 求解无状态偏差（即 δx=0）的受限问题，从而获得前馈项和活跃集，避免了对完整 KKT 矩阵的重复分解。
- **多重打靶集成（FDDP）**：
  - 定义状态间隙 \(\bar{f}_{k+1} = f_k(x_k,u_k) \ominus x_{k+1}\)，允许状态与控制序列在中间迭代中动态不可行；
  - 前向传播采用可行性驱动回溯，通过 α 参数逐步减小间隙（间隙以因子 (1−α) 衰减），使轨迹逐步收敛至可行；
  - 修正值函数以纳入间隙影响（\(V_{x_{k+1}} \leftarrow V_{x_{k+1}} + V_{xx_{k+1}}\bar{f}_{k+1}\)）。
- **虚拟约束与边界收缩**：
  - 在存在活跃约束且 α<1 时，将回溯所产生的前馈步视为位于一个超平面（虚拟约束）上，反馈分量沿该超平面滑动；
  - 引入参数 β 对原约束集进行线性收缩（\(C'_k := \{\delta u^{fb}_k \mid A_k \delta u^{fb}_k - \beta b^{ff}_k \le 0\}\)），限制反馈分量搜索区域，增强稳定性。
- **动态不可行初始 rollout**：
  - 通过 PD 型控制律构造名义轨迹，使其有界且不偏离期望轨迹，避免了欠驱动条件下单次打靶发散问题。
- **期望改进与正则化**：
  - 使用二阶期望改进准则决定回溯步是否接受，允许适度目标上升以优先改善可行性；
  - 若条件不满足，则对海森矩阵施加正则化（\(Q_{uu}^k \leftarrow Q_{uu}^k + \gamma I\)）。
- **算法流程**（Algorithm 2）：
  1. 初始 rollout；
  2. 计算间隙，若足够小则清零并设 α=1；
  3. 反向传播：计算泰勒系数，用 APG 解受限子问题，识别前馈项与活跃集，必要时更新虚拟约束，再解 KKT 得反馈增益，更新值函数；
  4. 前向传播：按 (20)(23) 更新状态与控制，计算期望改进，若不满足则缩小 β 或 α，必要时更新 γ；
  5. 迭代直到成本收敛和间隙为零。
