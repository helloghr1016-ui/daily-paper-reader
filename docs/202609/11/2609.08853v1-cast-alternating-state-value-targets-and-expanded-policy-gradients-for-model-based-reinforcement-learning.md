## 摘要
基于模型的强化学习（MBRL）是一类强化学习方法，它学习环境模型并将其用于动作选择，因其样本效率而非常适合机器人领域。将学习到的模型与在线规划相结合可以进一步改进动作选择，因为规划器能够利用模型找到比仅使用学习到的策略更好的动作。近期将学习到的策略与在线规划相结合的方法通常学习策略的价值，而不是更强的规划器引导行为。我们提出 CAST（Critic with Alternating State-value Target，即带有交替状态价值目标的评论家），它利用规划器引导的行为来改进价值学习，同时用当前策略对价值估计进行正则化。CAST 将动作价值评论家替换为状态价值评论家，其训练目标结合了一条真实的规划器引导转移和在当前策略下想象出的转移。由此得到的价值函数对应于规划器引导行为与当前策略之间的交替过程，使其能够受益于更强的规划器行为，同时受到正在学习的策略的正则化。我们在 DeepMind Control 和 HumanoidBench 套件上针对若干最先进方法评估 CAST，并展示了成功迁移到一台执行动态倒立的实体 Unitree Go2 四足机器人。

## Abstract
Model-based reinforcement learning (MBRL) is a family of RL methods that learn a model of the environment and use it for action selection, making it well suited to robotics due to its sample efficiency. Combining learned models with online planning can further improve action selection, as the planner can exploit the model to find better actions than the learned policy alone. Recent methods combining learned policies with online planning typically learn the value of the policy rather than the stronger planner-guided behavior. We present CAST (Critic with Alternating State-value Target), which uses planner-guided behavior to improve value learning while regularizing the value estimate with the current policy. CAST replaces the action-value critic with a state-value critic, trained using a target that combines a real planner-guided transition and an imagined transition under the current policy. The resulting value function corresponds to an alternating process between planner-guided behavior and the current policy, allowing it to benefit from the stronger planner behavior while being regularised by the policy being learned. We evaluate CAST on the DeepMind Control and HumanoidBench Suites against several state-of-the-art methods, and demonstrate successful transfer to a physical Unitree Go2 quadruped performing a dynamic handstand.

## 1. 核心问题与研究动机

- **背景**：基于模型的强化学习（MBRL）通过学习环境模型来提升样本效率，特别适合机器人领域。将学习到的模型与在线规划（如 MPPI）结合，可以借助规划器找到比学习策略本身更好的动作。
- **核心矛盾**：近期将策略与在线规划结合的方法（如 TD-MPC2、BOOM、BMPC）通常学习的是**策略 πθ 的价值**，而非更强的**规划器引导行为 β 的价值**。尽管行为策略 β（规划器）在训练早期通常显著优于 πθ，这些方法只是通过策略对齐（BOOM）、行为克隆（BMPC）等手段缩小 πθ 与 β 的差距。
- **关键问题**：
  - 既然 β 比 πθ 更强，critic 是否应直接学习 β 的价值？
  - 直接对 β 自举（bootstrapping）会导致策略更新过大、训练不稳定。
  - 学习 Qβ(z, a) 在计算上不可行，因为每次 TD 目标都需要重新调用规划器查询 β 的动作分布。
- **研究含义**：作者提出 CAST，通过交替状态价值目标，让 critic 在正则化下逼近 β 的价值，同时避免直接自举 β 带来的不稳定，从而提升样本效率与策略学习质量。

## 2. 方法论

### 2.1 核心思想

- 将 TD-MPC2 中的**动作价值 critic Q(z, a)** 替换为**状态价值 critic V(z)**，使其能够学习规划器引导行为 β 的价值。
- 构造**混合 Bellman 目标**：一条来自 replay buffer 的真实 β 转移 + 一条由当前策略 πθ 在学习模型中想象出的转移。
- 该目标对应交替过程：**β → πθ → β → πθ → …**，使 critic 既受益于更强的 β 行为，又被当前策略正则化。

### 2.2 关键技术细节

- **状态价值公式**（动力学确定性）：
  - Qπ(z, a) = R(z, a) + γ Vπ(d(z, a))
  - Vπ(z) = E_{a∼π(·|z)}[Qπ(z, a)]
- **Q 的重构**：当需要动作价值估计时，使用学习到的奖励模型 Rξ、动力学模型 dξ 和 target 状态价值 V̄ψ 重构：
  - Q̂(z, a) = Rξ(z, a) + γ V̄ψ(dξ(z, a))
- **混合价值目标**（Eq. 9）：
  - y_t = r_t + γ [ Rξ(z_{t+1}, ã_{t+1}) + γ V̄ψ(z̃_{t+2}) ]
  - 其中 z_{t+1} = hξ(s_{t+1})，ã_{t+1} ∼ πθ(·|z_{t+1})，z̃_{t+2} = dξ(z_{t+1}, ã_{t+1})。
  - 第一步来自 replay buffer 中 β 产生的真实转移，第二步由当前策略在学习模型中想象生成。
- **规划器终端目标修改**（Eq. 8）：
  - Ĝ = Σ_{h=0}^{H-1} γ^h Rξ(z_{t+h}, a_{t+h}) + γ^H V̄ψ(z_{t+H})
  - 不再需要采样终端策略动作，直接用状态价值评估终端。
- **理论分析**：
  - 定义 Bellman 算子 Tβ 和 Tπ，CAST 目标对应复合算子 TCAST = Tβ Tπ。
  - **命题 1**：在 β 与 πθ 固定、动力学确定性、价值函数可无误差表示的假设下，TCAST 是 γ²-压缩映射，存在唯一不动点 VCAST = Tβ Tπ VCAST。
  - 展开后 VCAST(z) = E[r₀^β + γ r₁^π + γ² r₂^β + γ³ r₃^π + …]，即 β 与 πθ 交替折扣奖励，位于 Vβ 与 Vπθ 之间。
- **扩展策略梯度**（Eq. 19–21）：
  - 将 Qψ(z, πθ(z)) 替换为 Q̂(z, πθ(z)) = Rξ(z, πθ(z)) + γ V̄ψ(dξ(z, πθ(z)))。
  - 递归展开 Hπ 步，通过可微分世界模型传播策略梯度，用冻结的 target critic V̄ψ 自举：
    - J_k(z₀; θ) = Σ_{i=0}^{Hπ-1} γ^i Rξ(z^(i), a^(i)) + γ^{Hπ} V̄ψ(z^(Hπ))
  - 梯度流经 πθ → Rξ → dξ → … → V̄ψ 整条想象链。
  - 主要配置 Hπ = 1，Hπ > 1 作为消融研究。
- **算法流程**（Algorithm 1）：
  1. 用 MPPI 规划、采集数据并存入 replay buffer；
  2. 采样轨迹，构造混合价值目标 y_t；
  3. 更新世界模型与 critic（πθ 不参与该优化器）；
  4. 用扩展策略梯度更新策略；
  5. Polyak 更新 target 网络。
