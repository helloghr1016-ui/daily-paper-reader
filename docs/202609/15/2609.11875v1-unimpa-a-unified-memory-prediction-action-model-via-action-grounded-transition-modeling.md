## 摘要
近期，视觉-语言-动作（VLA）模型的进展改进了机器人操作，但从观测到动作的学习仍受限于一个基本的转移可实现性鸿沟，该鸿沟表现为三个紧密耦合的问题：(i) 转移歧义。视觉上相似的当前观测可能对应不同的操作阶段，并意味着不同的后续转移。(ii) 预测-执行不匹配。视觉上合理的预测未来观测不一定对应物理上可实现的转移。(iii) 经验-实现不匹配。历史上可执行的动作模式在当前场景中不一定能实现预期转移，因此需要上下文感知的适应。为此，我们提出 UniMPA，一种统一的记忆-预测-动作模型，通过共享的动作锚定转移接口来解决这些问题。(i) UniMPA 引入持久-选择性未来预测，通过建模预期未来状态演化来解决转移歧义。持久潜在流持续跟踪任务级进展，而转移关键像素流通过基于记忆的预测选择性地解析细粒度交互变化。(ii) 为了评估预期转移的物理可执行性，预测转移查询一个时序视觉-动作记忆库。该库检索历史上已实现的视觉-动作经验，将未来预测建立在可执行证据之上。(iii) 为了使可执行经验适应当前场景，一个动作-视觉记忆库从历史动作演化中检索视觉锚定的动作原型。原型偏置流随后将流源推向历史上支持的动作流形，以进行上下文感知的细化。

## Abstract
Recent advances in Vision-Language-Action (VLA) models have improved robotic manipulation, yet observation-to-action learning remains limited by a fundamental transition realizability gap, manifested in three tightly coupled problems: (i) Transition ambiguity. Visually similar current observations may correspond to different manipulation phases and imply different subsequent transitions. (ii) Prediction--execution mismatch. A visually plausible predicted future observation does not necessarily correspond to a physically realizable transition. (iii) Experience--realization mismatch. A historically executable action pattern may not necessarily realize the intended transition in the current scene and therefore requires context-aware adaptation. Accordingly, we propose UniMPA, a Unified Memory-Prediction-Action model that addresses these problems through a shared action-grounded transition interface. (i) UniMPA introduces Persistent-Selective Future Prediction to resolve transition ambiguity by modeling the intended future state evolution. A persistent latent stream continuously tracks task-level progress, while a transition-critical pixel stream selectively resolves fine-grained interaction changes through memory-grounded prediction. (ii) To assess the physical executability of the anticipated transition, the predicted transition queries a temporal Visual-Action Memory Bank. The bank retrieves historically realized visual-action experience, grounding future prediction in executable evidence. (iii) To adapt executable experience to the current scene, an Action-Visual Memory Bank retrieves visually grounded action prototypes from historical action evolution. Prototype-Biased Flow then shifts the flow source toward a historically supported action manifold for context-aware refinement.

- **研究领域**：视觉-语言-动作（Vision-Language-Action, VLA）模型驱动的机器人操作。
- **核心痛点**：从观测到动作的学习存在一个根本性的 **“转移可实现性鸿沟”（transition realizability gap）**，即模型预测的“下一步”在视觉上可能合理，但在物理执行层面未必可实现。
- **该鸿沟被拆解为三个紧耦合的子问题**：

  - **预测-执行失配（Prediction–execution mismatch）**：视觉上看似合理的未来观测预测，不一定是物理上可实现的转移，预测空间与可执行空间之间存在偏差。
  - **经验-实现失配（Experience–realization mismatch）**：历史上可执行的动作模式，在当前场景中未必能实现预期转移，需要上下文感知的适应，而非简单复用。

### 2.1 核心思想

  1. **持久-选择性未来预测**（解决转移歧义）；
  2. **时序视觉-动作记忆库**（评估物理可执行性）；

### 2.2 关键技术细节（按摘要顺序）

- **（i）持久-选择性未来预测（Persistent-Selective Future Prediction）**
  - 目的：通过建模“预期未来状态演化”来消解转移歧义。
  - **持久隐流（persistent latent stream）**：持续跟踪任务级进展，提供长时程、任务层面的状态表征。
  - **转移关键像素流（transition-critical pixel stream）**：通过基于记忆的预测，选择性地解析细粒度交互变化，聚焦于对转移真正关键的像素级动态。
  - 二者结合：既保留任务级连续性，又对关键交互细节做选择性建模，避免对全部视觉信息均匀预测。

- **（ii）时序视觉-动作记忆库（Temporal Visual-Action Memory Bank）**
  - 目的：评估“预期转移”的物理可执行性。
  - 机制：预测得到的转移作为查询，从记忆库中检索 **历史上已实现的视觉-动作经验**，将未来预测锚定在可执行证据之上。
  - 作用：把“视觉上合理”约束为“历史上可实现”，缓解预测-执行失配。

- **（iii）动作-视觉记忆库与原型偏置流（Action-Visual Memory Bank + Prototype-Biased Flow）**
  - **动作-视觉记忆库**：从历史动作演化中检索 **视觉锚定的动作原型（visually grounded action prototypes）**。
  - **原型偏置流（Prototype-Biased Flow）**：将流源（flow source）推向 **历史上支持的动作流形（historically supported action manifold）**，实现上下文感知的细化。
  - 作用：使可执行经验适应当前场景，缓解经验-实现失配。

1. 输入当前观测与任务指令；
2. 持久隐流跟踪任务级进度，转移关键像素流选择性预测未来交互变化；

5. 通过原型偏置流，将动作生成流源偏置到历史支持的动作流形上；
6. 输出经上下文自适应细化的动作。

- **问题拆解清晰**：将“转移可实现性鸿沟”明确分解为转移歧义、预测-执行失配、经验-实现失配三个紧耦合问题，问题定义具有结构性。
- **统一接口设计**：以“动作锚定转移”作为共享接口，避免记忆、预测、动作三模块各自为政，思路具有系统性。
- **双流预测机制**：持久隐流负责任务级长时程进度，转移关键像素流负责细粒度交互变化，兼顾全局连续性与局部关键性，设计有针对性。
- **记忆库的双向使用**：
  - 时序视觉-动作记忆库用于**验证可执行性**（预测 → 检索历史实现）；
  - 动作-视觉记忆库用于**提供动作先验**（历史动作演化 → 视觉锚定原型）。
  两者分别对应“评估”与“生成”，分工明确。
- **原型偏置流**：将生成流源推向历史支持的动作流形，是一种把检索到的经验转化为生成约束的可行机制，兼具检索增强与流模型细化的特点。
- **潜在的可解释性**：记忆库检索与原型偏置为动作生成提供了“历史证据”来源，便于分析失败模式。

- **实证证据缺失（给定文本层面）**：

- **实验细节不可核验**：
  - 数据集、benchmark、对比方法、评价指标、消融设置均未在给定文本中出现。
  - 21 个表格与 24 张图的具体内容无法读取，不能据此断言实验充分。
- **算力与可复现性未说明**：无 GPU 型号、数量、训练时长、参数量与推理开销信息，难以评估实际部署成本。
- **潜在的方法局限（基于摘要推断）**：
  - **记忆库依赖**：性能可能高度依赖历史经验的质量与覆盖度；面对新场景、新物体或分布外任务时，检索到的原型可能不适用。
  - **检索开销**：时序视觉-动作记忆库与动作-视觉记忆库的构建、维护与查询可能带来显著计算与存储成本，摘要未讨论实时性。
  - **流形假设**：原型偏置流假设存在“历史上支持的动作流形”，若真实可行动作分布多峰或非连续，单一偏置方向可能引入偏差。
  - **三个失配的耦合性**：论文虽将其拆解，但未在给定文本中说明三者之间的相互影响是否被联合优化，是否存在误差累积。
  - **泛化与鲁棒性**：跨机器人本体、跨视角、跨光照条件下的表现未知。
- **偏差风险**：
  - 若记忆库主要来自特定任务或特定机器人数据，可能引入数据偏差，使模型偏向历史高频动作模式，降低探索能力。
  - 检索式方法可能对记忆库中的噪声或次优经验敏感。
- **应用限制**：
  - 长时程、多阶段操作任务中，持久隐流能否稳定跟踪任务进度尚需验证。
  - 真实机器人上的闭环执行安全性、失败恢复机制未在给定文本中讨论。
