## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解与连续动作控制，为通用机器人操作提供了一条可扩展的路径。然而，我们揭示了 VLA 架构的一个关键局限：动作专家对 VLM 特征中可用的三维几何和二维语义信息的访问有限。这一可访问性差距削弱了感知对齐，并限制了细粒度机器人操作的表现。为解决该问题，我们提出 V-Link，在视觉-语言（VL）到动作（A）的特征传递过程中显式恢复视觉表征。具体而言，V-Link 在 VLM 中学习互补的空间查询与语义查询表征，并通过非对称路径将其注入动作 DiT。语义查询补充原始 VLM 图像 token，而空间查询为空间有据的动作生成提供专门的几何条件。在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 上，我们的 V-Link 相对于基础模型 GR00T N1.6，平均成功率分别提升 +1.9%、+31.2% 和 +18.8%。在 AGIBOT A3 Ultra 上，V-Link 在两个真实世界人形机器人任务上进一步取得 +20% 和 +24% 的提升。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

- **研究领域与背景**：视觉-语言-动作（VLA）模型整合视觉感知、语言理解与连续动作控制，是实现通用机器人操作的重要范式。双系统架构（VLM + 动作专家）被广泛采用，其中视觉-语言（VL）到动作（A）的特征传递决定了动作专家能获得多少感知信息。
- **揭示的核心问题**：动作专家（Action DiT）对 VLM 特征中的 **3D 几何信息和 2D 语义信息** 的访问受到明显限制，即存在“视觉表征可访问性瓶颈”。
  - 论文采用诊断协议：冻结 VLM 和 Action DiT 特征，仅训练轻量深度估计头与语义分割头，评估冻结表征的可访问性。
  - 结果显示：与 VLM 特征相比，GR00T N1.6 的 Action DiT 特征在深度估计上 **MAE 从 0.015 恶化到 0.071**，语义分割 **mIoU 从 0.665 降至 0.290**，说明动作专家丧失了大部分 3D 几何和 2D 语义信息。
- **假设与动机**：由于最终层 VLM 特征高度纠缠，且动作监督仅关注降低动作损失，Action DiT 可能倾向采用“语义捷径”，优先利用语义线索而忽略结构关键的 3D 空间线索，导致局部最优和空间定位不足。
- **研究目标**：在 VL 到 A 特征传递中显式恢复视觉表征，使动作专家重新获得充分的几何与语义信息，从而提升细粒度机器人操作性能。

## 2. 方法论

- **整体框架**：提出 **V-Link**，在 VLM 中学习互补的 **Spatial Queries（空间查询）** 与 **Semantic Queries（语义查询）**，并通过非对称路径注入 Action DiT，在推理时不需要任何辅助头或额外标注。
- **VLM 表征解耦**：
  - 在 VLM 输入中引入两类可学习查询 token：`[E_t; E_o; E_d; E_s]`，其中 `E_d` 为空间查询，`E_s` 为语义查询，`E_t` 为文本 token，`E_o` 为多视角图像 token。
  - 使用定制因果注意力掩码 `M_q`，使两类查询独立关注图像和文本 token，同时不干扰原始多模态计算。
  - 通过多层 Transformer 聚合视觉线索，得到 `E'_d`（空间查询最终表征）和 `E'_s`（语义查询最终表征）。
  - **训练专用监督**：
    - 空间查询连接轻量深度头 `Φ_Depth`，预测密集深度图 `D̂ = σ_+(Φ_Depth(E'_d))`。深度头约 2.3M 参数，包含投影层、两层 per-view Transformer 编码器和卷积解码器。
    - 语义查询连接轻量语义分割头 `Φ_Seg`，输出语义 logits `Ŷ = Softmax(Φ_Seg(E'_s))`。
    - 损失函数包括 `L_depth`（smooth-L1 + relative loss + top-k 硬块损失）和 `L_seg`（交叉熵 + soft Dice），用于强制两类查询分别编码几何与语义信息。
    - 推理时移除辅助头，无需深度或分割标注。
- **Action DiT 中的视觉表征恢复**：
  - GR00T N1.6 采用 32 层 AlternateVLDiT，注意力模式每 4 层重复：非图像交叉注意力、状态/动作自注意力、图像交叉注意力、状态/动作自注意力。V-Link 仅在图像交叉注意力层（`ℓ = 4k + 2`）注入查询表征。
  - 机器人状态 `s` 和噪声动作 `x_t` 编码为输入 token `H_0`。
  - **语义路径**：`H_l` 同时与 VLM 图像 token `E'_o` 和语义查询 `E'_s` 做并行交叉注意力，输出 `N_l` 和 `S_l`；
    - 两者拼接后通过 `Fuse` 投影，并经过可学习门控参数 `g_l` 与残差连接得到语义增强特征 `Z_l = H_l + Fuse(N_l, g_l·S_l)`。
  - **空间路径**：`Z_l` 再与空间查询 `E'_d` 做交叉注意力，得到空间条件化特征 `H'_l = Z_l + CA_Spatial(Z_l, E'_d)`；
  - 经 FFN 得到该层输出 `H_{l+1} = H'_l + FFN(H'_l)`。
  - 这种非对称设计使得空间查询形成强制性的几何条件分支，避免 Action DiT 仅依赖语义捷径。
- **训练目标**：`L = L_act + λ_a1·L_depth + λ_a2·L_seg`，其中 `L_act` 为 flow-matching 动作损失，系数 λ_a1=0.1，λ_a2=0.002。
- **训练细节**：冻结预训练语言和视觉骨干，使用 rank-128 LoRA 适应 VLM；先 warm-up 训练 LoRA 参数、查询 token 和任务头，再进行联合优化。

## 3. 实验设计

## 6. 主要结论与发现

- V-Link 能够有效恢复 Action DiT 中被削弱的 3D 几何和 2D 语义表征，并显著提升操作成功率。
- 在仿真基准上，V-Link 平均成功率相比基础模型 GR00T N1.6 提升：
  - LIBERO：**+1.9%**（99.3% vs. 97.4%）；
  - LIBERO-Plus：**+31.2%**（75.0% vs. 43.8%）；
  - RoboTwin 2.0：**+18.8%**（56.8% vs. 38.0%）。
- 在真实世界 AGIBOT A3 Ultra 上，开机任务成功率 **98%**（基线 78%），关机任务 **94%**（基线 70%），分别提升 +20% 和 +24%。
- 消融实验表明，空间查询对移动和放置任务增益大，语义查询对接触类任务增益大，二者互补；任务监督与查询注入缺一不可。
- 推理延迟仅增加 1.58 ms，验证了表征恢复方法的高效性。
- 核心结论：在 VL-to-A 接口进行视觉表征恢复，是提升 VLA 模型精细

操作性能与分布外泛化能力的有效途径，同时保持了极低的额外推理延迟（+1.58 ms）。该工作表明，显式恢复动作专家中的空间与语义表征，能够缓解双系统 VLA 中由语义捷径引起的局部最优问题，并在仿真与真实人形机器人任务中验证了方法的有效性与部署可行性。

**局限性与未来工作**：论文也指出当前验证主要基于 GR00T N1.6 单一基础模型，尚未在更多 VLA 架构上进行跨模型检验；真实世界任务数量与物体类别仍相对有限，长期连续操作、动态环境及多任务泛化能力有待进一步评估。此外，训练阶段需要借助深度与语义分割监督，虽然推理时无需任何辅助标注，但增加了训练数据准备与计算开销。作者提出未来可探索将 V-Link 扩展到更广泛的基础模型和任务集，并研究弱监督或无监督的表征恢复方法，以进一步降低对额外标注的依赖。
