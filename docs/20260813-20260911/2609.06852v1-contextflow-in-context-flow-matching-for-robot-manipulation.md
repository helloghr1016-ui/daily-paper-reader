## 摘要
尽管在视觉和语言领域非常有效，将上下文学习应用于机器人技术仍然具有挑战性。现有的自回归上下文模仿方法将连续动作离散化，并通过下一个 token 预测加剧了早期预测误差的累积，限制了它们在未见任务配置上的泛化能力。同时，流匹配策略已被探索用于连续机器人控制，并有助于减轻复合误差；然而，在流匹配框架内的上下文模仿学习仍未得到充分探索。为了解决这些局限性，我们提出了 ContextFlow，一种条件流匹配模型，用于学习上下文模仿学习的连续动作分布。ContextFlow 将基于流的动作预测条件化于演示和观测，从而能够从含噪动作分布中鲁棒地生成。为了更好地编码多模态上下文演示，我们采用了 Perceiver 风格的多模态上下文压缩器，将视觉、本体感觉和动作序列提炼为紧凑的、与任务相关的潜在表示。在 LIBERO 上，ContextFlow 在未见任务配置上的平均成功率比 ICRT 高出 35 个百分点，同时在未见任务上无需任何微调即可达到任务特定微调 VLA 模型 π0 的性能。在真实机器人上，它泛化到单臂和双臂任务的未见配置，在新的开笔帽配置上实现了 40% 的成功率。项目页面：https://dingjiansw101.github.io/contextflow-page/。

## Abstract
Although highly effective in vision and language domains, applying in-context learning to robotics remains challenging. Existing autoregressive in-context imitation methods discretize continuous actions and exacerbate the accumulation of early prediction errors through next-token prediction, limiting their generalization on unseen task configurations. Meanwhile, flow-matching policies have been explored for continuous robot control and can help mitigate compounding errors; however, in-context imitation learning within a flow-matching framework remains underexplored. To address these limitations, we introduce ContextFlow, a conditional flow-matching model that learns continuous action distributions for in-context imitation learning. ContextFlow conditions flow-based action prediction on demonstrations and observations, enabling robust generation from noisy action distributions. To better encode multimodal in-context demonstrations, we adapt perceiver-style multimodal context compressors that distill visual, proprioceptive, and action sequences into compact, task-relevant latent representations. On LIBERO, ContextFlow outperforms ICRT by 35 percentage points in average success rate on unseen task configurations, while matching the performance of the task-specific fine-tuned VLA model $π_0$ without any fine-tuning on unseen tasks. On real robots, it generalizes to unseen configurations of both single-arm and bimanual tasks, achieving 40% success on a new pen-uncapping configuration. ## 1. 论文的核心问题与整体含义（研究动机和背景）

- 机器人操作中的**上下文模仿学习（in-context imitation learning）**希望模型仅通过少量演示即可适应新任务，无需参数更新。
- 现有自回归式上下文模仿方法（如 ICRT、LipVQ-VAE）存在两大问题：
  - **动作离散化**：将连续动作转换为离散 token，引入量化误差；
  - **误差累积**：逐 token 预测导致早期误差在长时程 rollout 中被不断放大，尤其在训练与评估任务分布不一致（unseen task configuration）时更为严重。
- 流匹配（Flow Matching）已在连续机器人控制中显示出减轻误差累积的能力，但**流匹配框架下的上下文模仿学习尚未被充分探索**。
- 因此，本文提出 **ContextFlow**，旨在将条件流匹配与上下文学习结合，解决自回归方法的离散化与误差累积问题，提升未见任务配置上的泛化能力。

## 2. 论文提出的方法论

### 2.1 核心思想

- 用**条件流匹配**直接建模连续动作分布 π(a_t | o_t, d)，其中 a_t 为未来 H 步动作块，o_t 为当前观测，d 为上下文演示。
- 与自回归不同，流匹配**并行预测整个动作块**，避免逐 token 依赖；同时**在连续空间生成动作**，无离散化误差。

### 2.2 关键技术细节

- **条件流匹配目标**：
  - 在标准高斯先验（s=0）和目标分布（s=1）之间构造线性插值路径：
    \[
    p_s(a_s^t | a_t) = N(a_s^t | s\,a_t, (1-s)^2 I)
    \]
  - 通过噪声插值 \(a_s^t = (1-s)\epsilon + s\,a_t\)，其条件速度场为 \(u(a_s^t | a_t) = a_t - \epsilon\)。
  - 训练损失：
    \[
    L_{CFM}(\theta) = \mathbb{E}_{s,a_t,\epsilon} \| u_\theta(a_s^t, o_t, d, s) - (a_t - \epsilon) \|^2
    \]
  - 推理时采用前向欧拉积分，从高斯噪声逐步去噪得到动作块（K=10 步）。
- **模型架构**（MoE 设计）：
  - **Context Expert**：编码当前观测、文本指令以及压缩后的上下文演示 token；
  - **Action Expert**：接收当前本体感觉状态和噪声动作 token，通过**交叉注意力**与 context expert 交互，执行 K 步流匹配去噪；
  - **块状因果注意力**：动作 token 可关注上下文 token，但上下文 token 不关注动作 token，从而允许缓存上下文 token，提升推理效率。
- **多模态上下文压缩器（Perceiver 风格）**：
  - 对演示中的图像、本体感觉、动作三个模态分别设计可学习 query token 的压缩器；
  - 使用交替的交叉注意力和自注意力层将长序列压缩为固定数量的潜在 token；
  - 每个相机视图的图像压缩器共享权重，共产生 N_q 个 token；状态/动作压缩器各产生 N_q 个 token；
  - 最终拼接所有压缩 token 得到统一上下文表示，显著降低编码长演示的计算成本。
