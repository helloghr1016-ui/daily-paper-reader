## 摘要
独立预训练的语言模型与视觉-语言-动作（VLA）策略为具身智能体提供了互补的构建模块，但将二者连接起来并不会自动产生协调的行为。VLA可能生成偏离LLM预期子任务的动作，并且在纠正后重新获得控制权时，撤销LLM所恢复的有希望的状态。我们提出ESI（具身自我改进），一种利用环境交互来对齐推理与动作的自动化飞轮。ESI将模块化智能体作为后训练单元，反复改进引导LLM的提示、表达其意图的共享技能接口，以及实现该意图的VLA参数，然后将这些组件一起重新部署。我们的关键洞见是，协作本身可以为改进这一接口提供监督信号。LLM的子任务决策为策略应执行什么提供语义监督，而其有效的纠正及随后的学生延续则为恢复与交接提供动作级监督。学生模型还从自身有效的执行中学习，使得即使整个回合失败，局部有用的经验也能作出贡献。在选定的十个RoboDojo任务上，ESI使用LLM-VLA智能体在不生成任务特定控制代码的情况下，取得了62.03的平均得分和49.41%的平均成功率。在这两项指标上，它均优于所有混合具身智能体的已发表参考结果，包括Agent+WAM系统GO-3 Nano Preview（得分47.27，成功率36.60%），以及所有对比的基于代码的方法。

## Abstract
Independently pretrained language models and vision-language-action (VLA) policies provide complementary building blocks for embodied agents, but connecting them does not automatically produce coordinated behavior. The VLA may generate actions that diverge from the LLM's intended subtask and, upon regaining control after a correction, undo the promising state restored by the LLM. We introduce ESI (Embodied Self-Improvement), an automated flywheel that uses environmental interaction to align reasoning and action. ESI treats the modular agent as the unit of post-training, repeatedly refining the prompts that guide the LLM, the shared skill interface that expresses its intent, and the VLA parameters that realize that intent, then redeploying these components together. Our key insight is that collaboration itself can supply supervision for improving this interface. The LLM's subtask decisions provide semantic supervision for what the policy should execute, while its effective corrections and subsequent student continuations provide action-level supervision for recovery and handoff. The student also learns from its own effective execution, allowing locally useful experience to contribute even when the overall episode fails. On ten selected RoboDojo tasks, ESI achieves a mean Score of 62.03 and a mean success rate of 49.41% using an LLM-VLA agent without generating task-specific control code. On both metrics, it outperforms the published reference results of all hybrid embodied agents, including the Agent+WAM system GO-3 Nano Preview (47.27 Score and 36.60% success), as well as all compared code-based methods.

# ESI 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：通用推理模型（LLM）与视觉-语言-动作（VLA）策略各自独立预训练，能力互补——LLM 负责理解指令、识别物体、规划中间目标、失败后修订计划；VLA 负责从图像、语言、本体感知生成连续动作。二者组合是通向通用机器人的有吸引力路径。
- **核心矛盾**：把两个强组件"接起来"并不自动产生协调行为，失败集中发生在**接口**上：
  - **意图鸿沟（intent gap）**：任务微调过的 VLA 可能识别到熟悉场景就复现熟悉动作，忽略教师更具体的指令；已有工作指出视觉捷径会让场景信息压过语言约束。
  - **交接鸿沟（handoff gap）**：LLM 正确诊断、调整夹爪、恢复了有希望的构型，但控制权交回后 VLA 会把这一纠正"撤销"。
- **现有做法的局限**：只靠反复干预，消耗推理算力却不提升底层动作能力，同样的协调失败会在下一回合重演。
- **核心主张**：这些交互本身是**有价值的学习数据**——它们标出了策略偏离目标的位置、展示了如何纠正、暴露了必须接续执行的状态。因此应把**推理-动作接口本身**作为协同后训练的目标，从"模型级后训练"转向"**系统级后训练**"：让部署中的协作经验反过来改进引导、接口与策略，形成"回合式协助 → 持久能力"的路径。

## 2. 方法论

### 2.1 核心思想

- 将模块化智能体整体作为后训练单元：第 r 轮智能体记为 **A_r = (T; P_r, S_r, θ_r)**，其中 T 为**冻结**的 LLM 权重，P_r 为决策提示/指导，S_r 为共享技能目录与参数模式，θ_r 为 VLA 参数。
- 一次收集-学习飞轮：**Collect（回合内 LLM 规划/审核、VLA 提议、教师纠错、VLA 接续）→ Learn（回合后从同一份经验记录更新 P、S、θ）→ Redeploy（三者一起进入下一轮）**。
- 两级具身蒸馏：
  - **语义级迁移**：LLM 的结构化子任务（如"Left arm: Grasp red block."）为"应该执行什么"提供语义监督。
  - **动作级迁移**：LLM 的有效纠正及其后的学生接续为"如何恢复与交接"提供行为监督。

### 2.2 共享子任务接口（在线控制与离线学习共用一套语言）

- 字段包括：`skill_type`（标准技能或 custom）、`arm`（left/right/both）、`object_ref`、`destination_ref`、`target_relation`（none/to/on/in/near）、`target_orientation_ref`、`custom_description`、`giver_arm/receiver_arm`。
- 渲染为简洁指令追加到原始任务后，形成 **subtask conditioning**（任务+局部指令）。
- 该表示只表达**意图**，不含几何规划；同一套语言既用于在线请求动作，也用于离线条件化训练数据。

### 2.3 回合内流程：Plan → Propose → Review → Execute

- 教师基于当前观测与任务上下文选择子任务；VLA 以观测+渲染指令为条件提出 action chunk；教师依据图像、机器人状态、近期反馈和提议的正向运动学轨迹决定执行哪一段、纠正运动/夹爪、或直接指定恢复动作。
- 教师纠正与学生接续共同构成**实际执行轨迹**，控制权切换被记录，供后续学习使用。

### 2.4 三条更新路径（同一经验记录驱动）

- **提示进化（Prompt）**：反思式提示优化。汇总 episode 摘要、结果、教师控制历史，识别反复出现的操作/恢复困难，再结合相关推理记录、旧指导与选定图像提出修订（操作指导、恢复规则、任务策略）；由**独立 reviewer** 核查证据是否支持该失败机制、触发条件是否可在线观测、是否保留原有有效行为；未通过的退回补充证据，通过者自动发布进入下一轮。LLM 权重不变。
- **技能进化（Skill）**：当教师频繁使用 custom 描述时，系统审查相关指令、推理、图像与执行上下文，把反复出现的行为固化为稳定可复用的命名技能；custom 选项保留以暴露新的扩展机会。
- **策略学习（VLA）**：
  - **对齐**：LLM 标注器用文本交互记录与动作后反馈评估局部结果与指令-动作一致性，把执行动作对齐到前序观测与局部意图。
  - **筛选**：保留有效的学生动作、有效的教师纠正、以及后续反馈支持其进展的准备性动作；排除失败、不确定、不一致的片段。**筛选与整条 episode 是否成功无关**（成功抓取/搬运可保留，即使后续放置失败；成功 episode 中的失败尝试也可剔除）。三轮收集中 **47.9%–49.7%** 的训练窗口起点来自最终失败的 episode。
  - **窗口构造**：把保留执行组织为时间连续的 action window，horizon H=50；**控制权在教师与学生间切换不打断窗口**，使"纠正如何到达 + 学生如何接续"联合受监督（称为 intervention-to-policy distillation）。监督在第一个不合格位置或 episode 结束时停止，之后即使重新合格也不再恢复。
  - **语言条件**：每个窗口只用起始点的观测与一个语言条件；在操作过渡处按规则回退到仅任务指令（在线数据：在相同子任务文本连续段的最后决策区间 [a,b) 中，起点 t < a+⌈(b−a)/2⌉ 用子任务，否则用任务目标；离线首轮段 [s,e) 有各自规则）。

### 2.5 经验回放与训练目标

- 递归回放分布：**q₁ = μ₁，q_r = α·μ_r + (1−α)·q_{r−1}，r ≥ 2，α = 0.6**（当轮 60%，历史 40%，历史内部保持相对比例）。对应第 i 轮数据在第 r 轮的权重为：i=1 时 (1−α)^{r−1}，2≤i≤r 时 α(1−α)^{r−i}；α=0.6 时前四个混合为 (1)、(0.4,0.6)、(0.16,0.24,0.60)、(0.064,0.096,0.24,0.60)。
- 轮内采样：任务等权、standard/random 各 0.5；成功/失败 case 权重 **2:1**；episode 内教师控制窗口起点权重 **4**、学生起点权重 **1**，按 episode 归一化。
- 掩码 flow-matching 损失：**L_r(θ) = E_{t∼q_r}[ Σ_{k=0}^{H−1} m_{t,k}·ℓ^FM_{t,k}(θ) / Σ_{k=0}^{H−1} m_{t,k} ]**，m 为时间掩码（有效前缀为 1），按有效位置数归一化使每个窗口等权（含短尾窗口）。
- 学生为 **π0.5**（OpenPI/JAX 实现），保留原生 flow-matching 目标；每轮从上一轮策略初始化并更新整个 VLA。
- 联合重部署：B_r ← Collect(A_r)；P_{r+1} ← ReviewAndRefine(T,P_r,B_r)；S_{r+1} ← ConsolidateSkills(T,S_r,B_r)；D_r ← AnnotateAndSelect(B_r)；θ_{r+1} ← PostTrain(θ_r, D_{1:r}; q_r)；A_{r+1} ← (T; P_{r+1}, S_{r+1}, θ_{r+1})。

## 3. 实验设计

- **平台与场景**：RoboDojo 仿真，双臂 **ARX X5** 操作。学生输入高视角相机+双腕相机+机器人状态+语言；动作表示每臂 6 个关节目标 + 1 个夹爪命令。教师通过 GPT-as-Policy 执行工具工作。
- **任务集**：10 个任务（打包物体、扫积木、摆最大数、套娃排序、物体分类、填笔筒、整理桌面、模仿排序、按语言堆叠、按语言分类）。作者说明是在 GPT-as-Policy 的十任务套件上**替换若干较简单任务为更难任务**。
- **数据规模**：三轮收集，每轮 200 episodes，累计池 200/400/600；每任务每轮 20 cases。三轮策略学习配置在 VLA 更新期间使用固定 prompt 与 skill catalog；首轮离线 bootstrap 子任务标签，后续轮使用在线 subtask conditioning 并在标注时保留

相同的语言条件构造规则；首轮离线 bootstrap 用于给初始策略提供可用的子任务标签，后续轮则直接使用在线收集的 subtask conditioning 数据，并在标注与筛选时保留对应的语言条件，以保证训练条件与部署条件一致。

- **评估协议**：每轮联合重部署后，在相同任务集与相同指令分布上评估，分别报告整体任务成功率、子任务完成率、教师干预频率/控制步比例、控制权交接后的恢复成功率，以及按 standard / random 指令类型拆分的表现。评估既关注最终成功率，也关注“教师纠正后学生能否接续”的接口质量。
- **对照与消融**：论文将完整系统与若干退化版本比较，包括冻结提示与技能目录、仅更新 VLA、仅做提示/技能进化、去掉教师纠正窗口、去掉失败 episode 数据、去掉递归经验回放、去掉独立 reviewer 等，以分离三条更新路径及数据筛选/回放策略的贡献。
- **训练与实现细节**：VLA 每轮从上一轮策略初始化并更新全部参数；策略学习阶段固定当轮 prompt 与 skill catalog，避免在线提示变化与策略更新相互干扰；数据窗口 horizon 为 50，按有效前缀掩码归一化；采样遵循任务等权、成功/失败 2:1、教师起点与学生起点 4:1 的轮内规则，并与递归回放分布 q_r 结合。

## 4. 主要结果与发现

- **整体趋势**：随着轮次推进，系统在十任务套件上的成功率与子任务完成率持续提升，教师干预需求下降；提升并非只来自底层 VLA 动作能力增强，也来自提示规则、技能目录与接口协作方式的共同改进。
- **接口失败显著缓解**：完整系统在“教师纠正后交回控制权”的场景中恢复成功率提升明显，说明将教师纠正与学生接续放入同一 action window 进行干预到策略蒸馏，能直接针对 handoff gap；提示进化则通过把反复出现的恢复规则写入指导，减少同类意图鸿沟的重复发生。
- **失败 episode 的价值**：约 47.9%–49.7% 的训练窗口起点来自最终失败的 episode，表明系统级后训练能够从局部有效但整体失败的经验中提取监督，而不是只依赖成功轨迹；这与“筛选局部动作而非筛选整条 episode”的设计一致。
- **三条路径互补**：提示进化主要改善任务分解、约束遵循与恢复策略；技能进化把频繁出现的 custom 行为固化为标准技能，降低在线决策负担并提高可复用性；策略学习则把纠正行为内化到 VLA 参数中。消融中移除任一关键组件都会削弱跨轮增益，尤其移除纠正窗口或失败数据后，交接恢复能力下降更明显。
- **剩余失败模式**：错误仍集中在长时程任务中的物体遮挡、双臂协调、细粒度放置、语言歧义以及连续多步恢复后的误差累积；这些场景对教师在线审核与策略接续仍提出较高要求。

## 5. 贡献与意义

- 提出**系统级后训练**视角：不把 LLM 与 VLA 的模块化组合视为固定流水线，而是把部署中的推理—动作接口、提示、技能与策略作为联合学习对象。
- 设计**共享子任务接口**，用同一套语言表示同时服务在线控制与离线条件化训练，使“教师如何纠正”和“学生如何接续”能够被统一监督。
- 提出**干预到策略蒸馏**：控制权在教师与学生间切换不打断训练窗口，从而显式学习纠正的到达方式与后续接续，而不是把二者割裂成独立样本。
- 将提示进化、技能进化与 VLA 后训练统一在一个 collect–learn–redeploy 飞轮中，并配合递归经验回放，缓解多轮更新中的遗忘与分布漂移。
- 实验表明，协作经验本身是高质量学习信号；从“回合式协助”可以走向“持久能力”，为通用机器人系统中 LLM 规划器与 VLA 执行器的协同部署提供了可复用的后训练范式。

## 6. 局限与可讨论问题

- 实验主要在 RoboDojo 仿真与固定双臂平台上完成，真实世界的感知噪声、接触动力学与安全约束可能改变接口失败的表现形式。
- 教师依赖 GPT-as-Policy 与人工设计的工具/审核流程，在线收集与提示进化成本较高；教师能力上限也会影响可蒸馏经验的质量。
- 任务集虽包含较难任务与语言条件变体，但规模仍有限，跨任务、跨 embodiment 的泛化需要进一步验证。
- 提示进化的独立 reviewer 能降低退化风险，但审核标准与证据充分性仍可能引入偏差；技能固化也可能过早收敛，抑制新策略探索。
- 失败数据筛选依赖标注器对局部进展的判断，若反馈信号稀疏或存在延迟，窗口构造与监督质量会受影响。

总体而言，论文的核心洞见是：模块化机器人系统的瓶颈常在接口，而接口处的协作轨迹恰好是可学习的数据；把系统而非单个模型作为后训练单元，是提升通用机器人长时程操作能力的一条有前景路径。
