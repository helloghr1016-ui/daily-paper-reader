## 摘要
通用操作机器人必须随时间获得新技能，同时不遗忘已有技能，也不从头重新训练。我们提出一种持续学习框架，将每项技能表示为渐进神经网络（PNN）中的专用专家子网络。新任务通过横向连接上的低秩适配（LoRA）模块复用先验知识，这些连接由可学习的逐父门控控制，从而能够显式衰减各条迁移路径，同时降低密集PNN横向连接的参数开销。对于长时程部署，一个冻结的本地大语言模型将自然语言指令分解为子任务，将其路由到合适的专家，并且仅在专家库不足时请求新专家。使用共享任务空间动作接口，我们在十二个MetaWorld任务以及Sawyer-to-Panda-to-UR5e跨本体迁移实验中评估该框架，结果表明在示范有限时，相对于从头学习，任务成功率有所提高。真实机器人操作实验进一步表明，所提出框架支持组合式执行与专家编排。

## Abstract
General-purpose manipulation robots must acquire new skills over time without forgetting prior ones or retraining from scratch. We present a continual learning framework that represents each skill as a dedicated expert sub- network in a Progressive Neural Network (PNN). New tasks reuse prior knowledge through low-rank adaptation (LoRA) modules on lateral connections controlled by learnable per-parent gates, enabling explicit attenuation of individual transfer paths while reducing the parameter cost of dense PNN laterals. For long-horizon deployment, a frozen local large language model decomposes natural-language instructions into sub-tasks, routes them to suitable experts, and requests a new expert only when the library is insufficient. Using a shared task-space action interface, we evaluate the framework on twelve MetaWorld tasks and in a Sawyer-to-Panda-to-UR5e cross-embodiment transfer experiment, showing improved task success relative to learning from scratch when demonstrations are limited. Real-robot manipulation experiments further demonstrate that the proposed framework supports compositional execution and expert orchestration.

- **背景**：通用操作机器人需要在开放、非结构化环境中终身学习新技能，但主流的“单一整体策略（monolithic policy）”范式存在两大痛点：

  - **可解释性与可部署性差**：不同技能纠缠在同一组参数中，难以定位某行为对应的网络部分、难以量化新技能对旧知识的复用程度，也不利于安全关键场景下的检查、验证与选择性部署。
- **已有持续学习（CL）方法的局限**：
  - 正则化、回放、架构扩展三类方法各有不足；
  - 近年机器人 CL 工作（LEGION、CLARE、SPECI、COLADA 等）多依赖大规模冻结 VLA 主干，训练、存储、部署成本高；
  - 原始渐进神经网络（PNN）虽能避免遗忘，但稠密横向连接参数随任务数呈 Θ(n²d²) 增长，且强制吸收所有前驱特征，易导致负迁移。
- **整体含义**：论文提出将每项技能表示为 PNN 中一个训练后冻结的专家子网络，用**门控低秩（LoRA）横向适配器**实现选择性、参数高效的前向迁移；并用**冻结本地 LLM** 做长时程任务分解与专家路由，从而构建一个可增长、可组合、可跨本体复用的机器人技能库。

## 二、方法论

### 1. 核心思想
- 每个任务对应 PNN 的一个新列（column），训练完成后冻结，保证**零遗忘**；
- 新列通过来自所有旧列的横向连接获取前向迁移，但横向连接改为 **LoRA 低秩分解**，并由**逐父可学习门控**调制，实现选择性迁移并抑制负迁移；
- 高层由冻结 LLM 负责符号级规划（分解、路由、按需新增专家），低层由学习到的专家策略做闭环控制，两层解耦。

### 2. 关键技术细节
- **PNN-LoRA 结构**：每列由若干宽度为 d 的块组成；第 ℓ 块除自身仿射变换 f^t_ℓ 外，接收来自每个前驱列 j<t 的横向适配器 L^t_{ℓ,j}，激活为：
  - h^t_ℓ = φ( f^t_ℓ(h^t_{ℓ−1}) + Σ_{j<t} g^t_{ℓ,j} · L^t_{ℓ,j}(h^j_{ℓ−1}) )
  - 其中 φ 为 ReLU，g^t_{ℓ,j} ∈ (0,1) 为门控；
- **LoRA 横向**：L^t_{ℓ,j}(h) = h · A^t_{ℓ,j} B^t_{ℓ,j}，A∈R^{d×r}、B∈R^{r×d}，秩 r≪d；参数量从 d² 降至 2rd，并把迁移限制在 r 维子空间内，起到稀缺数据下的正则化作用；
- **门控**：g^t_{ℓ,j} = σ(α^t_{ℓ,j})，α 为自由标量，与策略联合优化；有用父专家使门控趋近 1，无用者趋近 0；门控学习率更高且不加权重衰减；
- **可度量迁移**：定义迁移份额
  - u^t_j = c^t_j / (c^t_0 + Σ_{k<t} c^t_k) ∈ [0,1]
  - 其中 c^t_j 为父专家 j 注入列 t 的信号幅度，c^t_0 为列自身贡献；可据此读出新任务复用了哪些旧技能。
- **强化学习训练（MetaWorld 阶段）**：新列用 SAC + 行为克隆（BC）联合训练：
  - L_π = E[ η log π(ã|s) − min_i Q_i(s,ã) ] + λ_BC · E_D[ ‖μ(s) − a‖² ]
  - 双 critic + 延迟目标网络；在线回放与固定示范缓冲各半组成 batch；训练完成后仅冻结 actor 列并加入专家库。
- **LLM 规划（部署阶段）**：
  - 使用冻结的本地 Qwen2.5-7B（通过 Ollama 运行），不微调，只输出结构化 JSON；
  - 两阶段：**分解**（将复合指令拆为有序子目标 + 候选技能）与**路由/监督**（按技能描述匹配专家，依据运行成功率、阈值与切换预算输出 keep / switch / train-new 三种决策）；
  - 切换预算耗尽仍无专家达标时，触发 **train-on-failure**：新增 PNN 列训练该技能，评估后带描述符注册入库。
- **跨本体迁移**：所有本体共享任务空间动作接口 [Δx, Δy, Δz, g]；目标本体（Robosuite Panda/UR5e、真实 FR3）新增列，其 LoRA 横向连接到此前所有冻结专家；由于目标示范稀缺，新列用**条件流匹配**从 N 条示范中模仿学习（学习状态条件速度场，部署时从高斯先验采样并做 20 步 Euler 积分）。

## 六、主要结论与发现

- **零遗忘 + 选择性前向迁移有效**：PNN-LoRA 在 MetaWorld 上除首个任务外均比 standalone、vanilla PNN 及 CL 基线收敛更快；平均成功率 **97.8%**，显著高于 vanilla PNN（77.4%）、standalone（90.3%）、DEN（74.1%）、CLARE（72.8%）、LEGION（45.4%）、PackNet（23.2%）、Replay（26.4%）；在 assembly、box-close 等接触丰富任务上基线普遍崩溃而本方法稳定。
- **参数效率高**：存储与每任务可训练参数接近 standalone，远低于 vanilla PNN（后者随任务数快速增长）；在精度-规模权衡上更优（约 18 MB / 98% vs 113 MB / 77%）。
- **跨本体迁移一致受益**：在所有任务、所有示范预算下均优于从头训练的 MLP-flow；增益在最具挑战的面包拾取上最大；约 30 条示范后性能饱和。
- **迁移由任务相似性主导而非机器人身份**：随着目标数据增多，MetaWorld 粗粒度先验贡献下降（Panda-Can 从 42% 降至 25%，其余目标从约 1/4 降至 ≤3%），同任务族的拾取放置专家成为主要迁移来源；跨本体（UR5e）同样复用 Panda/UR5e 的拾取放置专家。
- **门控使迁移可量化**：真机 box-close 列中横向路径占 80% 迁移份额（53% 来自 5 个真机前置技能，27% 来自仿真专家），自身路径仅 20%。
- **位姿控制可扩展**：7 维动作下三任务成功率 84.0% / 100.0% / 76.0%；开门列强门控到螺母装配专家，收敛仅 10.6k 帧（父列为 106k 帧）。
- **真机长时程组合可行**：六阶段序列在 5 次试验中成功 4 次；LLM 在技能缺失时会先尝试最近专家，失败后触发增量训练新增专家。

- **可复现性信息不完整**：前述算力、训练时长、代码与数据开放情况未充分说明，限制了成本评估与独立复现；若后续能补充硬件配置、随机种子细节与超参敏感性，会显著增强可信度。

## 九、潜在影响与后续方向

- **对机器人持续学习范式的影响**：将 PNN 的“列式零遗忘”与 LoRA 的参数高效、门控的选择性迁移结合，为“可增长技能库”提供了一条比冻结大模型更轻量的路线，尤其适合资源受限的本地部署场景。
- **可解释迁移的实用价值**：迁移份额可作为技能库维护指标，用于发现冗余专家、诊断负迁移、决定是否新增技能，具备进一步工程化潜力。
- **后续可研究方向**：包括专家剪枝/合并与层级化路由、门控稀疏性与理论分析、LLM 规划器的定量基准、更多真实机器人与接触丰富任务的验证，以及把安全约束纳入 train-on-failure 流程。

## 十、总体评价

总体而言，论文的问题意识清晰，方法组合有针对性：以冻结专家列保证零遗忘，以 LoRA 横向连接控制参数增长，以逐父门控实现选择性迁移并可量化，再以冻结 LLM 完成高层分解与路由。实验覆盖仿真、跨本体、完整位姿控制与真机长时程组合，主实验公平性较好，结论具有较强说服力。其主要短板在于消融、规划层定量评估、真机样本量与算力/复现信息不足；这些不影响核心贡献的成立，但决定了该方法从“有前景的系统框架”走向“可广泛复现与部署的标准方案”仍需补强。
