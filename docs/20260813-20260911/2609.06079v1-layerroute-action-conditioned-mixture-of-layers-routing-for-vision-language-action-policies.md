## 摘要
视觉-语言-动作（VLA）策略利用预训练视觉-语言模型（VLM）来引导机器人控制的动作生成。VLM 提供跨层演化的层次化视觉-语义表征，从局部视觉几何到抽象、与语言对齐的语义；因此不同操作任务可能需要不同的层表征混合。同时，动作模块维持中间表征，这些表征在动作计算过程中不断演化，并可为后续决策提供有用信息。然而，现有 VLA 接口在表征访问上灵活性有限：VLM 信息通过为每个动作层固定的层分配来暴露，而中间动作状态仅通过残差流隐式传播，未被显式重用。我们提出 LayerRoute，一种动作条件化的表征路由接口，可自适应访问 VLM 层和动作表征。层混合路由器动态形成缓存 VLM 表征的混合，而动作状态重读则重用先前的动作表征。在多种仿真和真实世界基准上，LayerRoute 一致提升了 StarVLA-π 和 π_{0.5}，在 LIBERO Long 上最高提升 7.2，且仅增加 0.31% / 3.87% 的参数量。消融研究验证了动作条件化层路由的益处，路由分析揭示了跨动作层和任务设置的结构化分配模式。

## Abstract
Vision-Language-Action (VLA) policies leverage pretrained vision-language models (VLMs) to guide action generation for robot control. VLMs provide hierarchical visual-semantic representations that evolve across layers, from local visual geometry to abstract, language-aligned semantics; different manipulation tasks may therefore require different mixtures of layer representations. Meanwhile, the action module maintains intermediate representations that evolve throughout action computation and may provide useful information for subsequent decisions. However, existing VLA interfaces offer limited flexibility in representation access: VLM information is exposed through fixed layer assignments for each action layer, while intermediate action states are only propagated implicitly through residual streams without explicit reuse. We introduce LayerRoute, an action-conditioned representation routing interface that enables adaptive access to VLM layers and action representations. The Layer Mixture Router dynamically forms mixtures of cached VLM representations, while Action-State Reread reuses earlier action representations. Across diverse simulation and real-world benchmarks, LayerRoute consistently improves StarVLA-$π$ and $π_{0.5}$, achieving up to 7.2 gains on LIBERO Long with only 0.31% / 3.87% additional parameters. Ablation studies validate the benefit of action-conditioned layer routing, while routing analyses reveal structured allocation patterns across action layers and task settings.

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）策略通过预训练视觉-语言模型（VLM）为机器人控制生成动作。VLM 在不同深度层提供不同层次的表征：浅层偏局部纹理、几何与空间信息，深层偏抽象、语言对齐的语义信息。
- **核心问题**：不同操作任务需要不同组合的 VLM 层表征；动作模块内部中间状态也可能对后续决策有用。但现有 VLA 架构存在两个限制：
  - VLM 层暴露是**固定层分配**，动作计算过程中无法动态改变所需的 VLM 深度。
  - 早期动作中间状态仅通过残差流隐式传播，无法被后续动作层**显式重读和复用**。
- **整体含义**：论文提出一种**动作条件化的表征路由接口**，让动作计算既能动态选择 VLM 层表征，又能显式重用早期动作状态，从而提升机器人操作策略性能。

## 2. 论文提出的方法论

### 2.1 核心思想

LayerRoute 包含两个互补机制：

- **Layer Mixture Router（层混合路由器）**：以当前动作状态为条件，动态生成对缓存 VLM 层表征的混合权重。
- **Action-State Reread（动作状态重读）**：让当前动作 token 显式地重读并聚合早期动作块的中间状态。

### 2.2 Layer Mixture Router

- 在选定的动作层 \(s\)，对当前动作状态 \(a^{(s)}\) 和候选 VLM 状态 \(\{V_n\}_{n \in \mathcal{C}_s}\) 分别做池化，得到紧凑摘要 \(p_a^{(s)}\) 与 \(p_{V,n}\)。
- 对摘要做 LayerNorm 并用层特定投影映射到共享路由空间 \(d_{sel}=256\)，得到查询 \(q^{(s)}\) 和键 \(k_n^{(s)}\)。
- 计算缩放点积相似度得到路由 logits，再经 softmax 得到深度权重 \(\alpha_n^{(s)}\)。
- 用 \(\alpha_n^{(s)}\) 对所有候选 VLM 状态做加权和，得到路由后的表征 \(\tilde{V}^{(s)}\)，作为交叉注意力的上下文。
- **关键特征**：每个动作层生成一个**样本级、层级共享**的深度分布；所有 VLM token 位置共用同一组深度权重。

### 2.3 Action-State Reread

- 对每个选定动作层 \(s\)，可访问的动作状态源包括：初始动作状态 \(A_0\)、早期保留的中间状态 \(A_{j_1},...,A_{j_k}\)、当前状态 \(A_{cur}\)。
- 每个动作层维护一个**可学习查询向量** \(q_A^{(s)}\)，与所有动作 token 共享。
- 对于每个 token \(t\)，计算 \(q_A^{(s)}\) 与各源状态 token \(A_{i,t}\) 的相似度，softmax 后得到 **token 级权重** \(\rho_{t,i}^{(s)}\)。
- 按权重聚合源状态 token，得到重读状态 \(\hat{a}^{(s)}\) 并送入 FFN。
- **关键特征**：与 VLM 路由器不同，Action-State Reread 的权重是 token 特定的，允许不同 token 从不同早期状态中检索信息。

### 2.4 在两种 VLA 架构中的集成

- **StarVLA-π**：
  - 动作模块为 36 层 DiT，含 18 个交叉注意力层和 18 个自注意力层。
  - 缓存 Qwen3-VL 在层 \([5,11,17,23,29,35]\) 的 6 个隐藏状态。
  - 在全部 18 个交叉注意力层应用 Layer Mixture Router，路由结果直接替换原有编码器上下文。
  - 在全部 36 个 DiT 块应用 Action-State Reread，重读状态传入 FFN。
- **π0.5**：
  - 在线缓存 PaliGemma 在层 \([2,5,8,11,14,17]\) 的逐层输出，仅使用因果可用的候选层。
  - 在 18 个 action-expert 层每层加入未共享的 8 头 action-to-VLM 交叉注意力适配器，提供残差更新后再进入原生 joint attention。
  - Action-State Reread 结合初始状态、早期宏块状态和当前状态。

## 3. 实验设计

### 3.1 数据集与基准

- **性能提升**：
  - LIBERO Long：StarVLA-π 提升 7.2 个百分点，π0.5 提升 3.6 个百分点。

  - 训练过程中路由逐渐偏离均匀分布，约 20K 步后趋于稳定。
  - 动作计算前期偏好浅层 VLM 状态，后期偏好中层和深层状态。
